# 无鬼定理（Goddard–Thorn）剩余部分的 Lean 蓝图

对应图节点 `worldsheet.no-ghost-theorem-v4`、推导 `worldsheet.no-ghost-theorem-v4--via-goddard-thorn`、
里程碑 `ms.no-ghost-theorem`；对应 `formal/TODO.md` 的 `ddf-spans` 与 `no_ghost_theorem` 两项。

**本文件是规划文档，不是 Lean 源码。** 下面所有代码块都是**签名草案**：没有编译过，命名和
隐式参数一定要在真正写文件时再调。它的用途是把「无鬼定理 v4 变成 Lean 定理」剩下的部分
拆成有依赖顺序的、每条都能单独立项的引理，并对每条给出：依赖的**现有**声明名、预估难度、
Mathlib 缺什么。

写这份蓝图时的三条判断（详见 §D「对图的建议」）：

1. **纵向算子这一节几乎是白送的**。Goddard 2008 §6 (6.2)(6.3) 真正用的纵向对象是
   `K_m = k_0 · α_m`，不是 Brower 的 `A^L_n = Ã_n + F_n`。而 `K_m` 在本仓库里就是
   `towerModeVec η a b b m`（偏振取 `ε := b` 自身），它的全部代数关系都是现有引理在
   `ε := b` 处的特例——因为类光条件 `dotVec η b b = 0` 恰好就是 `b` 对自己的横向性。
   Brower 的 `A^L_n` 代价极大且**不在关键路径上**（见 §A.3）。
2. **D = 26 不在你以为的地方进来**。它**不**在特征标/计数里（`φ(q)^{-D} = φ(q)^{-1}φ(q)^{-1}φ(q)^{-(D-2)}`
   对任意 `D` 成立），也不在 DDF 代数、伴随关系、横向 Gram 正定里（这些对任意 `D ≥ 3`
   与任意 ℚ-代数成立）。它只在**「H_phys 中 DDF 之外的部分是零模态」**这一步进来，
   数值见证已经在 `LevelTwo.lean`：`⟨ψ₂,ψ₂⟩ = -2(D-26)(D-1)/25`。
3. **`ddf-spans` 的两条候选路线里，FGZ Prop 2.6(i) 那条在 Lean 里是死路**（卡在一般 `N`
   的 Kac 行列式，本仓库只到 `N ≤ 4`）；GT 原始的计数路线可行但真正的成本不是计数，
   而是**幺三角基变换**。详见 §B。

## A. 纵向算子

### A.0 先做一次文献裁决：是 `K_m` 还是 `A^L_n`？

> **证据层级（reviewer-batch25）**：「GT 真正用的是 K_n」依据是 Goddard 2008 §6 的自述（对 GT 1972 为 L3 转引），GT 1972 正文本项目未获取。裁决对 Lean 工作量的影响不变（K_n 白送），但写进论文时须注明层级。

`literature/extractions/gsw-1987-v1.md` 的 E6/E7/E8 三条（Goddard 2008 正文，标注 L1 已核实）
把两个不同的纵向对象写得很清楚，**图里目前一个节点都没有**：

* **E7（§6, p.15, (6.2)(6.3)）—— GT 真正用的是 `K_n = k · a_n`。** 逐字：
  「The space generated by the DDF states can be specified by imposing the conditions
  `K_n|ψ⟩ = 0, n > 0`, in addition to the physical state conditions」，
  以及 `[L_m, L_n] = (m-n)L_{m+n} + (D/12)m(m²-1)δ`、`[L_m, K_n] = -n K_{m+n}`、`[K_m, K_n] = 0`。
  抽取记录自己加的按语：「**(6.3) 的 `[L_m,K_n] = -n K_{m+n}` 是 GT 证明真正用的代数**，
  不是 `A^i_n` 的对易关系」。
* **E6（§5, p.12, (5.6)–(5.8)）与 E8（§6, p.16, (6.5)–(6.7)）—— Brower 的 `A^L_n = Ã_n + F_n`。**
  `Ã_n = k̃_μ A^μ_n`（`k·k̃ = -1`）**不**与 Virasoro 对易（(5.6) 右端非零），
  必须加修正项 `F_n = (n/4πi) ∮ (k·P'(z))/(k·P(z)) V(nk,z) dz`（(6.6)，Brower 1972）
  才有 `[L_m, A^L_n] = 0`、`[A^L_m, A^i_n] = -n A^i_{m+n}`、
  `[A^L_m, A^L_n] = (m-n)A^L_{m+n} + 2m³δ_{m,-n}`。

**结论：本蓝图走 `K_m`。** 理由：(a) `K_m` 是 GT 路线（本图推导挂的就是 GT）的真实输入；
(b) `K_m` 在 Lean 里几乎白送（A.1）；(c) `A^L_n` 需要把 `1/(k_0·P(z))` 形式化，
那是一个全新的构造（A.3），且只服务于 `D > 26` 的负模构造，而那一条**已经**由
`LevelTwo.lean` 走另一条路证完了。

### A.1 `K_m` 的定义与代数 —— 本蓝图最便宜的一节

**关键观察：`K_m = k_0 · α_m` 就是 `towerModeVec η a b b m`，即偏振取 `ε := b` 自身。**
类光条件 `hbb : dotVec η b b = 0` 恰好就是「`b` 对自己横向」，所以整套以 `hεb` 为钥匙的
既有引理在 `ε := b` 处全部可用。于是下面六条里有四条是现有引理的直接特例。

文件建议：`StringFormal/NoGhost/TowerK.lean`（新建，import `DDFAlgebra` 与 `VertexAdjoint`）。

```lean
namespace StringFormal.NoGhost

/-- **纵向（GT）算子** `K_m = k_0 · α_m = Σ_μ η_μ b^μ α^μ_m`（Goddard 2008 (6.2)）。
定义就是偏振取 `b` 自身的 `towerModeVec`；类光条件 `dotVec η b b = 0` 使 `b` 对自己横向。 -/
noncomputable def towerK (η a b : Fin D → R) (m : ℤ) : Module.End R (TowerFock D R) :=
  towerModeVec η a b b m
```

| # | 引理 | 依赖的既有声明 | 难度 |
|---|---|---|---|
| A1.1 | `lie_towerLop_towerK` | `lie_towerLop_towerModeVec`（`ε := b`） | **小**（一行 `rfl`/`exact`） |
| A1.2 | `lie_towerK_towerK` | `lie_towerModeVec_towerModeVec` + `hbb` | **小** |
| A1.3 | `towerK_zero_eq_id` | `Fock.mode_zero`、`dotVec_towerMomentum_right_of_isotropic`、`hba` | **小** |
| A1.4 | `lie_towerK_towerVertex` | `lie_towerModeVec_towerVertex` + `hbb` | **小** |
| A1.5 | `lie_towerK_ddfOp` | A1.4 + `lie_towerModeVec_towerModeVec` + 窗口（照抄 `towerPairing_ddfOp_left` 的窗口套路） | **中** |
| A1.6 | `towerPairing_towerK_left` | `Fock.towerPairing_towerModeVec_left`（`ε := b`） | **小** |

```lean
/-- `⁅L_m, K_n⁆ = -n K_{m+n}`（Goddard 2008 (6.3) 第二式）。对**任意** `D` 成立，
不需要 `hbb`/`hba`。 -/
theorem lie_towerLop_towerK (hη : ∀ μ, η μ * η μ = 1) (m n : ℤ) :
    ⁅towerLop η a b m, towerK η a b n⁆ = (-(n : R)) • towerK η a b (m + n)

/-- `⁅K_m, K_n⁆ = 0`（(6.3) 第三式）。中心项是 `m (k_0·k_0) δ_{m+n,0}`，由 `k_0² = 0` 消失
——**这是类光条件在本节唯一用到的地方**。 -/
theorem lie_towerK_towerK (hη : ∀ μ, η μ * η μ = 1) (hbb : dotVec η b b = 0) (m n : ℤ) :
    ⁅towerK η a b m, towerK η a b n⁆ = 0

/-- **`K_0 = 1`**：归一化 `2α' k_0·p = 1` 在**每一层**都成立
（`dotVec_towerMomentum_right_of_isotropic`），所以零模是恒等算子而不只是标量。 -/
theorem towerK_zero_eq_id (hbb : dotVec η b b = 0) (hba : dotVec η b a = 1) :
    towerK η a b 0 = LinearMap.id

/-- `⁅K_p, V^{(n)}_K⁆ = n (k_0·k_0) V^{(n)}_{K-p} = 0`：`K` 与顶点算子**严格对易**。 -/
theorem towerK_mul_towerVertex (hη : ∀ μ, η μ * η μ = 1) (hbb : dotVec η b b = 0) (n K p : ℤ) :
    towerK η a b p * towerVertex η b n K = towerVertex η b n K * towerK η a b p

/-- **`⁅K_m, A^ε_n⁆ = 0`**：横向 DDF 算子与纵向算子对易。两个输入各用一次：
`hbb` 让 `K` 穿过顶点算子（A1.4），`hεb` 让 `K` 与 `α^ε_j` 对易（偏振 CCR 的中心项是
`m (k_0·ε) δ`）。 -/
theorem lie_towerK_ddfOp (hη : ∀ μ, η μ * η μ = 1) (hbb : dotVec η b b = 0)
    (hεb : dotVec η ε b = 0) (m n : ℤ) :
    ⁅towerK η a b m, ddfOp η a b ε hη hεb n⁆ = 0

/-- `K_m† = K_{-m}`。 -/
theorem towerPairing_towerK_left (m : ℤ) (v w : TowerFock D R) :
    Fock.towerPairing η (towerK η a b m v) w = Fock.towerPairing η v (towerK η a b (-m) w)
```

**关于 A1.5 的唯一实现风险**：`ddfOp` 是 `lsumLocFin`，把 `K_m` 移进求和需要一个对
`x` 与 `K_m x` 同时够大的公共窗口。`Fock.towerPairing_ddfOp_left`（`VertexAdjoint.lean:369`）
与 `lie_towerLop_ddfOp_of_pos`（`DDFOperator.lean:332`）里各有一份现成的窗口套路，
照抄即可；`DDFAlgebra.lean` 的 `Finset.biUnion` 技巧在这里用不上（不需要嵌套求和）。

**Mathlib 缺什么**：什么都不缺。这一节纯粹是本仓库既有引理的重新打包。

### A.2 `K` 的物理内容：DDF 态的刻画条件

这是 Goddard 2008 (6.2) 的 Lean 形式，也是 §B 的接口。

```lean
/-- 塔上的真空 `|0; k⟩`，第 0 层的 Fock 真空。 -/
noncomputable def towerVacuum (D : ℕ) (R : Type*) [CommRing R] : TowerFock D R :=
  Finsupp.single 0 (Fock.vacuum D R)

/-- `K_n |0;k⟩ = 0`（`n > 0`）：`K_n` 的每个分量都是湮灭算子。 -/
theorem towerK_apply_towerVacuum_of_pos {n : ℤ} (hn : 0 < n) :
    towerK η a b n (towerVacuum D R) = 0

/-- **`K` 条件的子模** `⨅_{n>0} ker K_n`（Goddard 2008 (6.2)）。 -/
noncomputable def towerKerK (η a b : Fin D → R) : Submodule R (TowerFock D R) :=
  ⨅ n : ℤ, ⨅ _ : 0 < n, LinearMap.ker (towerK η a b n)

/-- **DDF 态满足 `K` 条件**：由 A1.5 加上 `K_n|0;k⟩ = 0`，对 DDF 单项式归纳。
`ddfSpan` 的定义见 §B.2。 -/
theorem ddfSpan_le_towerKerK ... : ddfSpan η a b hη Ε ≤ towerKerK η a b
```

难度：**小**（`towerVacuum` 与 `towerK_apply_towerVacuum_of_pos` 各几行；
`ddfSpan_le_towerKerK` 是 `Submodule.span_le` + 对单项式归纳，中等偏小）。

### A.3 Brower 的 `A^L_n`：建议**不做**，并给出代价估计

若日后要做（例如为了形式化推导 summary 第 (2) 条的原始论证），成本如下：

1. **`k̃` 的引入**：需要第二个类光向量 `k̃`，`dotVec η b b̃ = -1`。当前 `Fock D R` 的度规
   被钉死成对角 `η : Fin D → R`，但 `k̃` 本身只是一个 `Fin D → R` 向量，不需要改度规
   ——这一步反而不难（见 §C.2 的显式见证）。`Ã_n := ddfOp η a b b̃ hη hb̃b n`？
   **不行**：`ddfOp` 的定义**要求** `dotVec η ε b = 0`，而 `dotVec η b̃ b = -1 ≠ 0`。
   局部有限性的上端截断正是靠横向性，所以 `Ã_n` 的模态和**在代数 Fock 空间上不局部有限**，
   `lsumLocFin` 用不了。**这是第一道硬墙**：`Ã_n` 需要一套全新的求和存在性论证
   （文献里靠围道积分，本仓库没有围道）。
2. **`F_n` 的形式化**：(6.6) 含 `1/(k·P(z))`，即要对一个零模可逆、非零模幂零方向的
   算子值形式 Laurent 级数取逆。在本仓库的模型里 `k_0·P(z) = Σ_m K_m z^{-m-1}`，
   `K_0 = 1`（A1.3！），所以几何级数 `(1 + Σ_{m≠0} K_m z^{-m})^{-1}` 逐向量确实有限
   ——但这要新写一套「算子值形式级数的逆 + 逐向量局部有限」的基础设施，
   规模与 `VertexProduct.lean` + `VertexWeightedSum.lean` 相当（两者合计约 700 行）。
3. **中心项的算术校验（写之前先手算）**：(5.7) 的 `m³` 与 (6.5) 的 `2m³` 都不是
   `conv.virasoro-standard` 的形状 `(c/12)m(m²-1)`。把 `A^L_0` 平移常数 `κ` 后
   `(m-n)A^L_{m+n} + (2m³ - 2κm)δ`，要它等于 `(c/12)(m³-m)δ` 得 `c = 24`、`κ = 1`；
   同理 (5.7) 给 `Ã` 的 `c = 12`、`κ = 1/2`。`c = 24` 与 Goddard 自己那句
   「`A^i_n` 与 `A^L_n` 的代数同构于 24 个欧氏振子 `a^i_n` 加它们的 Sugawara `L^a_n`」
   自洽（24 个欧氏振子的 Sugawara 中心荷正是 24）。**这条算术本身值得单独立一条 Lean 引理**
   （`ring` 一行），但它不构成做 `A^L_n` 的理由。

**估计：`A^L_n` 是 1–2 个月的独立项目，且不在无鬼定理第 (1) 条的关键路径上。建议搁置。**

## B. 张成引理（`ddf-spans`）

这是整个工程的核心，也是唯一真正困难的一节。

### B.0 目标陈述

无鬼定理 v4 (1b) 的 Lean 形式（`a₀ = 1`，快子壳 `α'k² = 1`，`D = 26`）：

```lean
/-- **Goddard–Thorn 分解**（Goddard 2008 (6.4)：`|ψ⟩ = |f⟩ + |n⟩`）。 -/
theorem towerPhysSubmodule_le_ddfSpan_sup_null
    (hη : ∀ μ, η μ * η μ = 1) (hbb : dotVec η b b = 0) (hba : dotVec η b a = 1)
    (hshell : invTwo R * Fock.zeroModeSq η a = 1) (hD : D = 26) (Ε : TransverseFrame η b) :
    towerPhysSubmodule η a b 1 ≤ ddfSpan η a b hη Ε ⊔ towerNullSubmodule η a b 1
```

反包含 `ddfSpan ≤ towerPhysSubmodule` **已经有了**（`ddfOp_mem_towerPhysSubmodule` +
真空是物理态 + 对张成集归纳），所以 (1b) 的等距同构等价于上面这一条加上 §C 的正定性。

### B.1 先补的基础设施（与路线无关，一定要做）

### B.3 路线 (ii)：GT 原始的计数论证 —— 可行，但成本不在「计数」上

计数论证的骨架是特征标等式（`φ(q) = ∏_{n≥1}(1-q^n)`）：

```
ch F          = φ(q)^{-D}          （D 个振子的 Fock 空间）
ch U(Vir⁻)    = φ(q)^{-1}
ch R[K_{-n}]  = φ(q)^{-1}
ch H^⊥        = φ(q)^{-(D-2)}
```

于是 `φ(q)^{-1} · φ(q)^{-1} · φ(q)^{-(D-2)} = φ(q)^{-D}`，即

```
U(Vir⁻) ⊗ R[K_{-n}] ⊗ H^⊥  ≅  F      （作为分级向量空间）
```

**这个等式对任意 `D` 成立，`26 = 1 + 1 + 24` 只是 `D = 1 + 1 + (D-2)` 的实例。**
所以**计数一步根本看不见 26**（见 §B.5）。

计数所需的 Lean 件：

### B.4 路线 (iii)：幺三角基变换 —— **推荐**，并且它把 (ii) 的「张成」也一并解决

思路：不做维数计数，直接证「DDF/K/L 单项式」到「振子单项式」的转移矩阵是幺三角的。

**第 1 步：光锥标架下的振子基变换。**

```lean

难度：**中–大**。数学上平凡（多项式变量的可逆线性代换），Lean 上要把

**注意一个结构性限制**：本仓库的 `Fock D R` 把度规钉成对角 `η : Fin D → R` 且假设 `η_μ² = 1`，
**不能**直接改成光锥基（光锥基下度规非对角）。上面的做法是**不动 `Fock` 的定义**，
只在算子层面换基（`towerModeVec η a b v p` 对任意 `v` 都有定义），这是唯一不需要重构

### B.5 `D = 26` 究竟在哪里进来 —— 一条应写进图的数学结论

把 B.3 / B.4 走完，得到的是

```
F ≅ U(Vir⁻) ⊗ R[K_{-n}] ⊗ H^⊥,   ch H_phys = φ(q)^{-(D-1)},   ch H^⊥ = φ(q)^{-(D-2)}
```

**这些对任意 `D` 都成立。** 独立核算（可作为 Lean 里的小 sanity 检查）：
`N = 1`、`a₀ = 1` 时 `H_phys` 是横向极化 `ζ·k = 0`，维数 `D - 1 = 25`
（`mem_physSubmodule_inf_levelSubmodule_one_iff` 已证）；
`span{A^i_{-1}|k⟩ (24 个), K_{-1}|k⟩ (1 个)}` 维数也是 25；零模态是 `L_{-1}|k⟩`（1 维，
`Lop_neg_one_apply_one_mem_nullSubmodule` 已证），`25 - 1 = 24 = p_{24}(1)` ✓。
`N = 2`、`D = 26` 时 `dim H_phys(2) = D(D+1)/2 - 1 = 350 = p_{25}(2)` ✓。

于是**剩下的、也是唯一含 26 的断言**是：

> **(B-26)** `H_phys` 里 `H^⊥` 之外的那 `p_{D-1}(N) - p_{D-2}(N)` 个方向，在 `D = 26` 时恰好是零模态。

等价说法：`H_phys` 上双线性型的秩恰为 `p_{D-2}(N)`。`D < 26` 时秩更大但仍半正定
（这正是 `worldsheet.no-ghost-theorem-subcritical` 只断言正定性、**不**断言与 24 个横向振子
同构的原因）；`D > 26` 时多出的方向有负模（`LevelTwo.lean` 的
`Fock.pairing_levelTwoScalar_intercept_one`：`⟨ψ₂,ψ₂⟩ = -2(D-26)(D-1)/25`，`N = 2` 上的显式见证）。

**两条已知机制，都还没有可形式化的证明：**

* **Brower 机制**：纵向算子 `A^L_{-n}` 生成那些多余方向，其 Gram 正比于 `(26 - D)`，
  `D = 26` 时整体为零。**需要 `A^L_n`**，成本见 §A.3。
* **GT 机制**（Goddard 2008 (6.2)）：物理态再加 `K_n|ψ⟩ = 0`（`n > 0`）就恰好是 DDF 态；
  对一般物理态要减掉一个伪态把 `K` 条件配平，可解性用到 `D = 26`、`a = 1`。
  **Goddard 2008 只给结论 (6.4)，不给证明**（原话是 "we were able to prove the No-Ghost
  Theorem [45]"，[45] = GT 1972，而 GT 1972 正文本项目从未获取，推导 gaps 已记
  「两篇 1972 年论文的正文都未获取……这是本推导目前最大的问题」）。

**对图的建议（重要）**：(B-26) 是整条 GT 链的**真正承重点**，而它现在的文献支撑只有
一篇未获取正文的 1972 年论文里的一句无证明结论。建议在
`worldsheet.no-ghost-theorem-v4--via-goddard-thorn` 的 gaps 里把这一点单独列出来，
措辞不要与已有的「两篇 1972 论文正文未获取」那条合并——那条讲的是**可追溯性**，
这条讲的是**论证结构**：即使拿到正文，形式化仍需在 Brower 机制（要 `A^L`）与 GT 机制
（要一个本项目尚未理解其细节的配平论证）之间做一次选择。

### C.2 假设集的可满足性见证 —— **最便宜、也最该先做的一条**

整个 DDF 岛的每条定理都带 `hη ∧ hbb ∧ hba ∧ hεb`，而仓库里**没有任何一条**证明这套假设
可以同时满足。这不是吹毛求疵：`FockGram.lean` 已经吃过一次亏（`ZMod 2` 上对角元为零的反例
是那一节最有价值的发现之一），而 `VertexAdjoint.lean` 的
`add_self_eq_zero_of_pairing_vertexOsc_same_momentum` 正是同类「审计引理」。

显式见证（`K` 为 ℚ-代数即可；正定性再要有序域）：

```
η  = mostly-plus Minkowski：η_0 = -1，η_μ = 1 (μ ≥ 1)
b  = (1, 1, 0, …, 0)            -- k_0，类光
b̃  = (1/2, -1/2, 0, …, 0)       -- 共轭类光方向
a  = (1/2, 3/2, 0, …, 0)        -- 快子壳上的动量
ε_i = Pi.single i 1  (2 ≤ i ≤ D-1)
```

逐条验算（全部 `Fin` 上的有限和，`decide`/`simp` + `ring` 可做）：

```
b·b  = -1·1·1 + 1·1·1 = 0                      ✓ 类光
b·a  = -1·1·(1/2) + 1·1·(3/2) = 1              ✓ 2α' k_0·k = 1
a·a  = -(1/2)² + (3/2)² = 2，故 α'k² = 1        ✓ 快子壳、a₀ = 1
b·b̃  = -1·1·(1/2) + 1·1·(-1/2) = -1            ✓ 光锥归一
b̃·b̃  = -(1/2)² + (1/2)² = 0                    ✓
ε_i·b  = η_i · 1 · b_i = 0   (i ≥ 2)           ✓ 横向
ε_i·ε_j = δ_ij  且 > 0                          ✓ 横向 Gram 正定
```

```lean
/-- **DDF 假设集非空**：`D ≥ 3` 时存在满足全部四条几何假设的 `(a, b, ε)`，
且横向偏振的 Gram 是单位阵。`D = 26` 时给出 24 个横向方向。 -/
theorem exists_ddf_data (hD : 3 ≤ D) :
    ∃ (a b : Fin D → K) (Ε : TransverseFrame (Fock.minkowski D K) b),
      dotVec (Fock.minkowski D K) b b = 0 ∧
      dotVec (Fock.minkowski D K) b a = 1 ∧
      invTwo K * Fock.zeroModeSq (Fock.minkowski D K) a = 1
```

### C.3 抽象 Heisenberg 族的 Gram —— 关掉 `fock-gram` 记录的缺口 (a)

`FockGram.lean` 的 `pairing_creationMonomial_of_hypotheses` 是图卡
`worldsheet.transverse-ddf-fock-gram-matrix` 的条件版，**但它只在 `Fock D R` 上、只对
`Fock.creation` 实例化**。TODO 的 `fock-gram` 项自己记了这个缺口：
「本文件……**没有**证明 DDF 算子满足 (H1)–(H4)——那是无鬼岛里另一项义务」。

要关掉它，正确做法**不是**把 DDF 算子塞进 `Fock.creation`，而是把 Gram 递推抽象化：

```lean
/-- **抽象 Heisenberg 族的 Gram 矩阵**：只用 CCR + 伴随 + 真空归一化 + 真空湮灭。
这就是图卡 `worldsheet.transverse-ddf-fock-gram-matrix` 的 (H1)–(H4)，
但不预设载体是 `MvPolynomial`。 -/
theorem gram_of_heisenberg_family
    {M ι : Type*} [AddCommGroup M] [Module R M] [DecidableEq ι]
    (B : LinearMap.BilinForm R M) (Ω : M) (A : ι → ℤ → Module.End R M)
    (hccr : ∀ i j (m n : ℤ), ⁅A i m, A j n⁆
        = (if m + n = 0 ∧ i = j then (m : R) else 0) • (LinearMap.id : Module.End R M))
    (hadj : ∀ i (n : ℤ) (v w : M), B (A i n v) w = B v (A i (-n) w))
    (hvac : B Ω Ω = 1)
    (hann : ∀ i (n : ℤ), 0 < n → A i n Ω = 0)
    (d e : (ι × ℕ+) →₀ ℕ) :
    B (heisMonomial A Ω d) (heisMonomial A Ω e)
      = if d = e then ∏ v ∈ d.support, ((v.2 : R) ^ (d v) * (d v)!) else 0
```

要点：

* **(H1)「产生算子互相对易」不是额外假设，是 `hccr` 的推论**：两个指标都为负时
  `m + n ≠ 0`，中心项为零。这一点 `FockGram.lean` 是单独证的（`commute_creation`），
  抽象版里可以省掉。
* 证明结构与 `FockGram.lean` 逐字相同：
  `annihilation_creationMonomial`（Leibniz 一步）→ `pairing_creationMonomial_add_single`
  （伴随给递推）→ 对 `d` 的 level 强归纳。

  即 `FockGram.lean` 的 `foldr_creation_vacuum` 的抽象版。

### B′.5 归纳变量与不变量（β-消元的精确写法）

这是 PR4 的核心，也是整条计划里唯一真正的归纳。

* **对象**：光锥单项式 `lcMonomial F d`，`d : (Fin D × ℕ+) →₀ ℕ`，`level d = N`，放在 rung `-N`。
* **两个次数**：`β d :=` `d` 在 `b̃` 那一行的总次数（`∑_n d (idx b̃, n)`）；
  `ω d :=` `b̃` 行的**加权**次数（`∑_n n · d (idx b̃, n)`），`0 ≤ ω d ≤ N`。
* **归纳变量**：单个自然数 `μ d := β d * (N + 1) + ω d`（`Nat.strong_induction_on`）。
* **不变量**：`lcMonomial F d ∈ conjFreeSlice F N ⊔ towerSpuriousSubmodule η a b`。
* **归纳步**：`β d = 0` 平凡。`β d ≥ 1` 时取一个 `b̃` 因子 `ũ_n`，写 `d = d' + single (idx b̃, n) 1`，
  用 `towerLop_neg_conjDegree_leading` 把 `ũ_n · m(d')` 表成
  ```
  ũ_n · m(d') = -L_{-n}(m(d')) - Σ_{l=1}^{n-1} u_{n-l} ũ_l · m(d') + (β ≤ β d' 的项)
  ```
  三类右端项：`L_{-n}(m(d'))` **是伪态**（`towerLop_neg_mem_towerSpuriousSubmodule`）；
  `u_{n-l} ũ_l · m(d')` 的 `β` 不变而 `ω` 严格变小（`l < n`）⇒ `μ` 严格变小；
  末项 `β` 严格变小（= `β d'`）而 `ω ≤ N` ⇒ `μ` 严格变小。
* **为什么这个测度是对的**：`L_{-n}` 在光锥变量下最多把 `b̃`-次数升 1，升 1 的部分是
  乘以 `ũ_n + Σ_{l<n} u_{n-l} ũ_l`；这一族乘法算子对 `ω` 是幺三角的（领头项 `ũ_n`），
  而 `ω` 在固定 level 下有界，所以三角化终止。**这正是 §B.4 第 3 步「幺三角」的正确位置**：
  它不在「DDF/K/L 单项式 → 振子单项式」的转移矩阵上（那需要线性无关与行列式），
  而在**单个乘法算子族**上（只需要张成）。

### B′.8 计数：需要的恒等式究竟是什么（订正）

* §B.3 的特征标恒等式 **`φ(q)^{-D} = φ(q)^{-1} · φ(q)^{-1} · φ(q)^{-(D-2)}`** 是对的，
  两个 `φ^{-1}` 分别是 **Virasoro 塔**与 **K 塔**。**不要**写成 `φ^{-(D-2)} = φ^{-D}(1−q)^2`：
  那只对应 `n = 1` 模态，是错的。正确形式是 `φ^{-(D-2)} = φ^{-D} · φ · φ`，`φ = ∏_{n≥1}(1−q^n)`。
* **这个恒等式对任意 `D` 成立，所以计数一步永远看不见 26**（§B.5 的结论不变）。
  真正含 `D` 的量是 `p_{D−1}(N) − p_{D−2}(N)`（必须被零态吃掉的方向数），它对任意 `D`（`N ≥ 2`）都非零；
  **26 决定的是零态够不够多**，不是这个差本身。
* `N = 2` 的独立核算（`LevelTwoSpan.lean` 的 Gaps 记的那组数）在一般 `D` 下是：
  `dim(H_phys ∩ 片) = p_{D−1}(2) = (D−1)(D+2)/2`（`D = 26` 时 350）；
  `dim(DDF ∩ 片) = p_{D−2}(2) = (D−2)(D+1)/2`（324）；
  伪态生成元 `D + 1` 个（27），其中零态 `D` 个（26）。`350 = 324 + 26` ✓。
  **注意 `2p_{D−1}(2) − p_{D−2}(2) − p_D(2) = −1` 对一切 `D` 成立**，
  所以任何「二阶差为正」式的不等式都不是 26 的来源。
* **Lean 里不要求值任何分拆数**：(P2)(P3) 两边都是指标集的 `Fintype.card`，
  两者之差由「`Fin (D−2) ↪ Fin (D−1)`，余集 = 含 `u` 的单项式」给出显式单射，
  永远不需要 `p_c(N)` 的闭式。`Math/PartitionCard.lean` 只在 (B-26) 形式 (iii) 的**种子计数**
  （普通分拆 `p(m)`）里用得上，而那正是它能算的（`m ≤ 5`）。
  `Math/EulerPartition.lean` 的 `φ^{-1}` 生成函数在本路线上**用不到**（没有一步需要形式幂级数）。

### B″.2 手算基准：`N = 2` 的完整账，与 `D = 26` 唯一进入的那个方程

```
p·p = a·a − 4 a·b + 4 b·b = 2 − 4 + 0 = −2 ,      h := ½ p·p = −1 = a₀ − 2  （a₀ = 1）
```

片 `V_2` 的伪态由 **`D + 1` 个生成元**张成（`towerSpuriousSubmodule` 的 `n = 1, 2` 两段；
`n ≥ 3` 因为落不进 level 2 而不贡献）：

χ_v := L_{-1} (v·α_{-1}) |p⟩ = (v·α_{-2})|p⟩ + (v·α_{-1})(p·α_{-1})|p⟩ ,   v ∈ K^D
χ_0 := L_{-2} |p⟩          = (p·α_{-2})|p⟩ + ½ Σ_μ η_μ (α^μ_{-1})² |p⟩
```

（第一式就是已有的 `Fock.Lop_neg_one_apply_polState`；第二式是 `Fock.Lop_neg_two_apply_one`。
两者都已在 Lean 里，这是本小节能被廉价复算的原因。）这 `D + 1` 个向量线性无关：
`χ_v` 的 `α_{-2}` 分量对 `v` 单射，而 `χ_0` 的 `η`-迹项 `Σ_μ η_μ (α^μ_{-1})²`
不在 `{(v·α_{-1})(p·α_{-1})}` 的张成里（`D ≥ 2`）。

**伪态上的 Gram**（三条，逐条只用一次对易子）：

```
⟨χ_v, χ_u⟩ = ⟨(v·α_{-1})|p⟩ , L_1 L_{-1}(u·α_{-1})|p⟩⟩
           = ⟨v·α_{-1} , 2L_0 (u·α_{-1})|p⟩ + L_{-1}(u·p)|p⟩⟩
           = (u·p)(v·p)                                   （2L_0 那一项的本征值 h+1 = 0）
⟨χ_v, χ_0⟩ = ⟨v·α_{-1} , 3 L_{-1}|p⟩⟩ = 3 (v·p)          （[L_1, L_{-2}] = 3L_{-1}）
⟨χ_0, χ_0⟩ = 4h + c/2 = c/2 − 4                           （[L_2, L_{-2}] = 4L_0 + c/2）
```

于是在坐标 `(v, t) ↦ χ_v + t χ_0` 下

```
G((v,t),(u,s)) = (v·p)(u·p) + 3t(u·p) + 3s(v·p) + (c/2 − 4) t s
```

**这是一个秩 ≤ 2 的型**（它只通过两个线性泛函 `v ↦ v·p` 与 `(v,t) ↦ t` 看参数）。
把它限制在二维子空间 `span{(p,0), (0,1)}` 上：

```
        ⎡ (p·p)²   3(p·p) ⎤   ⎡  4   −6 ⎤
  G₂ =  ⎣ 3(p·p)   c/2−4  ⎦ = ⎣ −6  c/2−4 ⎦ ,      det G₂ = 4(c/2 − 4) − 36 = 2(c − 26)
```

⭐ **`(p, 0)` 就是 `L_{−1}²|p⟩`，`(0,1)` 就是 `L_{−2}|p⟩`，所以 `G₂` 逐字是
`span{L_{−2}|p⟩, L_{−1}²|p⟩}` 上的 Kac/Shapovalov 二阶 Gram**，
而 `det G₂ = 2(c − 26)` 与本仓库已有的 `kacDet2` 完全一致：

```
kacDet2 c h = 2h(16h² + 2h(c−5) + c)        （Virasoro/FockFreeLowLevel.lean:292）
kacDet2 c (1 − 2) = 2(c − 26)               ⟨手算，`ring` 一行可验⟩
```

**结论（`N = 2`）**：`rank G = 2` 当 `c ≠ 26`，`rank G = 1` 当 `c = 26`
（后者因为 `c/2 − 4 = 9 = 3·3` 使 `G` 分解成 `(v·p + 3t)(u·p + 3s)`）。故

```
r_2 := dim(S_2 ⊓ H_2) = (D + 1) − rank G = D   当 D = 26 ；= D − 1   当 D ≠ 26
p_{D−1}(2) − p_{D−2}(2) = D                    （对一切 D）
```

⇒ ⭐ **`B26 2` 与 `D = 26` 等价**。这是整条链上第一处、也是唯一一处
能把「`D = 26`」写成一个**方程**而不是一个假设的地方。`D = 26` 时 `350 = 324 + 26` ✓
（`350 = p_{25}(2)`、`324 = p_{24}(2)`），与 §B′.8 的独立核算一致。

### B″.11 三个最可能的断点

1. ⭐ **（最致命）两族零态在 `N ≥ 5` 处的重叠，恰好是 Euler 五边形数。**
   ⟨手算⟩ 记 `U := L_{-1}(Q_{N-1})`、`W := 𝒟₂(Q_{N-2})`。由 B″.4.1，
   `dim U ≤ p_{D−1}(N−1)`、`dim W ≤ p_{D−1}(N−2)`，而目标是

   ```
   p_{D−1}(N) − p_{D−2}(N) = [q^N] φ^{-(D-1)}(1 − φ) ,   1 − φ = q + q² − q⁵ − q⁷ + q¹² + q¹⁵ − ⋯
   dim U + dim W           = [q^N] φ^{-(D-1)}(q + q²)
   ```

   两者在 `N ≤ 4` **恰好相等**（`D = 26` 数值核对：`N=2: 25+1 = 26`；`N=3: 350+25 = 375`；
   `N=4: 3575+350 = 3925 = 29575 − 25650` ✓），从 **`N = 5`** 起 `dim U + dim W` 比目标
   **多出** `p_{D−1}(N−5) + p_{D−1}(N−7) − p_{D−1}(N−12) − ⋯`（`N = 5` 时多出 `1`）。
   ⇒ **要得到 `dim(U + W) ≥ 目标`，必须给 `dim(U ⊓ W)` 一个上界，而那个上界恰是五边形数修正。**
   这等价于 `⋯ → Q_{N-5} ⊕ ⋯ → Q_{N-1} ⊕ Q_{N-2} → Z_N → 0` 正合，
   即 `c = 26`、`h = 1−N` 处 Verma 模的 BGG / Feigin–Fuks 嵌入结构。
   **这是一个独立的大项目，不是 PR5c 的技术细节。**
   两条绕法（都未验证）：
   (i) 不算维数，直接证**张成** `H_N ≤ D_N ⊔ U ⊔ W`——但这几乎就是 (B-26) 本身换了个写法；
   (ii) ⭐ **换一族按指标构造的种子**：`p_{D−1}(N) − p_{D−2}(N)` 既数「含至少一个 `b` 因子的
       `b̃`-free 占据函数」，也数「不含 `b`、含至少一个 `b̃` 的占据函数」；
       而 PR4 的领头项引理 `α^{b̃}_{-n} m(d′) = −L_{-n} m(d′) + (更小测度)`
       正是把后者与伪态联系起来的三角关系。若能对每个「含 `b̃`」指标造出一个零态、
       并用**与 `C_N` 的配对矩阵的三角性**证独立（而不是用维数相减），
       重叠问题就不出现。**这是本节认为最值得先试的绕法**，且它与 PR5a 的基结构相容。
2. **把 PR4 的消元从反对角线推广到任意 rung，可能比想象贵。**
   `conjFreeSlice hD F N` 把 rung 写死成 `Finsupp.lsingle (-(N:ℤ))`
   （`SpuriousElimination.lean:264`），`towerBigrade_le_conjFreeSlice_sup_towerSpurious`
   也只在 `(-N, N)` 上陈述。PR4 订正第 11 条说机制与 rung 无关（`b̃` 分量恒为 `−1`），
   所以数学上没有障碍；但那是一个 **85 条声明、1300 行**的文件，重参数化要动很多条。
   **缓解**：按 B″.1 的记号约定，把这些引理改写在 `Fock` 层（动量 `p`，假设 `dotVec η b p = 1`），
   塔版作为推论。若成本超过 400 行，退而只推广 `Q_{N−1}`、`Q_{N−2}` 需要的那两条。
3. **排序引理在 `Finsupp` 指标上的实现。**
