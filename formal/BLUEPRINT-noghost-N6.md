## 1. 精确问题陈述：`N ≥ 6` 的开放内容 = 一条**核的上界**

### 1.1 把开放内容写成核界

两族合并映射（种子版，`Q × Q`）

```
T_N|_{Q×Q} : Q_{N−1} × Q_{N−2} → V_N ,   (φ, ψ) ↦ L_{−1}φ + 𝒟₂ψ .
```

秩–零化度（`L_{−1}` 在片上单射 [Lean `towerLop_neg_one_injective`]）给

```
dim(U + W) = dim Q_{N−1} + dim Q_{N−2} − τ_N ,     τ_N := dim ker(T_N|_{Q×Q}) .
```

由 `U, W ⊆ Z_N` 得 `dim Z_N ≥ dim(U + W) = p_{D−1}(N−1) + p_{D−1}(N−2) − τ_N`。代入 `B26 N`
要求的下界 `dim Z_N ≥ p_{D−1}(N) − p_{D−2}(N)`，得到一条**充分条件**：

```
(★)   τ_N  ≤  τ_N^目标 := p_{D−1}(N−1) + p_{D−1}(N−2) − p_{D−1}(N) + p_{D−2}(N) .
```

`ker(T_N|_{Q×Q})` 与任务书里的 `dim(U ⊓ W)` 的关系：⟨analysis 2026-09-14⟩ 映射
`ker → U ⊓ W, (φ,ψ) ↦ L_{−1}φ` 满射，核是 `{(0,ψ) : 𝒟₂ψ = 0} = 0 × ker(𝒟₂|_{Q_{N−2}})`，故

```
dim(U ⊓ W)  =  τ_N − dim ker(𝒟₂|_{Q_{N−2}})  ≤  τ_N ,
```

期望 `𝒟₂` 在种子上单射（则等号）。用于 `(★)` 记账的是 `τ_N`；「重叠核界 dim(U ⊓ W) ≤ κ_N」这句话
里应理解成 `τ_N ≤ κ_N`，两者相差一个期望为零的 `ker(𝒟₂|Q)`。下面统一用 `τ_N`。

### 1.2 已 formalized 的**粗**核界 `κ_N`（整片、`D`-无关）

## 2. 为什么 `N = 5` 的纯计数在 `N ≥ 6` 失效：种子条件必须进核的估计

### 2.1 失效的算术定位

缺口

```
κ_N − τ_N^目标 = Σ_{|k| ≥ 2} (−1)^k [ p_D(N − g_k) − p_{D−1}(N − g_k) ] .
```

`⟨analysis 2026-09-14⟩` `p_D(M) − p_{D−1}(M)` = 恰用到第 `D` 种颜色的 `M`-分拆数，`M = 0` 时为 `0`、
`M = 1` 时为 `1`，从 `M = 1` 起非零。领头项 `k = ±2` 给 `g = 5, 7`：

* `N = 5`：`N − 5 = 0`，`p_D(0) − p_{D−1}(0) = 1 − 1 = 0` ⇒ **缺口 = 0**（两 shadow 首项都是「常数 1」，看不出颜色数）。
* `N = 6`：`N − 5 = 1`，`p_D(1) − p_{D−1}(1) = D − (D−1) = 1` ⇒ **缺口首次 = 1**（`κ₆ = 26 > τ₆ = 25`）。

⇒ **`N = 6` 是「颜色数第一次进入」的能级**：整片核 `κ_N` 数的是 `V×V`（`D` 色）上的核对，
`B26 N` 只关心 `Q×Q`（种子，`D−1` 色）上的核对，后者严格更少。`N = 5` 处两者恰好相等纯属首项巧合。

### 2.2 「种子条件」是什么，机制如何

**种子条件**：`Q_{j,M} := towerBigrade(j,M) ∩ ⋂_{n≥1} ker L_n`，即被**全部正模湮灭**（准物理，
`§B″.4.1`、`ocq-null-state-two-families` (1)(2) 的定义域）。它把 level-`M` 片从 `dim V_M = p_D(M)`
（`D` 色光锥单项式）压到 `dim Q_M = p_{D−1}(M)`（`b̃`-free，少一种颜色）。

整片核 `κ_N` 用 `V_{N−1} × V_{N−2}`（全片，`b̃` 可任意出现）；种子核 `τ_N` 只允许 `φ, ψ ∈ Q`。
**必须把「`φ, ψ` 被正模湮灭」用进核的估计**，才能把 `D`-shadow 收紧成 `(D−1)`-shadow。

机制（`⟨analysis 2026-09-14⟩`，把 §B⁗.7 的路线判断落实成因果链）：核 `ker T_N` 由
**`U(Vir⁻)` 的 syzygy** 生成（§B⁗.2、§B⁗.7），syzygy 是「同一个负模组合被 `L_{−1}·(⋯)` 与
`𝒟₂·(⋯)` 两种方式写出」。种子条件通过下面这条转化进核：

```
τ_N = dim { (u, w) ∈ V_{N−5} × V_{N−7} × ⋯ :  S_N(u, w) ∈ Q_{N−1} × Q_{N−2} }
```

其中 `S_N` 是 syzygy 生成映射（§B⁗.7 第 1 步，`range S_N ≤ ker T_N`）。要证 `τ_N ≤ τ_N^目标`
等价于「`S_N(u,w)` 落在种子里 ⟹ `(u,w)` 落在低一层的种子里」——一条 `L_1, L_2` 与 syzygy 算子
`(x₄, y₃, …)` 的对易子计算。**正是这一步把「被正模湮灭」的信息注入，从而把颜色数从 `D` 降到 `D−1`。**

### 3.2 嵌入图：链 / 辫 / 岛 分类（文献）

Virasoro Verma 模 `V(c,h)` 的**嵌入图**（embedding diagram）画出最高权向量与所有奇异向量
（每层至多一个，唯一到差常数——这是 Feigin–Fuks 嵌入图定理的直接推论 ⟨lit, 待核⟩），
用箭头连「低层奇异向量可经 Virasoro 作用打到高层奇异向量」。分类（Feigin–Fuks「I–II–III 型」，
现代统一表述见 Iohara–Koga *Representation Theory of the Virasoro Algebra*，Springer 2011，
Ch. 5–6「Verma Modules I & II：结构定理」；另 Kac–Raina）：

* **Verma 模**：若指标满足某种整除关系，嵌入呈**链**（chain，线性、单股，有时有限截断）；
  否则呈**辫**（braid，双股交织的梯形），一般情形是辫。
  「Verma L-模的每个非零子模要么是 Verma 模，要么是两个 Verma 模之和」是嵌入图的结构推论 ⟨lit, 待核⟩。

**`c = 26` 的定位（`⟨analysis 2026-09-14⟩` + `⟨lit, 待核⟩`）**：`c = 26 > 25`，`b² = 3/2` 为正有理数，

  处 `κ_N > τ_N`（上界问题）」是**两个不同层次**的门槛（见 §3.6）。

### 3.6 两个门槛不要混淆（`⟨analysis 2026-09-14⟩`，本项目多卡已反复强调）

## 6. 诚实裁决

`⟨analysis 2026-09-14⟩` 综合以上：

### 6.1 表示论（Feigin–Fuks / BGG） vs 继续初等构造

**推荐：继续初等构造（§4.3 / §5 的 `L_1/L_2` 对易子路线），不建一般 Feigin–Fuks / BGG 理论。** 三条理由：

1. **方向对**。`B26 N` 要的是**种子核** `τ_N ≤ (D−1)`-shadow；BGG 正合性给的是**整片核**紧性
   `dim ker = κ_N`（`D`-shadow）——太重且不是所需之物（§4.2）。§B⁗.4 对账表已把「`N=5` 需要 BGG
   正合性」这句 §B″.11 的过强断言订正为「只需正合序列的一半，且那一半是纯计数」。
2. **`N = 5` 的先例**。§B⁗ 证明了 `N = 5` 完全不需要 BGG：`κ₅ = τ₅ = 1`，重叠的显式生成元
   `(x₄, y₃)` 手算即得。`N = 6` 只差把种子条件用进核（一条 level-1 转移引理），**没有原则障碍**
   要动用一般嵌入图理论。
3. **表示论只在「想证上界紧」时才需要**，而 `B26 N` 只需上界，不需紧性。§3 的 Feigin–Fuks 图景
   （嵌入图、五边形影子、`c=26` 自对偶）是**理解**为什么障碍长成五边形数的正确语言，也是给图卡写
   `notes` 的正确框架，但**不是形式化关键路径上的必需前置**。

⚠ **但有一条真实风险**（`⟨analysis 2026-09-14, 自我攻击⟩`）：§4.3 的种子转移引理「`S_N(u,w) ∈ Q ⟹
(u,w) ∈ Q`」在 `N ≥ 7` 是否对所有 `N` 一致成立、`S_N` 是否单射，§B⁗.7 明确标为「未验证的路线判断」。
若这条一致的转移引理在某个 `N` 失败，才可能真的被迫回到 Feigin–Fuks 的结构结果。**建议先做 `N = 6`
（最便宜、level-1、必成），用它验证路线，再决定 `N ≥ 7` 是否沿用。**
