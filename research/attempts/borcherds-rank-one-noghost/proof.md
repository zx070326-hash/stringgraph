## 1. 本文件研究的特化：`D=2`（退化情形，无横向自由度）

`D=2` 时 `𝔥 = span(a,b)` 自己，没有额外的横向坐标。这是 P1 在其自身陈述里允许的一个**合法特例**
（P1 的陈述对一般 `D` 成立，`D=2` 只是取 `D` 最小；`claim.md` 里额外要求的 `(D26)` 是给 Thm 5.1′
用的，不是 P1 陈述本身的前件——见 `scoping.md` 616 行，P1 的记号栏没有限定 `D`）。

**记号**：`e_+ := a-b`。直接计算：`η(e_+,e_+) = η(a,a)-2η(a,b)+η(b,b) = 2-2+0 = 0`；
`η(b,e_+) = η(b,a)-η(b,b) = 1-0 = 1`。即 `{b,e_+}` 是一组双曲对，张成 `𝔥` 全体（`D=2`）。

`Kt_n := e_+·α_n`（`K_n` 的"缺失的共轭"）。由自由玻色子对易关系与 `η` 的值：

```
[K_m, Kt_n] = m·η(b,e_+)·δ_{m+n,0} = m·δ_{m+n,0}      （所有 m,n∈Z）
[K_m, K_n]  = m·η(b,b)·δ_{m+n,0}  = 0
[Kt_m,Kt_n] = m·η(e_+,e_+)·δ_{m+n,0} = 0
```

零模：`K_0 = η(b,v_j) = η(b,a)+jη(b,b) = 1`（对一切 `j` 恒成立，由 (S)(N)）；
`Kt_0 = η(e_+,v_j) = η(a,a)+jη(a,b)-η(a,b)-jη(b,b) = 2+j-1 = j+1 =: x`（自由参数，`x∈Z`
对应塔上的层，但下面的证明对任意 `x∈R` 成立，不需要整数性）。

`F_hl(v_j)`：由 `{K_{-n},Kt_{-n} : n≥1}` 自由生成的 Fock 空间（在 `D=2` 时 `F(v_j)=F_hl(v_j)`
恰好没有横向因子）。层 `M` 的维数 = 2 色配分数 `p_2(M)`。

**引理 0（Sugawara 限制到 `𝔩`）**：`L_m^{𝔩} := (1/2)Σ_n :α_{m-n}^𝔩·α_n^𝔩:`。用双曲对分解
`α_p^𝔩 = Kt_p·b + K_p·e_+`（因为 `η(α_p,e_+)=Kt_p`、`η(α_p,b)=K_p`，`{b,e_+}` 双曲对的展开公式），
代入内积：

```
α_p^𝔩·α_q^𝔩 = Kt_pKt_qη(b,b) + Kt_pK_qη(b,e_+) + K_pKt_qη(e_+,b) + K_pK_qη(e_+,e_+)
            = K_qKt_p + K_pKt_q
```

代入 Sugawara 和并对第二项换指标 `n↦m-n`（`:AB:=:BA:` 对正规序乘积恒成立）：

```
L_m^𝔩 = (1/2)[Σ_n:K_{m-n}Kt_n: + Σ_n:Kt_{m-n}K_n:] = Σ_n :K_{m-n}Kt_n:
```

（`D=2` 时无横向项，`L_m=L_m^𝔩`。）记 `L_{-m} = Σ_n :K_{-m-n}Kt_n:`（`m≥1`）。

## 2. 基本对易子（从头导出，不引用未证的"标准 CFT 事实"）

**引理 1**：`[L_p, K_n] = -n·K_{p+n}`，`[L_p, Kt_n] = -n·Kt_{p+n}`（对一切 `p,n∈Z`）。

*证明*。用恒等式 `[:AB:,C] = :[A,C]B: + :A[B,C]:`——此式对我们的情形是**精确**成立（非仅"标准做法"）：
`A=K_{p-r}`、`B=Kt_r` 都是振子的线性函数，`[A,C]`、`[B,C]`（`C=K_n` 或 `Kt_n`）都是**纯数**
（振子代数是 Heisenberg 型，两个线性算子的对易子必为中心元），故 `:[A,C]B:=[A,C]B`（纯数乘算子，
正规序无作用），恒等式退化为普通的莱布尼茨对易子公式 `[AB,C]=[A,C]B+A[B,C]`，而正规序与原始乘积
只差一个纯数（对易子不受影响）。于是：

```
[L_p,K_n] = Σ_r [:K_{p-r}Kt_r:,K_n] = Σ_r{[K_{p-r},K_n]Kt_r + K_{p-r}[Kt_r,K_n]}
          = Σ_r K_{p-r}·(-n·δ_{r,-n})     （[K,K]=0，[Kt_r,K_n]=-[K_n,Kt_r]=-nδ_{n+r,0}）
          = -n·K_{p+n}
```

同理 `[L_p,Kt_n] = Σ_r[K_{p-r},Kt_n]Kt_r = Σ_r(p-r)δ_{r,p+n}Kt_r = -n·Kt_{p+n}`。∎

（核对：这与 Borcherds 自己写的 `[L_i,K_j]=-jK_{i+j}`——`scoping.md` D1，**[B-逐字, E5]**——
指标形式逐字一致，是一个独立的交叉验证。）

**引理 2（真空公式）**：对 `m≥1`，

```
L_{-m}|0;v_j⟩ = Kt_{-m}|0⟩ + x·K_{-m}|0⟩ + Σ_{s=1}^{m-1} K_{-(m-s)}Kt_{-s}|0⟩
```

（`m=1` 时求和为空，即 `L_{-1}|0⟩ = Kt_{-1}|0⟩ + x·K_{-1}|0⟩`。）

*证明*。逐项分析 `L_{-m}|0⟩=Σ_{r∈Z}:K_{-m-r}Kt_r:|0⟩` 中哪些 `r` 给出非零贡献：

- `r>0`：`Kt_r` 是湮灭算子（正整数模），直接杀真空，贡献 0。
- `r=0`：`:K_{-m}Kt_0:|0⟩ = x·K_{-m}|0⟩`（`Kt_0=x` 是纯数）。
- `r=-s`，`0<s<m`：两个因子指标都是负的（`K` 因子指标 `s-m<0`，`Kt` 因子指标 `-s<0`），
  都是产生算子，正规序无操作，贡献 `K_{-(m-s)}Kt_{-s}|0⟩`。
- `r=-m`：`K` 因子指标为 `0`，即 `K_0=1`（纯数），贡献 `Kt_{-m}|0⟩`。
- `r=-s`，`s>m`：`K` 因子指标 `s-m>0` 是湮灭算子，`Kt` 因子指标 `-s<0` 是产生算子，正规序把
  湮灭放右边：`:K_{s-m}Kt_{-s}: = Kt_{-s}K_{s-m}`，作用于真空先湮灭再产生，`K_{s-m}|0⟩=0`，贡献 0。

汇总 `r=0`、`r=-m`、`r=-s(0<s<m)` 三类非零贡献即得引理断言。∎

## 3. 关键引理：Claim ★（`Kt` 的产生算子可以被 `{L,K}`-单项式"吸收"）

记 `S := span_R{L_{-m_1}⋯L_{-m_s}K_{-n_1}⋯K_{-n_t}|0;v_j⟩ : s,t≥0, m_i,n_i≥1}`
（即 P1 在 `D=2`、`T_j⊇{|0⟩}` 特殊情形下要证张成一切的那个空间）。

**Claim ★**：对每个 `k≥1`，`S` 在 `Kt_{-k}` 的乘法作用下封闭，即 `Kt_{-k}·S ⊆ S`。

*证明*。由线性性，只需对 `S` 的生成元（长度为 `ℓ≥0` 的 `{L,K}`-单项式作用在 `|0⟩` 上的向量 `w`）
证明 `Kt_{-k}w ∈ S`，对**每个 `k≥1` 同时**做长度 `ℓ` 上的强归纳（这个"每个 `k` 同时"的加强是必需的，
见下面 `G=L_{-m}` 分支）。

**预备事实（产生算子两两对易）**：`K_{-a}`、`Kt_{-b}`（`a,b>0`）互相之间总是对易——
`[K_{-a},K_{-a'}]=0`、`[Kt_{-b},Kt_{-b'}]=0` 恒成立；`[K_{-a},Kt_{-b}]=(-a)δ_{-a-b,0}`，
而 `-a-b<0`（`a,b>0`）永不为零，故也是 `0`。所以 `Kt_{-k}` 乘一个产生算子单项式，就是把
`Kt_{-k}` 这个因子插入该单项式的（作为集合/多重集看待的）任意位置，不产生额外的重排纯数——
这就是把 `Kt_{-k}·w`（`w` 是任意产生算子单项式）解释为"多加一个因子"而非"算子复合"的合法性来源。

**基础 `ℓ=0`**（`w=|0⟩`，对一切 `k` 同时证）：对 `k` 做第二层强归纳。假设对一切 `1≤s<k`
已有 `Kt_{-s}|0⟩∈S`（`k=1` 时此假设为空）。引理 2 给：

```
Kt_{-k}|0⟩ = L_{-k}|0⟩ - x·K_{-k}|0⟩ - Σ_{s=1}^{k-1} K_{-(k-s)}·(Kt_{-s}|0⟩)
```

右边：`L_{-k}|0⟩,K_{-k}|0⟩∈S`（长度 1 的生成元本身）；求和里每项 `Kt_{-s}|0⟩∈S`
（内层归纳假设，`s<k`），而 `S` 对"左乘任意生成元 `K_{-(k-s)}`"自动封闭（把 `K_{-(k-s)}`
接到已经是 `{L,K}`-单项式-线性组合的向量上，逐项接长即可，仍是 `{L,K}`-单项式的线性组合）。
故 `Kt_{-k}|0⟩∈S`。内层归纳完成，基础情形对一切 `k≥1` 成立。

**归纳步 `ℓ≥1`**：设对长度 `ℓ-1`（对一切 `k'≥1` 同时）已证。设 `w=G·w'`，`w'` 长度 `ℓ-1`，
`G∈{K_{-n}(n≥1), L_{-m}(m≥1)}`。固定任意 `k≥1`：

*(a) `G=K_{-n}`*：`Kt_{-k}` 与 `K_{-n}` 都是产生算子，互相对易（预备事实），故
`Kt_{-k}K_{-n}w' = K_{-n}(Kt_{-k}w')`。由归纳假设（长度 `ℓ-1`，同一个 `k`）`Kt_{-k}w'∈S`，
再左乘生成元 `K_{-n}` 仍在 `S`（封闭性）。

*(b) `G=L_{-m}`*：引理 1 给 `[L_{-m},Kt_{-k}]=-(-k)Kt_{-m-k}=k·Kt_{-(m+k)}`，故
`[Kt_{-k},L_{-m}]=-k·Kt_{-(m+k)}`，于是

```
Kt_{-k}L_{-m}w' = [Kt_{-k},L_{-m}]w' + L_{-m}(Kt_{-k}w') = -k·Kt_{-(m+k)}w' + L_{-m}(Kt_{-k}w')
```

第二项：归纳假设（长度 `ℓ-1`，同一个 `k`）给 `Kt_{-k}w'∈S`，左乘生成元 `L_{-m}` 仍在 `S`。
第一项：归纳假设在长度 `ℓ-1`、**另一个值 `k'=m+k`**（`≥1`）下给出 `Kt_{-(m+k)}w'∈S`——
**这正是需要"对每个 `k` 同时"归纳的原因**：只对固定 `k` 做归纳无法在这一步闭合，因为它需要
一个不同的 `k'` 值在同一深度 `ℓ-1` 上的结论。

两项都在 `S`，故 `Kt_{-k}w∈S`。这对任意 `k≥1` 成立，完成长度 `ℓ` 的归纳步。∎

## 4. 定理 A（P1 在 `D=2` 情形的完全证明）

**定理 A**：设 `D=2`（`𝔥=span(a,b)`），则对一切 `j∈Z`（等价地，一切 `x=j+1∈R`——证明对任意
`x∈R` 成立，不需要整数性）、一切能级 `M≥0`，

```
S = F_hl(v_j)     （S 定义见 §3；F_hl 的层-M 维数 = p_2(M)，2 色配分数）
```

即 `{L_{-m},K_{-n}}`-单项式作用在 `|0;v_j⟩` 上张成整个 Fock 空间。特别地，`P1` 在 `D=2`
情形下无条件成立（`T_j⊇{c|0⟩:c∈R}` 已足够，不需要知道 `T_j` 是否更大——见推论 B）。

*证明*。`F_hl(v_j)` 由（作为向量空间，按 Fock 空间的 PBW 基）一切"产生算子单项式"
`K_{-n_1}⋯K_{-n_t}Kt_{-k_1}⋯Kt_{-k_r}|0⟩`（`r,t≥0`，指标 `≥1`）张成。对 `Kt`-因子个数 `r`
做归纳，证明每个这样的单项式 `μ∈S`：

- `r=0`：`μ=K_{-n_1}⋯K_{-n_t}|0⟩` 本身就是（`t`个 `K`、`0`个 `L` 的）`{L,K}`-单项式，
  按定义 `∈S`。
- `r≥1`：写 `μ=Kt_{-k_1}·w'`，`w':=K_{-n_1}⋯K_{-n_t}Kt_{-k_2}⋯Kt_{-k_r}|0⟩` 恰有 `r-1` 个
  `Kt`-因子，归纳假设给 `w'∈S`（作为 `S` 的具体单项式生成元，或退一步只需 `w'` 是 `S` 中元素，
  由 Claim ★ 对 `S`（一个 `R`-子空间，Claim★ 已由线性性推广到全体 `S`，不止生成元）的封闭性，
  `Kt_{-k_1}w' = μ ∈ S`。

对 `r` 归纳完成，一切产生算子单项式 `∈S`，故 `S⊇` 一组张成 `F_hl(v_j)` 的集合，`S=F_hl(v_j)`。∎

**范围说明**：整个证明（引理 1、2、Claim★、定理 A）没有用到任何除法（系数只出现整数
`m,n,k,s` 与自由参数 `x`），故对**任意特征 0（甚至只需交换环，因为唯一"分母"是概念上的
`R`-线性张成，不涉及求逆）**上的 `R` 成立，对**一切 `x∈R`**成立（不需要 `x` 是整数、不需要
`x` 泛性）。这与本轮 sandbox 脚本 `research/sandbox/rank2-core-check.py` 的穷举结果
（`M=0..6`，`x∈{0,±1,±2,3,5,1/2,-1/3}`，全部满秩）完全吻合，是同一个事实的两种独立核验
（脚本先于手证，手证解释了脚本为什么总是满秩）。

## 5. 推论 B：`D=2` 情形下 `T_j = R·|0⟩`（计算验证，未手证一般情形）

`T_j`（`§0` 定义）在 `D=2` 情形显然包含 `R|0⟩`（`L_m|0⟩=0` 是标准最高权事实——`m>0` 时
Sugawara和里唯一可能不消失的项需要产生算子撞真空，`m≥1` 时不存在这种项；`K_i|0⟩=0`
`i>0` 时同理）。**是否 `T_j` 恰好等于 `R|0⟩`，不多不少**，是一个独立于定理 A 的问题
（定理 A 只用了 `|0⟩∈T_j`，不需要 `T_j` 的上界）——这对应 Borcherds Lemma 5.3 的图景
（`T≅Ve^r`，即"每个动量恰好一维"）在本退化情形的具体形状。

**计算结果**（`research/sandbox/rank2-core-check.py` 的 `Tj_hl_dimension` 函数）：对
`M=1,2,3,4` 和 `x∈{0,1,-2,1/2}`（共 16 组），`ker(L_1,…,L_M,K_1,…,K_M)` 限制在层 `M`
的维数**精确为 `0`**，即 `T_j` 在这些层上确实等于 `R|0⟩`。

`[GAP: 推论 B 的一般 M 手证]`——上面只是穷举到 `M=4` 的核验，不是对一切 `M` 的证明。
一个可能的证明路子（未完成）：用定理 A（`S=F_hl`）说明 `F_hl` 作为 `{L_{-m},K_{-n}}`-代数
的表示是由 `|0⟩` 生成的最高权模，但"由单个向量生成"**不**自动排除更深层出现新的奇异向量

需要额外论证（比如显式核对 Kac 行列式，或利用 `c=2`、`h=x²/2`-型的具体 Verma 模结构）；
本轮未展开此计算。**这条 GAP 不影响定理 A 本身**（定理 A 不依赖推论 B），只影响"`T_j` 的
显式刻画"这一更强的附带问题。

## 6. 推广到 `D≥3`（物理相关情形）：诚实记录一次不成功的推广尝试

P1 真正要证的是 `claim.md` 需要的一般 `D`（尤其 `D=26`）情形，此时 `F(v_j) = F_hl(v_j) ⊗ V`，
`V := F_𝔱(0)` 是 `D-2` 个横向自由玻色子在零动量处的 Fock 空间（正定内积，`𝔱:=𝔩^⊥`）。
本节记录本轮对这一推广的完整尝试过程，包括一个被推翻的错误方案与随后的部分计算结果。

### 6.1 一个被推翻的方案："`T_j = V_prim ⊗ R|0⟩_hl`"

最自然的猜想是：`T_j` 由横向 Virasoro-primary 态（`L_m^𝔱φ=0 ∀m≥1`，记这些态构成 `V_prim⊆V`）
与光锥真空的简单张量积构成，即 `T_j = V_prim⊗R|0⟩_hl`。检验：对简单张量 `φ⊗|0⟩_hl`
（`φ∈V` 任意），全 Sugawara `L_m(φ⊗|0⟩_hl) = (L_m^𝔱φ)⊗|0⟩_hl + φ⊗(L_m^{hl}|0⟩_hl)
= (L_m^𝔱φ)⊗|0⟩_hl`（用 `L_m^{hl}|0⟩_hl=0`，`m≥1`，标准最高权事实）。所以 `φ⊗|0⟩_hl` 物理
`⟺ φ∈V_prim`——**这一步是对的**。

但这个方案在**下一步**垮掉：`φ⊗|0⟩_hl` 是否落在 `T_j` 里，还需要它是 `K_i`-primary
（`i>0`）——`K_i` 只作用在 `hl` 因子上，`K_i|0⟩_hl=0` 自动成立，这一步也对。**问题出在
`V_prim` 本身的刻画，以及"`T_j` 是否恰好是这样一批简单张量的张成"这件事**：

- **正面发现**：层-1 横向元素 `φ=J^i_{-1}|0⟩_𝔱`（`J^i` 记一个横向自由玻色子方向）自动落在
  `V_prim`——`L_1^𝔱φ` 需要横向零动量的非零缩并，此处零动量为 `0`；`L_{m≥2}^𝔱φ` 需要至少两个
  振子才能不为零。逐一验证（用 `[J^i_p,J^j_{-1}]=δ^{ij}δ_{p,1}`）两者都是 `0`。故
  `J^i_{-1}|0⟩⊗|0⟩_hl ∈ T_j`，**独立于任何猜想，直接验证成立**。
- **推翻方案的反例**：层-2 元素 `φ=(J^i_{-1})²|0⟩_𝔱`（同一方向自乘）**不在** `V_prim`——
  `L_2^𝔱φ` 通过 `[J^i_1,J^i_{-1}]=1` 给出非零缩并，直接计算 `L_2^𝔱(J^i_{-1})²|0⟩_𝔱 = |0⟩_𝔱 ≠ 0`。
  所以 `(J^i_{-1})²⊗|0⟩_hl` **不是**简单张量意义下的 `T_j` 候选元素——但这不代表它不在
  `T_j` 里以某种**非简单张量**的方式出现；而下面 §6.2 的直接计算显示，`L_{-2}` 作用在
  真空上的确直接产生横向内容，说明 `T_j` 的真正结构比"简单张量的集合"纠缠得多。

**结论（诚实记录，不是进展）**：`T_j = V_prim⊗R|0⟩_hl` 这一"张量分解"方案**不成立**，
`T_j` 对 `D≥3` 的真实结构比这更纠缠——它按 `(𝔱`-层, `hl`-层`)` 双分次，`L_m` 把双分次
`(p,N)` 映到 `(p-m,N)` 或 `(p,N-m)`（视 Sugawara 项落在哪个因子），一个非双齐次态的
不同双分次分量之间可以通过这种映射**互相抵消**而凑出一个物理态，这种"跨扇区抵消"机制
本轮未刻画。这是**归约，不是进展**——按任务纪律单独记录，不伪装成部分证明。

### 6.2 直接计算：`L_{-2}` 作用在真空上确实产生横向内容

以下手算（`D` 任意 `≥3`，`𝔱` 内每个方向记 `J^i`，`i=1,…,D-2`）：

```
L_{-2}|0;v_j⟩ = (Kt_{-2}+x·K_{-2})|0⟩ + K_{-1}Kt_{-1}|0⟩ + (1/2)Σ_i (J^i_{-1})² |0⟩
```

（前两项是 §2 引理 2 里 `L_{-2}^{hl}|0⟩` 的贡献；第三项是横向 Sugawara `L_{-2}^𝔱|0⟩` 里
唯一存活的 `n=1`（及其配对 `n=-1`）交叉项，`(1/2)Σ_i:J^i_{-1}J^i_{-1}: = (1/2)Σ_i(J^i_{-1})²`
——`n=0` 项因横向零动量为零而消失。）

已用 `research/sandbox/rank3-full-check.py` 独立机检核对（精确有理数，`x` 任意取值），
逐项吻合。**结论**：`L_{-2}` 直接在真空上生成横向-能级-2 内容，说明"横向"与"光锥"两个
因子在 `L_{-m}` 作用下**不可分离**地混合——这正是 §6.1 张量分解方案失败的根源，而非
一个孤立的计算意外。

## 7. 评估：这条路线走不走得通

**`D=2`（§4）：完全可行，已完成。** 定理 A 是一个真正独立的结果：无条件（一切能级、
一切 `x`、任意特征 0 交换环）地证明了 P1 在退化情形下成立，附带证明的核心技术
（Claim ★，"用一个跨越 `k→m+k` 的加强归纳吸收共轭产生算子"）是本轮的原创论证，
不依赖任何未证明的引理。

**`D≥3`（§6）：本轮未能完成，且诊断出了具体的结构性原因，不是笼统的"太难"。**
诊断分两层：

1. **表层原因**："仅用真空生成"或"用几个手算出的低层 `T_j` 元素生成"这类**在单一层
   内部拼凑生成集**的策略，在 `D≥3` 时必然因为 `T_j` 本身依赖更高层信息而秩亏
   （§6.3–6.4 的计算，附带 `M=1` 情形的严格证明）。这与定理 A 里"仅用 `|0⟩`"就够的
   `D=2` 情形形成鲜明对比——`D=2` 之所以只需要 `|0⟩`，是因为那里 `T_j` 本身恰好就是
   `R|0⟩`（推论 B）,没有更多信息需要补充；`D≥3` 时 `T_j` 真的更大，而"更大"具体是
   什么，不知道。
2. **深层原因**（§6.1 的失败张量分解方案揭示的）：`L_m` 在 `𝔱`-`hl` 双分次下**不保持
   双齐次性**（一个态的横向部分与光锥部分会通过 Sugawara 交叉项相互耦合，§6.2 的
   `L_{-2}|0⟩` 直接算例），使得"先在横向因子里找出 primary 态、再简单张量光锥真空"
   这条最自然的分离策略**结构性地**不可行，不是算漏了哪一项。

这与任务书原本提示的"或证明它和 `N≥6` 的 DDF-秩难题一样难"这一诊断方向是**吻合**的：
两者的共同根源都是"单层/单一构造能看到的数据不足以刻画一个本应递归/整体定义的对象"
（`N≥6` 情形是 DDF 单项式的秩需要多组算子的整体配合，而不是逐个方向独立可数的；这里
是 `T_j` 的高层结构需要横向-光锥的整体耦合，而不是分离变量可解的)。**本轮的结论是：
这条"猜测生成集 + 算秩"的路线在 `D≥3` 情形此路不通**——不是因为算力不够，是因为
它试图用局部（单层内、猜出来的几个元素）数据回答一个非局部（`T_j` 的真正定义本质上
和 Borcherds 引理 5.3–5.5 的递归结构绑定）的问题。这不排除存在另一条完全不同的路线
（比如先证 P3 + Lemma 5.5 的塔上版本，再倒推 `T_j` 的刻画，绕开直接猜测），但那已经是
一个不同的攻坚方向，本轮未展开。
