## 1. Objects and notation

Fix a commutative field `K` with `CharZero K` and `Algebra ℚ K` (matches the hypotheses of
`DescendantKernel.lean`), a dimension `D : ℕ` with `2 ≤ D`, and a Lorentzian datum
`η : Fin D → K` with `hη : ∀ μ, η μ * η μ = 1` (one timelike direction encoded by `η 0 = -1`,
the rest `η μ = 1`; this is the hypothesis actually used everywhere in `formal/`, e.g.
`towerLop_apply_towerLop_of_ne_zero`, `Lop_apply_mode`).

**Free-boson Fock space at momentum `p`.** For a fixed vector `p : Fin D → K`, let `F(p)` be
the free-boson Fock module generated by oscillators `α^μ_n` (`μ ∈ Fin D`, `n ∈ ℤ \ {0}`) acting
on a cyclic vacuum `|0;p⟩`, with:
- **(CCR)** `[α^μ_m, α^ν_n] = m η^{μν} δ_{m+n,0}` (only nonzero for opposite-sign, matched
  indices; `η^{μν} = η μ · [μ = ν]` since `η` is diagonal),
- `α^μ_n|0;p⟩ = 0` for `n > 0`, and the "zero mode" convention `α^μ_0 := p^μ · \mathrm{id}`
  (scalar multiplication by the `μ`-component of `p`; this realizes momentum as the zero mode,
  matching `Fock.alpha`/`Fock.mode` at `n = 0` and the `DDFLightConeFrame` tower's
  `towerMomentum`).

`F(p)` is graded by **level** `N ∈ ℕ`: `F(p)_N` is spanned by all products
`α^{μ_1}_{-n_1}⋯α^{μ_k}_{-n_k}|0;p⟩` with `Σ n_i = N`. In particular `F(p)_1` is spanned by
`{α^μ_{-1}|0;p⟩}_{μ=0}^{D-1}` and has dimension exactly `D`.

**Sugawara Virasoro generators.** `L_n := ½ Σ_{k∈ℤ} :α_{n-k}·α_k:` (normal-ordered, negative
modes to the left; the sum is finite on any fixed vector), where
`α_{n-k}·α_k := Σ_μ η_μ α^μ_{n-k}α^μ_k`. This is the object named
`worldsheet.virasoro-generators-free-boson` in the graph (see bricks table, §3).

**The two syzygy operators** (level-4 singular vectors at `h=-4, c=26`, exactly as defined in
`formal/StringFormal/NoGhost/SeedTransferSix.lean` lines 92–121, verified by direct `Read`):
```
y3 := 12 L_{-3} + 6 L_{-2}L_{-1} + L_{-1}³              (operator word order: rightmost applied first)
x4 := -76 L_{-4} - 52 L_{-3}L_{-1} - 12 L_{-2}² - 20 L_{-2}L_{-1}² - 3 L_{-1}⁴
```
with the syzygy identity `L_{-1}x4 + 𝒟₂y3 = 0` (`𝒟₂ := 2L_{-2}+3L_{-1}²`), proved unconditionally
in `SeedTransferSix.lean:towerLop_neg_one_mul_x4_add_descTwo_mul_y3` (no `sorry`, needs only
`hη`, no central charge, no highest weight).

**The map.** For a fixed momentum `p` (any `p`, any level of degeneracy), define
```
S : F(p)_1 → F(p)_5 × F(p)_4,   S(u) := (x4 · u, y3 · u).
```

## 2. Precise statement of the target claim

> **Theorem (S6-whole-slice injectivity).** Let `K` be a field with `CharZero K`, `D : ℕ` with
> `2 ≤ D`, `η : Fin D → K` with `hη : ∀ μ, η μ * η μ = 1`, and `p : Fin D → K` *arbitrary*
> (no constraint on `p·p`; in particular this covers the rung `j = -6` case `p = p_{-6}`,
> `p·p = -10`, but also every other rung and every other momentum). Then the linear map
> `S : F(p)_1 → F(p)_5 × F(p)_4` defined above is **injective**. In fact the stronger statement
> holds: `x4 : F(p)_1 → F(p)_5` **alone** is injective, and `y3 : F(p)_1 → F(p)_4` **alone** is
> injective (each individually, without pairing).
>
> Equivalently: for `u = Σ_μ c_μ α^μ_{-1}|0;p⟩ ∈ F(p)_1`, `x4 · u = 0 ⟹ ∀μ, c_μ = 0`, and
> likewise for `y3`.

**Quantifiers, spelled out.** ∀ fields `K` (`CharZero`, `Algebra ℚ K`), ∀ `D ≥ 2` (in fact the
proof below only needs `D ≥ 1`; `D ≥ 2` is kept for compatibility with the ambient frame
hypotheses used elsewhere), ∀ `η` with `hη`, ∀ `p : Fin D → K` (no constraint whatsoever), ∀
`u ∈ F(p)_1`: `x4·u = 0 → u = 0` and `y3·u = 0 → u = 0` (hence `S(u)=0 → u=0`).

**Why this suffices for the docstring's target.** In the tower formalism, fix rung `j = -6`.
`V_{-6,1} := towerBigrade D K (-6) 1` is (via `Finsupp.single (-6) ·`) a copy of `F(p_{-6})_1`
with `p_{-6} = a - 6b` (`p_{-6}·p_{-6} = -10`), of dimension `D` (`finrank_towerBigrade`); the
theorem above applied at `p = p_{-6}` gives exactly the injectivity of `S₆` on this slice.
Combined with (§4 below) the already-proven counting bound and the already-closed seed
criterion, this closes the docstring's gap.

## 4. The exact logical chain closing the docstring's gap (context, not itself new math)

This is recorded here for completeness / to justify why the theorem above is the *whole*
remaining gap; the chain itself is elementary bookkeeping over already-proven Lean facts, not
part of the new mathematics of this attempt.

1. **Syzygy ⟹ image lands in `ker(descPair)`.** For `u ∈ V_{-6,1}`, the syzygy identity gives
   `L_{-1}(x4u) + 𝒟₂(y3u) = x4(L_{-1}u)+... ` — more directly, `descPair η a b (-6) 6`
   evaluated at `(x4u, y3u)` (viewed as an element of `V_{-6,5}×V_{-6,4}`, **once we know**
   `x4u ∈ V_{-6,5}` and `y3u ∈ V_{-6,4}`, which holds by bidegree bookkeeping, not seed
   membership) equals `L_{-1}(x4u) + 𝒟₂(y3u)`. This is **not** simply `0` from the syzygy as
   stated (the syzygy is an identity of operators applied to the SAME vector `v`, i.e.
   `L_{-1}(x4v)+𝒟₂(y3v)=0` for every `v`); taking `v = u` gives exactly
   `descPair(x4u,y3u) = 0`, i.e. `S(u) ∈ ker(descPair η a b (-6) 6)` for every `u ∈ V_{-6,1}`
   — no seed condition needed. So `S(V_{-6,1}) ⊆ ker(descPair(-6,6))`.
2. **Already-proven generic bound (K6).** `LevelSixCount.lean:finrank_ker_descPair_six_le`
   gives `dim ker(descPair η a b (-6) 6) ≤ D` unconditionally (`hD26` not even needed for this
   direction per the file; effective status: this file compiles with no `sorry`, see §5).
3. **This theorem (S-injectivity) ⟹ dimension count is exact.** `S : V_{-6,1} → V_{-6,5}×V_{-6,4}`
   is injective (proved below) and `dim V_{-6,1} = D` (`finrank_towerBigrade`), so
   `dim S(V_{-6,1}) = D`. Combined with step 1–2, `D ≤ dim ker(descPair(-6,6)) ≤ D`, forcing
   **`ker(descPair(-6,6)) = S(V_{-6,1})` exactly**, of dimension exactly `D`.
4. **Restrict to seeds.** `ker(seedPair(-6,6)) = ker(descPair(-6,6)) ∩ (Q_{-6,5}×Q_{-6,4})`
   (seedPair is literally descPair restricted to the seed subspaces, per
   `DescendantKernel.lean:seedPair_eq_comp`). By step 3 this equals
   `S(V_{-6,1}) ∩ (Q_{-6,5}×Q_{-6,4})` (as subsets of `V_{-6,5}×V_{-6,4}`, under the injection
   `u ↦ (x4u,y3u)`) `= S({u ∈ V_{-6,1} : x4u ∈ Q_{-6,5} ∧ y3u ∈ Q_{-6,4}})`
   `= S(Q_{-6,1})` **by the already-closed seed criterion**
   (`SeedCriterionSix.mem_towerSeed_neg_six_one_iff`, requires `hD26 : (D:K)=26`,
   `haa : zeroModeSq η a = 2`).
5. **Conclude.** `dim ker(seedPair(-6,6)) = dim S(Q_{-6,1}) = dim Q_{-6,1} = D-1` (the last
   equality is `TypeOneFamily.lean`'s exact `dim Q_{j,M} = p_{D-1}(M)` at `M=1`, and `S`
   restricted to `Q_{-6,1}` is still injective since `S` is injective on the ambient
   `V_{-6,1}`). This is exactly the docstring's target `dim ker(seedPair) ≤ D-1` (in fact
   **exact equality**, stronger than the `≤` asked for).

Step 5 needs `D=26` (via the seed criterion, step 4); steps 1–3 (the theorem of this attempt)
hold for **every** `D` and every rung, as stated in §2.
