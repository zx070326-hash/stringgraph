## 1. 格论字典

沿用 `claim.md` §0 的记号。`Λ` 是偶自对偶格（本节只用到"偶"与"`M` 在 `Λ` 中饱和"）。

**Lemma 1.1.** `I = gcd(Q∧P) = [M : L]`。

*证明.* 取 `Λ` 的一组基，设 `A` 是以 `Q,P` 为行的 `2×r` 整数矩阵。Smith 标准型给出
`A = U D V`，`U ∈ GL(2,ℤ)`，`V ∈ GL(r,ℤ)`，`D` 的非零对角元为 `d₁ | d₂`。
`k×k` 子式的 gcd 在左右乘幺模矩阵下不变（每个子式是原子式的整系数线性组合，反之亦然，
Cauchy–Binet），故 `gcd(Q∧P) = gcd` (`D` 的 2×2 子式) `= d₁d₂`。
另一方面 `DV` 的两行是 `d₁v₁, d₂v₂`，其中 `v₁,v₂` 是 `V` 的前两行；`U` 幺模故
`L = ℤd₁v₁ + ℤd₂v₂`。因 `V ∈ GL(r,ℤ)`，`v₁,v₂` 可扩成 `Λ` 的基，于是
`M = (L⊗ℚ) ∩ Λ = ℤv₁ + ℤv₂`，`[M:L] = d₁d₂`。∎

（脚本 `lattice_witness.py` 的 `saturation()` 即此算法；输出逐行打印 `(V1) True`。）

**Lemma 1.2（适配 ⟹ 可容许）.** 若 `Q ∈ IΛ`，则 `I² | m` 且 `I | ℓ`。

*证明.* 写 `Q = I q`，`q ∈ Λ`；由 `q ∈ (L⊗ℚ)∩Λ = M`。`Λ` 偶故 `q²/2 ∈ ℤ`，于是
`m = Q²/2 = I²·(q²/2)`，`I² | m`；又 `ℓ = Q·P = I(q·P)`，`I | ℓ`。∎

**Lemma 1.3（适配框架存在 ⟺ `M/L` 循环）.**

*证明.* 由 Smith 标准型（对包含 `L ⊆ M` 用），存在 `M` 的基 `(u,v)` 与 `a | b`，`ab = I`，
使 `L = ℤ(au) + ℤ(bv)`，`M/L ≅ ℤ/a ⊕ ℤ/b`。循环 ⟺ `a = 1`。

(⟸) `a = 1`：`L = ℤu + ℤ(Iv)`，取 `(Q,P) := (Iv, u)`，`Q = I v ∈ IM ⊆ IΛ`，适配。

(⟹) 设 `(Q,P)` 是 `L` 的基且 `Q = I q`，`q ∈ Λ`，则如上 `q ∈ M`。在基 `(u,v)` 下写
`Q = αau + βbv`。`Q` 是 `L` 的基向量之一 ⟹ 它在 `L` 的基 `(au, bv)` 下的坐标 `(α,β)` 互素。
又 `Q = ab·q`，`q = q₁u + q₂v`，比较坐标得 `αa = ab q₁`、`βb = ab q₂`，即 `α = b q₁`、`β = a q₂`。
于是 `a | b | α` 且 `a | β`，`gcd(α,β) = 1` 迫使 `a = 1`。∎

**Lemma 1.4（`Q` 或 `P` 本原 ⟹ `M/L` 循环）.**

*证明.* 同一 Smith 基。`Q ∈ M`；若 `Q = k x` 且 `x ∈ Λ`，则 `x ∈ (L⊗ℚ)∩Λ = M`，
故 "在 `Λ` 中本原" 与 "在 `M` 中本原" 对 `Q` 等价。`Q` 在 `M` 的基 `(u,v)` 下的坐标是
`(αa, βb)`，其 gcd 被 `a` 整除；本原 ⟹ `a = 1`。对 `P` 同理。∎

**Lemma 1.5（适配框架 = `Γ₀(I)` 轨道）.** 设 `M/L` 循环，`(Q₀,P₀)` 是一个适配框架。则
`(Q,P) = (aQ₀+cP₀,\ bQ₀+dP₀)`（`U = [[a,b],[c,d]] ∈ SL(2,ℤ)`）适配 ⟺ `I | c`。

*证明.* 先证任一适配框架形如 `(Iw, u)`，其中 `(w,u)` 是 `M` 的基：由 `Q₀ = I w`，`w ∈ M`；
令 `M' := ℤw + ℤP₀ ⊆ M`，则 `L = ℤ(Iw)+ℤP₀ ⊆ M'`，`[M':L] = I = [M:L]`，故 `M' = M`，
且 `(w,P₀)` 是 `M` 的基。记 `u := P₀`。现在
`Q = aIw + cu`，`Q/I = a w + (c/I)u ∈ M = ℤw+ℤu` ⟺ `I | c`。∎

（`Γ₀(I) = {I | c}` 与 A-N eq(2.16) 的 `Γ⁰(I) = {I | b}` 在 `S`-共轭下相同，
也与姊妹尝试 `torsion-immortal-positivity-hecke` Prop 7.1 的 `Γ₀(I)` 一致：
那里证明的是生成函数 `𝒢_I` 只在 `Γ₀(I)` 下不变。本 Lemma 给出该群的**电荷侧**解释。）

**Lemma 1.6（可容许三元组 = 适配框架的不变量）.** 固定 `I ≥ 1`。集合

  `𝒜_I := { (m,n,ℓ) ∈ ℤ³ : I²|m, I|ℓ, m,n ≥ 1, Δ = 4mn−ℓ² > 0 }`（论文 Thm 6.1 的假设域）

恰是"某个挠恰为 `I` 的电荷对的某个**适配**框架的不变量三元组"的全体。

*证明.* (⊇) 由 Lemma 1.2 与 `T` 正定。
(⊆) 给定 `(m,n,ℓ) ∈ 𝒜_I`，令 `(μ,ν,λ) := (m/I², n, ℓ/I) ∈ ℤ³`，则 `μ,ν ≥ 1`、
`4μν−λ² = Δ/I² > 0`。在 `U ⊕ U ⊆ Λ`（基 `e₁,f₁,e₂,f₂`，`⟨x,y⟩ = x₀y₁+x₁y₀+x₂y₃+x₃y₂`）取

  `w := e₁ + μ f₁ = (1,μ,0,0)`,  `u := λ f₁ + e₂ + ν f₂ = (0,λ,1,ν)`,

则 `w²/2 = μ`、`u²/2 = ν`、`w·u = λ`；矩阵 `[[1,μ,0,0],[0,λ,1,ν]]` 的 2×2 子式含 `1`，
故 `M := ℤw+ℤu` 在 `U⊕U` 中本原，从而在 `Λ` 中本原（`U⊕U` 是 `Λ` 的直和项）。
取 `(Q,P) := (Iw, u)`：不变量为 `(I²μ, ν, Iλ) = (m,n,ℓ)`，挠 `= I·gcd(w∧u) = I`，且适配。∎

> **注 1.7.** Lemma 1.6 说明论文 Thm 6.1 的假设域**恰好**参数化了适配框架——就假设域本身而言
> 论文没有写错；错的是把 `(m,n,ℓ)` 当作电荷的完全标签（前提 (P′)）。

## 2. eq(52) 右端到底在算什么

回忆（`claim.md` §0.3）

  `D_I(m,n,ℓ) := Σ_{s|I,\ s²|m,\ s|ℓ} s · d_*(m/s², n, ℓ/s)`。

**Prop 2.1（机制）.** 设 `(Q,P)` 是 `L` 的框架，`s ≥ 1` 满足 `s²|m`、`s|ℓ`。在 `L⊗ℚ` 中令

  `L^{(s)} := ℤ(Q/s) + ℤP`。

则 (a) `L ⊆ L^{(s)}` 且 `[L^{(s)} : L] = s`；
(b) `L^{(s)}` 关于基 `(Q/s, P)` 的 Gram 三元组恰是 `(m/s², n, ℓ/s)`，判别式 `Δ/s²`；
(c) `L^{(s)} ⊆ Λ ⟺ Q/s ∈ M`；特别地，若框架适配，则对每个 `s|I` 有 `L^{(s)} = L_s`，
其中 `L_s` 是 `M/L ≅ ℤ/I` 的唯一 `s` 阶子群对应的中间格；
(d) 若框架不适配，则对某个 `s|I`，`L^{(s)} ⊄ Λ`，此时 `L^{(s)}` 与 `L_s` 是同一二次空间中
判别式相同（`= Δ/s²`）但一般**不等价**的两个格。

*证明.* (a) `Q = s·(Q/s) ∈ L^{(s)}`，`P ∈ L^{(s)}`，故 `L ⊆ L^{(s)}`；共体积之比为 `s`，
而 `s²|m`、`s|ℓ` 保证 Gram 整性，故指数为 `s`。
(b) 直接计算：`(Q/s)²/2 = m/s²`，`P²/2 = n`，`(Q/s)·P = ℓ/s`；`4(m/s²)n − (ℓ/s)² = Δ/s²`。
(c) `L^{(s)} ⊆ Λ ⟺ Q/s ∈ Λ ⟺ Q/s ∈ (L⊗ℚ)∩Λ = M`。适配时 `Q/I ∈ M`，故 `Q/s ∈ M` 对一切 `s|I`；
此时 `L ⊆ L^{(s)} ⊆ M` 且 `[L^{(s)}:L] = s`，由 `M/L` 循环，指数为 `s` 的中间格唯一，故 `= L_s`。
(d) 由 (b) 判别式相同；不等价性由 §3 的见证实现。∎

> **注 2.2.** 这正是 DGM 推导路径（`literature/extractions/dabholkar-gomes-murthy-2008.md` S4：
> "重标 `ρ→s²ρ, v→sv`"）在电荷侧的内容：**把 `Q` 除以 `s`**。该操作停留在电荷格内当且仅当
> 框架适配。eq(52) 的右端因而不是 `(m,n,ℓ,I)` 的函数，而是**框架**的函数。

**Prop 2.3（为什么以前没被发现）.** 固定轨道与 `I`。若对每个 `s|I`，判别式 `Δ/s²` 的正定整二元形
只有一个 `GL(2,ℤ)` 类，则 `D_I` 在该轨道的**全部**可容许框架上取同一值。

*证明.* 由 Prop 2.1(b)，第 `s` 项恒是某个判别式 `Δ/s²` 的正定整形的 `d_*`；类数为 1 时所有这样的形
`GL(2,ℤ)` 等价，由 (B2) 其 `d_*` 相同。逐项相同故总和相同。∎

> **注 2.4.** 论文 §3 用来区分 eq(51)/eq(52) 的那个见证是 `I=2, (m,n,ℓ) = (4,1,2)`，`Δ = 12`，
> `s=2` 项的判别式是 `Δ/4 = 3`，而判别式 3 的正定形只有一个类 `(1,1,1)`。**该见证恰好落在
> Prop 2.3 的盲区里**：无论换到轨道里哪个可容许框架，`D_2` 都不变。这解释了为什么两轮审查
> 都没有撞上框架依赖性——需要 `Δ/s²` 类数 ≥ 2 才看得见。本文件的见证正是这样挑的。

## 3. 主见证：`D_I` 不是 S-对偶不变量

**Thm 3.1.** `claim.md` Claim 1 成立。以下三组见证均已用精确整数验证
（`scripts/divisor_sum_values.py`，转录见 `scripts/run_output.txt`）。

### 见证 A（`I = 2`，最小判别式，框架 2 的 `Q,P` 均本原）

取 `U ⊕ U` 中 `w := e₁+f₁ = (1,1,0,0)`，`u := e₂+4f₂ = (0,0,1,4)`；
`M := ℤw + ℤu`，Gram 三元组 `(μ,ν,λ) = (1,4,0)`，`Δ_M = 16`，`M` 在 `Λ` 中本原。
令 `L := ℤ(2w) + ℤu`，则 `[M:L] = 2`、`M/L ≅ ℤ/2`、`I = 2`。

| | 框架 1（适配） | 框架 2（不适配） |
|---|---|---|
| `Q` | `2w = (2,2,0,0)`（非本原） | `−2w−u = (−2,−2,−1,−4)`（**本原**） |
| `P` | `u = (0,0,1,4)`（本原） | `−u = (0,0,−1,−4)`（**本原**） |
| `(m,n,ℓ)` | `(4,4,0)` | `(8,4,8)` |
| `Δ` | 64 | 64 |
| 可容许（`4|m, 2|ℓ`） | 是 | 是 |

两框架由 `U = [[−1,0],[−1,−1]] ∈ SL(2,ℤ)` 相联（`(Q,P) ↦ (−Q−P, −P)`），张成**同一个** `L`，
挠同为 2，`T` 同属一个 `GL(2,ℤ)` 类（`(8,4,8) ~ (4,4,0)`）。

所需的 `d_*` 值（Gauss 约化后读取）：

```
d_*(4,4,0) = 7999169992704      d_*(8,4,8) = d_*(4,4,0) = 7999169992704
d_*(1,4,0) =      185738352     d_*(2,4,4) = d_*(2,2,0) =       32861184
```

于是

```
D_2(4,4,0) = 7999169992704 + 2 ×  185738352 = 7999541469408
D_2(8,4,8) = 7999169992704 + 2 ×   32861184 = 7999235715072
差         =                2 × (185738352 − 32861184) =     305754336   ≠ 0
```

**机制（Prop 2.1）**：框架 1 的 `s=2` 项是 `L^{(2)} = ℤw + ℤu = M`，类 `(1,4,0)`；
框架 2 的 `s=2` 项是 `ℤ((−2w−u)/2) + ℤ(−u)`，而 `(−2w−u)/2 ∉ Λ`，其类是 `(2,2,0)`。
判别式 16 的正定形恰有两个 `GL(2,ℤ)` 类：`(1,4,0)` 与 `(2,2,0)`——见证正是让两个框架落进不同的类。

## 6. 协变改写与权重唯一性

**定义.** 设 `L ⊆ M ⊆ Λ`，`M` = `L` 的饱和，`I = [M:L]`，`T_L` 正定。令

  **`𝔇(L) := Σ_{L ⊆ L' ⊆ M} [L' : L] · d_*(T_{L'})`**，

和跑遍全部中间格；`T_{L'}` 取 `L'` 的任一组基的 Gram 形，由 (B2) `d_*(T_{L'})` 与基的选取无关。

**Thm 6.1.**
(a) `𝔇(L)` 只依赖于 `L`（与任何框架无关）；
(b) 若 `M/L ≅ ℤ/I` 循环且 `(Q,P)` 是适配框架，则 `𝔇(L) = D_I(m,n,ℓ)`，且逐项对应
（`s` 项 ↔ 指数 `s` 的中间格）。

*证明.* (a) 定义中没有出现基。
(b) `M/L ≅ ℤ/I` 的子群与 `I` 的因子一一对应，故每个 `s|I` 恰有一个指数 `s` 的中间格 `L_s`，
且 `[L_s:L] = s`。由 Prop 2.1(c)，适配框架下 `L^{(s)} = L_s`，而 `D_I` 的第 `s` 项按定义是
`s·d_*(m/s², n, ℓ/s) = s·d_*(T_{L^{(s)}}) = s·d_*(T_{L_s})`。逐项相等。∎

**Thm 6.2（权重唯一性）.** 设 `w : ℤ_{≥1} → ℝ`，且对**每个** `I ≥ 1` 与每个满足
`M/L ≅ ℤ/I`、`T_L` 正定（`m,n≥1`，`Δ>0`）的配置，

  `Σ_{L ⊆ L' ⊆ M} w([L':L]) · d_*(T_{L'})` `=` 适配框架下 eq(52) 的右端 `D_I`。

则 `w(s) = s` 对一切 `s ≥ 1`。

*证明.* 对 `I` 的因子个数归纳。`I = 1`：和只有一项，`w(1)d_*(T_L) = d_*(T_L)`；
由 (B1) `d_*(T_L) > 0`，故 `w(1) = 1`。
设 `w(t) = t` 对 `I` 的一切真因子 `t` 成立。由 Thm 6.1(b)，两端逐项相消后只剩
`(w(I) − I)·d_*(T_M) = 0`。取 Lemma 1.6 的实现（`μ = ν = 1, λ = 0`，即 `T_M = (1,1,0)`，`Δ_M = 4 > 0`），
由 (B1) `d_*(T_M) > 0`，故 `w(I) = I`。∎

> **[GAP: `𝔇(L)` 在 `M/L` 非循环时是否是物理免死指标，本文件不作断言。]**
> 由 Lemma 1.4，`M/L` 非循环要求 `Q` 与 `P` **都**非本原；此时根本不存在适配框架，
> eq(52) 在任何框架下都没有 DGM 推导的支持。`𝔇(L)` 在这种情形给出一个自然的、
> 框架无关的候选值（例如 `L = 2M` 时 `M/L ≅ (ℤ/2)²` 有 5 个中间格，`𝔇` 有 5 项，
> 而 eq(52) 只有 3 项），但这是**提案**，不是定理。

## 7. 正性存活，且覆盖面更大

**Thm 7.1（纯数学）.** 设 `L ⊆ M ⊆ Λ` 如上，`T_L` 正定，`m,n ≥ 1`，`Δ > 0`。则
对每个中间格 `L'`，`T_{L'}` 的 Gram 三元组 `(m',n',ℓ')` 满足 `m',n' ≥ 1`、
`Δ' = Δ/[L':L]² > 0`，故由 (B1) `d_*(T_{L'}) > 0`。从而对任意权重 `w ≥ 0`（不全为零），

  `Σ_{L ⊆ L' ⊆ M} w([L':L]) · d_*(T_{L'}) > 0`；

特别地 `𝔇(L) > 0`。

*证明.* `L' ⊆ M ⊆ Λ`，`Λ` 偶，故对 `0 ≠ x ∈ L'` 有 `x²/2 ∈ ℤ`；`L'` 与 `L` 张成同一个二次空间，
该空间正定（`T_L` 正定），故 `x² > 0`，于是 `x²/2 ≥ 1`。取 `x` 为 `L'` 的基向量得 `m',n' ≥ 1`。
判别式：`det T_{L'} = det T_L / [L':L]²`，故 `Δ' = Δ/[L':L]² > 0`。(B1) 适用（它不要求
`gcd(m',n',ℓ') = 1`）。非负权重的正组合为正。∎

**Cor 7.2（物理结论，修正版）.** 在 (P′_ad) 之下：设 `(Q,P) ∈ Λ×Λ` 是任一 1/4-BPS 电荷，
`m = Q²/2 ≥ 1`，`n = P²/2 ≥ 1`，`Δ > 0`，`I = gcd(Q∧P)`，且 `M/L` 循环
（由 Lemma 1.4，只要 `Q` 或 `P` 本原即自动满足）。则该电荷的免死指标为正。

*证明.* 由 Lemma 1.3 取一个适配框架 `(Q₀,P₀)`，其不变量 `(m₀,n₀,ℓ₀) ∈ 𝒜_I`（Lemma 1.2）。

Thm 6.1(b) 给出 `= 𝔇(L)`；Thm 7.1 给出 `> 0`。∎
