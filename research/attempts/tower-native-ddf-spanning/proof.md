## §0 证明梗概（一页）

Goddard–Thorn 的困难历来在于：物理态空间 `H_phys` 是两个无穷多条件的交，而 DDF 态是一个
显式构造的子空间，两者之间没有现成的桥。Borcherds 1992 §5 的做法是先取一个抽象的
"横向空间" `T`，证 `H = U(Vir_{<0})·T`（Lemma 5.2），再证 `T¹` 就是要找的补空间。
本项目此前的死路都卡在：**那个 `T` 在动量塔里是什么，没人知道**（见
`research/attempts/borcherds-rank-one-noghost/`）。

本证明把这一步倒过来：**先指定 `W`，再证它可以当 `T` 用。** 取

```
W_j := ker( K_m |_{F(p_j)} : m ≥ 1 ) = R[ K_{−n}, E^i_{−n} : n ≥ 1 ]·|0;p_j⟩ ,
```

即"把 `Λ` 方向的振子全部去掉"。这个空间是**显式多项式代数**，一切计算都变成偏导数计算。
三步：

1. **§3 Theorem 1**：`F(p_j)` 作为 `U(Vir_{<0})`-模在 `W_j` 上自由。
   机制：在滤过权 `w = Mλ − κ`（`λ` = `Λ`-次数，`κ` = `K`-次数，`M` 充分大）下，
   `L_{−m}` 的**唯一**最高权项是"乘以 `Λ_{−m}`"，其系数恰是 `η(b, p_j) = 1`。
   于是 `L_{−m_1}⋯L_{−m_r}w` 的领项是互不相同的单项式 `Λ_{−m_1}⋯Λ_{−m_r}·w`，
   线性无关；再用特征函数恒等式 `∏(1−q^n)^{−1}·∏(1−q^n)^{−(D−1)} = ∏(1−q^n)^{−D}`
   把"无关"升级成"基"。**这里唯一的输入是 (S)**。
2. **§4 Theorem 2**：`T_j := W_j ∩ P_j` 就是 DDF 空间。
   机制：`L_m|_{W}` 的 `K`-次数最低项是 `m∂_{K_{−m}}`（降 1 次），其余保次数；于是
   `T_j ∩ I_j = 0`，`I_j` = `W_j` 里 `K`-次数 ≥ 1 的部分。同时**在 `W` 上顶点算子的
   湮灭指数部分退化为恒等**，给出精确同余 `A^ε_n|_W ≡ E_n S_n (mod I)`。
   两件事一夹，`dim T¹_{−N} ≤ p_{D−2}(N) = #{DDF 单项式} ≤ dim T¹_{−N}`。
3. **§5 Theorem 3**：`D = 26` 在此仅通过一条**有限**的计算进入：

   `g_2 := L_2 + (3/2)L_1²` 把 `S¹` 打回 `S`；而它们把 `W` 打回 `W` 是自动的。
   于是 `F = W ⊕ S` 的分解与 `P¹` 相容，给出 `P¹ = T¹ ⊕ N¹`，即 `H_phys = D(Ε) ⊕ H_null`。

### 1.2 对偶基与 `α_p·α_q` 的展开

**引理 1.** 设 (N)(S)(T)(T′)(O)(C)。`{a, b, ε_i}` 关于 `η` 的对偶基是

## §2 滤过与领项

**定义（权滤过）.** 固定能级上界 `N`，取整数 `M := N + 1`。对 `F(p_j)_{≤N}`（能级 ≤ `N`）
上的双分次单项式 `x ∈ F^{λ,κ}` 定义

```
w(x) := M·λ(x) − κ(x) ∈ ℤ .                                           (2.1)
```

因能级 ≤ `N` 时必有 `κ ≤ N < M`，故

```
w(x) ≥ w(y)  且  λ(x) > λ(y)   ⟹  w(x) > w(y) ,
w(x) = w(y)  ⟺  λ(x) = λ(y) 且 κ(x) = κ(y) .                          (2.2)
```

即 `w` 在能级 ≤ `N` 的范围内**忠实地把 `(λ, −κ)` 的字典序编码成一个整数**。
置 `F_{≤w}` := 权 ≤ `w` 的单项式张成的子空间；`{F_{≤w}}` 是 `F(p_j)_{≤N}` 的递增穷竭滤过。

**引理 6（`L_{−m}` 的领项）.** 设 `1 ≤ m ≤ N`。在 `F(p_j)_{≤N−m} → F(p_j)_{≤N}` 上，把
引理 4 的展开逐项按 (2.1) 记权变化 `Δw`：

| 项 | `Δλ` | `Δκ` | `Δw` |
|---|---|---|---|
| (Z) `Λ_{−m}` | `+1` | `0` | `+M` |
| (Z) `j·K_{−m}` | `0` | `+1` | `−1` |
| (CC) `Λ_{−r}K_{−(m−r)}` | `+1` | `+1` | `M−1` |
| (CC) `K_{−r}Λ_{−(m−r)}` | `+1` | `+1` | `M−1` |
| (CC) `K_{−r}K_{−(m−r)}` | `0` | `+2` | `−2` |
| (CC) `E^i_{−r}E^i_{−(m−r)}` | `0` | `0` | `0` |
| (CA) `Λ_{−m−k}K_k`（`K_k = k∂_{Λ_{−k}}`） | `+1−1 = 0` | `0` | `0` |
| (CA) `K_{−m−k}Λ_k`（`Λ_k = k(η(a,a)∂_{Λ_{−k}} + ∂_{K_{−k}})`） | `0` 或 `−1` | `+1` 或 `0` | `−1` 或 `−M` |
| (CA) `K_{−m−k}K_k` | `−1` | `+1` | `−M−1` |
| (CA) `E^i_{−m−k}E^i_k` | `0` | `0` | `0` |

故

```
L_{−m} = (乘以 Λ_{−m}) + (Δw ≤ M−1 的项) ,                              (2.3)
```

且 `(乘以 Λ_{−m})` 的系数是 `1`——它来自 (Z) 的 `α_{−m}·α_0 = η(p_j, α_{−m})`，
`Λ_{−m}` 的系数恰为 `η(b, p_j) = 1`（引理 2 的 `K_0`）。**这是 (S) 在全证明中唯一的入口。**

*证明.* 逐行核对引理 2 与引理 4。唯一需要留意的是 (CA) 的 `K_{−m−k}Λ_k`：
`Λ_k` 先作用，它是 `η(a,a)k∂_{Λ_{−k}} + k∂_{K_{−k}}` 之和，两支分别给 `Δw = −1`（先降
`λ` 再乘 `K`：`Δλ = −1, Δκ = +1` ⟹ `−M−1`）……更精确地：
`η(a,a)k∂_{Λ_{−k}}` 支给 `Δλ = −1`，随后乘 `K_{−m−k}` 给 `Δκ = +1`，合计 `Δw = −M−1`；
`k∂_{K_{−k}}` 支给 `Δκ = −1`，随后乘 `K_{−m−k}` 给 `Δκ = +1`，合计 `Δw = 0`。
两支都 `≤ M−1`（`M ≥ 2`；`M = 1` 即 `N = 0` 时 `L_{−m}` 的定义域为 0，无需论证）。
其余行同理。因 `M = N+1 ≥ 2`，表中除首行外全部 `≤ M−1 < M`。∎

**推论 6.1.** 对 `m_1 ≥ m_2 ≥ … ≥ m_r ≥ 1`、`Σm_i ≤ N` 与 `W_j` 的单项式 `v`（`λ(v) = 0`），

```
L_{−m_1}⋯L_{−m_r}·v = Λ_{−m_1}⋯Λ_{−m_r}·v + (权 < M·r − κ(v) 的项) .     (2.4)
```

*证明.* 对 `r` 归纳。`Λ_{−m_1}⋯Λ_{−m_r}v` 的权是 `M·r − κ(v)`。由 (2.3)，
每作用一次 `L_{−m}`，"最高权项"是乘 `Λ_{−m}`（`Δw = +M`），其余 `Δw ≤ M−1`；

`F_{≤w}` 送进 `F_{≤w+M}`，由 (2.3) 逐项可见。）∎

## §3 Theorem 1：`F(p_j)` 在 `U(Vir_{<0})` 上自由

> **Theorem 1.** 设 (R)(D)(F1)(N)(S)(T)(T′)(O)(C)，`j ∈ ℤ` 任意。则
> ```
> μ : U(Vir_{<0}) ⊗_R W_j ⟶ F(p_j) ,    u ⊗ w ↦ u·w

> **不需要 (A)、(D26)**（`η(a,a)` 可以是任意标量）。

*证明.*

**(2) 分次.** `L_{−m}` 抬高能级 `m`（引理 5(a)），`W_j` 是能级分次的，故 `μ` 是
能级分次映射。只需对每个 `N ≥ 0` 证 `μ_N` 是同构。

**(3) 维数相等.** 定义域的能级 `N` 部分的基元 `L_{−m_1}⋯L_{−m_r} ⊗ v` 由一个分拆
`π = (m_1 ≥ … ≥ m_r)` 与一个 `(D−1)` 色分拆（即 `v ∈ B_j`）组成，`|π| + level(v) = N`。
故

```
Σ_N dim(定义域)_N q^N = (Σ_ℓ p(ℓ)q^ℓ)·(Σ_ℓ p_{D−1}(ℓ)q^ℓ)
 = ∏_{n≥1}(1−q^n)^{−1} · ∏_{n≥1}(1−q^n)^{−(D−1)}
 = ∏_{n≥1}(1−q^n)^{−D} = Σ_N p_D(N)q^N = Σ_N dim F(p_j)_N q^N ,
```

用了引理 3 与 (1.2)。两边逐项有限，故 `dim(定义域)_N = dim F(p_j)_N < ∞`。

**(4) 单射.** 设 `x = Σ_{(π,v)} c_{π,v}·L_{−π}v`（`L_{−π} := L_{−m_1}⋯L_{−m_r}`）是能级 `N`
的非零元素，`c` 不全为 0。取 `M = N+1`、按 (2.1) 定权。在出现的 `(π,v)` 中取
`w_max := max{ M·r(π) − κ(v) }`，由 (2.2) 该最大值对应的 `(π,v)` 集合
`Σ_max` 恰是"`r(π)` 最大、且在其中 `κ(v)` 最小"的那些。由推论 6.1，

```
x = Σ_{(π,v) ∈ Σ_max} c_{π,v}·Λ_{−π}·v  +  (权 < w_max 的项) ,
```

其中 `Λ_{−π} := Λ_{−m_1}⋯Λ_{−m_r}`。关键：映射

```
(π, v) ⟼ Λ_{−π}·v
```

是**单射**——`Λ_{−π}·v` 是 (1.1) 的一个单项式，从它可以读出 `Λ` 变量的多重集（即 `π`）
与剩下的 `K,E` 部分（即 `v`）。故 `Σ_{Σ_max}c_{π,v}Λ_{−π}v` 是互不相同单项式的非平凡
线性组合，非零。由于它是 `x` 的权 `w_max` 齐次分量，`x ≠ 0`。故 `μ_N` 单。

**(5)** 单 + 有限维数相等 ⟹ 同构。∎

**推论 1.1.** `F(p_j) = W_j ⊕ S_j`（内直和，能级分次），
`S_j := Σ_{m≥1}L_{−m}F(p_j)`。

*证明.* `S_j = μ(U(Vir_{<0})_{>0} ⊗ W_j)`，其中 `U(Vir_{<0})_{>0}` = `U(Vir_{<0})` 的
增广理想（`r ≥ 1` 的 PBW 基元张成）。确实：`⊇` 显然（`L_{−m}·(u w) = (L_{−m}u)w`）；
`⊆` 由 Theorem 1 把任意 `F(p_j)` 元素写成 PBW 形式，再左乘 `L_{−m}`。
而 `W_j = μ(1 ⊗ W_j)`，且 `U(Vir_{<0}) = R·1 ⊕ U(Vir_{<0})_{>0}`。
`μ` 是同构 ⟹ 直和分解。能级分次性由 (2) 得。∎

**推论 1.2.** `S_j = P_j^⊥`（在 `F(p_j)` 内取正交补），
`P_j := {v : L_mv = 0, ∀m ≥ 1}`。

*证明.* 由引理 5(c)(d)：`x ⊥ S_j` ⟺ `∀m ≥ 1, y: ⟨L_{−m}y, x⟩ = 0` ⟺
`∀m,y: ⟨y, L_mx⟩ = 0` ⟺ `∀m ≥ 1: L_mx = 0`（型非退化）⟺ `x ∈ P_j`。
故 `S_j^⊥ = P_j`。又 `S_j` 与 `P_j` 都是能级分次的（引理 5(a)），每个 `F(p_j)_N`
有限维且型在其上非退化，故 `S_j^{⊥⊥} = S_j`（有限维非退化空间里的标准事实，逐能级应用）。
于是 `P_j^⊥ = S_j^{⊥⊥} = S_j`。∎

**注 3.1（对比 Borcherds Lemma 5.2）.** Borcherds 的 Lemma 5.2 断言
`H = U(Vir_{<0})·T` 并需要先知道 `T`；这里 `W_j` 是预先指定的显式空间，
自由性由多项式代数上的领项计算直接给出。代价是我们**还不知道** `W_j ∩ P_j` 是什么——
那是 §4 的内容。
