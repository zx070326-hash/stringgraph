## §0 一句话

**(T′) 可以整条删掉，且不需要任何替代前件。**
机制：对任何只满足 (T)(O) 的标架，令 `c_i := η(ε_i, a)`、`ε_i′ := ε_i − c_i b`，则 `Ε′` 恢复 (T′)

## §2 待证命题

沿用 `claim.md` §1.2–§1.3 的定义（`F(p_j)`、`T(a;b)`、Fock 型、`W_j`、`I_j`、`P_j`、`S_j`、
`T_j := W_j ∩ P_j`、`N_j := S_j ∩ P_j`、上标 `¹` 表 `L_0 = 1` 本征分量、
`D(Ε) := span_R{ A^{ε_{i_1}}_{−n_1}⋯A^{ε_{i_r}}_{−n_r}|0;a⟩ : r ≥ 0, n_k ≥ 1 }`）。

> **引理 A（标架平移）.** 设 (R)(D)(F1)(N)(S)(T)(O)。置 `ε_i′ := ε_i − c_i b`。则
> `Ε′ := (a, b, ε_1′,…,ε_{D−2}′)` 满足 (N)(S)(A)(T)(**T′**)(O)(C)，且 `a`、`b`、`η(a,a)` 不变。
> 过渡矩阵是幂幺的，行列式 `1`。

> **引理 B（零极化 DDF 算子恒为零）.** 设 (R)(D)(F1)(N)(S)。在动量塔 `T(a;b)` 上，
> 对一切 `n ∈ ℤ∖{0}`
> ```
> A^b_n = 0 ,        而 A^b_0 = id .
> ```
> （`A^b_n` 指 `claim.md` §1.2 的 DDF 模和定义中把极化向量取成 `b`；其合法性由 (N) 即 `η(b,b)=0`
> 提供所需的横向性 `η(b,b) = 0`。）**不用 (A)(T)(O)(C)(D26)，不用 `D ≥ 2`。**

> **推论 B.1（DDF 算子只依赖 `ε` 模 `Rb`）.** 设 (R)(D)(F1)(N)(S)。若 `ε, ε″ ∈ 𝔥` 均横向
> （`η(ε,b) = η(ε″,b) = 0`）且 `ε − ε″ ∈ Rb`，则对一切 `n ≠ 0`：`A^ε_n = A^{ε″}_n`。
> 特别 `A^{ε_i′}_n = A^{ε_i}_n`（`n ≠ 0`），从而
> ```
> D(Ε′) = D(Ε)    （两边的张成集逐元相同，不只是张成相同）。
> ```

> **Theorem 1′.** 设 (R)(D)(F1)(N)(S)(T)(O)(C)，`j ∈ ℤ` 任意。则
> ```
> μ : U(Vir_{<0}) ⊗_R W_j ⟶ F(p_j) ,    u ⊗ w ↦ u·w
> ```
> 是 `R`-线性同构；等价地 `{L_{−m_1}⋯L_{−m_r}·v : r ≥ 0, m_1 ≥ … ≥ m_r ≥ 1, v ∈ B_j}` 是
> `F(p_j)` 的基。**不需要 (T′)、(A)、(D26)。**
> 推论 1.1′ `F(p_j) = W_j ⊕ S_j`；推论 1.2′ `S_j = P_j^⊥`。

> **Theorem 2′.** 设 (R)(D)(F1)(N)(S)(A)(T)(O)(C)，`D ≥ 2` 任意。则对一切 `N ≥ 0`
> ```
> T¹_{−N} = D(Ε)_{−N} ,     rank_R T¹_{−N} = p_{D−2}(N) ,
> ```
> 且 `T¹_j = 0`（`j > 0`）；合起来 `T¹ = D(Ε)`。且对每个 `(D−2)` 色分拆
> `{(i_1,n_1),…,(i_r,n_r)}`（`Σn_k = N`）各取一个排序，所得
> `{A^{ε_{i_1}}_{−n_1}⋯A^{ε_{i_r}}_{−n_r}|0;a⟩}` 是 `D(Ε)` 的一组 `R`-基。
> **不需要 (T′)、(D26)。**

> **Theorem 3′（主定理）.** 设 (R)(D)(F1)(N)(S)(A)(T)(O)(C)(D26)。则在

## §3 量词总结（审查时请逐条核对）

- **`D`**：Theorem 1′ 对 `D ≥ 1` 都有意义（横向指标集可空）；Theorem 2′ 对 `D ≥ 2` 任意；
  Theorem 3′ 只在 `D = 26` 断言等号（`D ≠ 26` 时 `⊇` 仍成立、`⊆` 失效，见 `proof.md` §5）。
- **系数环**：任意含 `ℚ` 的交换环 `R`。不要求域、不要求 `R` 约化、不要求 `Â` 或 `|c|²` 可逆。
  `ℚ ⊆ R` 用在：`u(n) = n∂_{u(−n)}`（除以 `n`）、`L_m` 里的 `½`、引理 B 里的除以 `n`、引理 11 里的除以 `1−n`。
- **标架**：一切满足 (F1)(N)(S)(A)(T)(O) 的 `(a,b,ε_1,…,ε_{D−2})`，`c = η(ε_·,a)` **任意**。
  这正是目标卡 `worldsheet.ddf-spanning-hypothesis-v2` 的【设定】所量化的范围减去 (S)。
- **`n`**：引理 B 与推论 B.1 对一切 `n ∈ ℤ∖{0}`；`n = 0` 时 `A^b_0 = id ≠ 0`，
  **推论 B.1 在 `n = 0` 上是假的**（`A^{ε_i′}_0 = A^{ε_i}_0 − c_i·id`）。
  `D(Ε)` 的定义只用 `n_k ≥ 1`，故不受影响——这是本路线能走通的**关键边界条件**，
  也是审查时最该盯的一处。
- **`j`**：一切 `j ∈ ℤ`（塔的每一层）。
