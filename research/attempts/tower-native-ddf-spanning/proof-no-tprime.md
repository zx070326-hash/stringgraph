## §0 路线图

设标架满足 (F1)(N)(S)(A)(T)(O)，但 **`c_i := η(ε_i, a)` 任意**。两步：

1. **引理 A**：`ε_i′ := ε_i − c_i b` 把标架平移回 (T′)。`a`、`b` 不动，(N)(S)(A)(T)(O)(C) 全部保持。
   这一步是纯线性代数，三行。
2. **引理 B**：`A^b_n = 0` 对一切 `n ≠ 0`。这是本文件唯一一条**新数学**。
   由它与 `ε ↦ A^ε_n` 的 `R`-线性性得 `A^{ε_i′}_n = A^{ε_i}_n`（`n ≠ 0`），
   而 `D(Ε)` 的定义只用 `n_k ≥ 1` 的模，故 **`D(Ε′) = D(Ε)`，张成集逐元相同**。

于是把 `proof.md` 的 Theorem 1/2/3 用到标架 `Ε′` 上（合法：`Ε′` 满足那里的全部前件），
再把结论里的 `D(Ε′)` 替换成 `D(Ε)`，即得 Theorem 1′/2′/3′。
Theorem 1′ 更简单：它的陈述里根本不出现 `ε`（见 §4.1）。

**为什么这不是"偷换前提".** 引理 A 单独看确实像"把不满足 (T′) 的标架换成满足的"——
若 `D(Ε)` 依赖标架的具体选取，这种替换就不合法，因为目标卡断言的是**原来那个** `D(Ε)`。
全部实质内容都在引理 B：它说 `D(Ε)` **确实**不依赖 `c`。删掉引理 B，整条路线立刻失效。

## §1 记号与 `c`

沿用 `claim.md` §1：`p_j := a + jb`，`F(p_j) = R[Λ_{−n}, K_{−n}, E^i_{−n} : n ≥ 1]`，
`Λ_n := a(n)`、`K_n := b(n)`、`E^i_n := ε_i(n)`，`[u(m),v(n)] = m η(u,v)δ_{m+n,0}`，
`u(0)|_{F(p_j)} = η(u, p_j)`，`T(a;b) = ⊕_{j∈ℤ}F(p_j)`。

对**任意** `u ∈ 𝔥` 记 `u(n)` 为相应的模算子：`n ≥ 1` 时是由
`u(n)·v(−m) = n η(u,v)δ_{nm}` 决定的导子；`n ≤ −1` 时是乘以生成元 `u(n)`；
`n = 0` 时是标量 `η(u,p_j)`。三种情形下 `u ↦ u(n)` 都是 `R`-线性的
（导子由 `η(u,·)` 线性决定；乘法算子因 `𝔥 ⊗ t^{−1}R[t^{−1}] → F(p_j)` 线性；标量显然）。

置

```
c_i := η(ε_i, a) ∈ R  (i = 1,…,D−2) ,    |c|² := Σ_i c_i² ,    Â := η(a,a) − |c|² .
```

(T′) ⟺ `c = 0`。**(T′) 在 (T)(O) 下不是免费的**——具体反例（坐标下标 `0..5`，`R = ℝ` 或 `ℚ`）：

```

b = e_0 + e_1 = (1,1,0,0,0,0) ,    a = e_1 + e_2 = (0,1,1,0,0,0) ,
ε_1 = e_2 ,  ε_2 = e_3 ,  ε_3 = e_4 ,  ε_4 = e_5 .
```

核对：`η(b,b) = −1 + 1 = 0`（(N)）；`η(a,b) = (−1)·0·1 + 1·1·1 + 1·1·0 = 1`（(S)）；
`η(a,a) = 1 + 1 = 2`（(A)）；`η(ε_i,b) = 0`（(T)，`ε_i` 的 `0,1` 分量全为 `0`）；
`η(ε_i,ε_j) = δ_{ij}`（(O)）；`{a,b,ε_1,…,ε_4}` 的行列式 `= −1`（(C)）；
`v := a − b = (−1,0,1,0,0,0)` 满足 `η(v,v) = −1 + 1 = 0`（目标卡【设定】的条件）。
而

```
c_1 = η(ε_1, a) = η(e_2, e_1 + e_2) = 1 ≠ 0 ,    c_2 = c_3 = c_4 = 0 .
```

即这是目标卡量化范围内的一个合法标架，却违反 (T′)。（本文件 §6 的机检以
`D = 6, c = (1,0,0,0)` 作为首要构形，就是这个例子。）

**§1.1（`c` 可任意：一般性构造）.** 设 (F1)(N)(S)(A)(T)(O) 的一组标架
`(a,b,ε_1,…,ε_{D−2})` 存在（例如 `proof.md`/`claim.md` 的标准 `c = 0` 标架）。
对任意 `t = (t_1,…,t_{D−2}) ∈ R^{D−2}` 置

```

```

则 `η(ε_i^{(t)}, b) = 0`（(T)(N)），`η(ε_i^{(t)}, ε_j^{(t)}) = δ_{ij}`（(T)(N)(O)），

```
c_i = η(ε_i^{(t)}, a) = η(ε_i,a) + t_i η(b,a) = 0 + t_i = t_i ,
```

即 **`c` 可以取 `R^{D−2}` 中任意值**。这说明 (T′) 在目标卡的【设定】下**不是免费的**，
删掉它确有必要；同时它也预告了引理 A——上式正是引理 A 的逆变换。∎

## §2 引理 A：标架平移

> **引理 A.** 设 (R)(D)(F1)(N)(S)(T)(O)。置 `ε_i′ := ε_i − c_i b`。则
> ```
> η(ε_i′, b) = 0 ,   η(ε_i′, a) = 0 ,   η(ε_i′, ε_j′) = δ_{ij} ,
> ```
> 即 `Ε′ := (a, b, ε_1′,…,ε_{D−2}′)` 满足 (T)(T′)(O)；`a`、`b` 不变故 (N)(S)(A) 自动保持；
> 过渡矩阵幂幺（行列式 `1`），故 (C) 对 `Ε′` 与对 `Ε` 等价。

*证明.*
`η(ε_i′, b) = η(ε_i,b) − c_iη(b,b) = 0 − 0 = 0`（(T)(N)）。
`η(ε_i′, a) = η(ε_i,a) − c_iη(b,a) = c_i − c_i·1 = 0`（`c_i` 的定义 + (S)）。
`η(ε_i′,ε_j′) = η(ε_i,ε_j) − c_jη(ε_i,b) − c_iη(b,ε_j) + c_ic_jη(b,b) = δ_{ij}`（(O)(T)(N)）。
过渡矩阵在有序基 `(a,b,ε_1,…,ε_{D−2})` 下是单位下三角（只在 `b` 那一行加了 `−c_i`），
行列式 `1`，可逆。∎

**注 2.1（多项式模型的坐标变换）.** `Ε′` 给出同一个 `F(p_j)` 的另一组多项式生成元
`E′^i_{−n} = E^i_{−n} − c_i K_{−n}`，且

```
R[Λ_{−n}, K_{−n}, E^i_{−n}] = R[Λ_{−n}, K_{−n}, E′^i_{−n}]
```

（幂幺变量替换）。所以 `F(p_j)`、`T(a;b)`、能级分次、`L_m`、`W_j = ker(K_{m≥1})`、
`P_j`、`S_j`、`T_j`、`I_j`（`= W_j` 中 `κ ≥ 1` 的部分，`κ` = `K`-次数，与 `E` 的选取无关）
**作为空间全都不变**。唯一可能随标架变的对象就是 `D(Ε)`。

## §3 引理 B：`A^b_n = 0`（`n ≠ 0`）

本节只设 **(R)(D)(F1)(N)(S)**。不用 (A)(T)(O)(C)(D26)，`D ≥ 1` 任意。

### 3.0 定义与约定

按 `claim.md` §1.2（= Lean `StringFormal.NoGhost.ddfOp`）：对横向极化
`ε ∈ 𝔥`（`η(ε,b) = 0`）与 `n ∈ ℤ`，

```
A^ε_n = Σ_{J ∈ ℤ} ε(J) · V^{(n)}_J ,      V^{(n)}_J := S_n ∘ vertexOsc(nb)_{J−n} ,   (3.1)
vertexOsc(nb)_M = Σ_{L ≥ 0} Φ^{(n)}_{M+L} Ψ^{(n)}_L ,                                (3.2)
E_-^{(n)}(z) = exp( n Σ_{m≥1} K_{−m} z^m / m ) = Σ_{r ≥ 0} Φ^{(n)}_r z^r ,            (3.3)
E_+^{(n)}(z) = exp( −n Σ_{l≥1} K_l z^{−l} / l ) = Σ_{L ≥ 0} Ψ^{(n)}_L z^{−L} ,       (3.4)
```

`S_n : F(p_j) → F(p_{j+n})` 是层移（对振子多项式部分是恒等）。
约定 `Φ^{(n)}_r = 0`（`r < 0`）、`Ψ^{(n)}_L = 0`（`L < 0`）、`Φ^{(n)}_0 = Ψ^{(n)}_0 = 1`。
`exp` 在 `ℚ ⊆ R` 下良定义（(R)）。以下固定 `n` 并略去上标：`Φ_r`、`Ψ_L`、
`V_M := vertexOsc(nb)_M`（把它看成振子多项式代数上的算子，层移单独写）。

**取 `ε = b`（合法性）.** (3.1) 要求 `η(ε,b) = 0`；取 `ε = b` 时这正是 (N)。
于是 `A^b_n = Σ_J K_J·S_n·V_{J−n}`，`K_J := b(J)`。

### 3.1 三条对易事实

固定 `x ∈ F(p_j)`，设其能级 `≤ N_x`（任何元素是有限多个齐次分量之和，可取 `N_x` 为最大能级）。
能级 `≤ N_x` 蕴含 `x ∈ R[Λ_{−m},K_{−m},E^i_{−m} : 1 ≤ m ≤ N_x]`。

**(K1)** 对一切 `p, q ∈ ℤ∖{0}`：`[K_p, K_q] = p·η(b,b)·δ_{p+q,0} = 0`（(N)）。
特别地 `K_p`（`p ≥ 1`，导子）在生成元 `K_{−m}` 上取值 `0`，故由 Leibniz 律

```
K_p ∘ (乘以任意 f ∈ R[K_{−1},K_{−2},…]) = (乘以 f) ∘ K_p .                        (3.5)
```

`Φ_r ∈ R[K_{−1},…,K_{−r}]`，`Ψ_L ∈ R[K_1,…,K_L]`，故 **`K_p` 与一切 `Φ_r`、`Ψ_L` 对易**
（`p ≤ −1` 时 `K_p` 是乘法算子，与乘法算子当然对易，与 `Ψ_L` 对易由 (K1)）。
从而 `K_p` 与一切 `V_M` 对易（`p ≠ 0`）。

**(K2)** `K_0|_{F(p_{j′})} = η(b, p_{j′}) = η(b,a) + j′η(b,b) = 1`（(S)(N)），
对**每一层** `j′ ∈ ℤ` 都成立。故 `K_0 = id` 于整个塔 `T(a;b)` 上。

**(K3)** `S_n ∘ K_J = K_J ∘ S_n`（`J ∈ ℤ`）：`J ≠ 0` 时 `K_J` 在振子多项式代数上的作用
与层无关（乘以 `K_J` 或导子 `|J|∂_{Λ_{−|J|}}`），而 `S_n` 对振子部分是恒等；
`J = 0` 时两边都是 `S_n`（由 (K2)）。

### 3.2 求和的局部有限性

**(F-a)** `Ψ_L` 把能级降低恰好 `L`（(3.4) 中 `Ψ_L` 是 `K_l` 的、总降级为 `L` 的齐次多项式），
`F(p_j)` 只有非负能级，故 `Ψ_L x = 0` 当 `L > N_x`。于是 (3.2) 在 `x` 上是**有限和**：

```
V_M x = Σ_{L = 0}^{N_x} Φ_{M+L}·Ψ_L x .                                            (3.6)
```

**(F-b)** `Φ_{M+L} = 0` 当 `M+L < 0`；配合 `0 ≤ L ≤ N_x` 得

```
V_M x = 0    当 M < −N_x .                                                          (3.7)
```

**(F-c)** 对 `M + n ≥ 1`：由 (3.5) 与 (K1)，`K_{M+n}` 可以穿过 (3.6) 中的 `Φ_{M+L}` 与 `Ψ_L`
直接落到 `x` 上：`K_{M+n}V_Mx = V_M(K_{M+n}x)`，而 `K_l x = 0`（`l > N_x`）。故

```
K_{M+n}·V_M x = 0    当 M > N_x − n .                                               (3.8)
```

合起来：`{M : K_{M+n}V_Mx ≠ 0} ⊆ [−N_x, N_x − n]` 有限，
即 **`A^b_n x` 的定义 (3.1) 是有限和**。
（注：(F-c) 的论证对任意横向 `ε` 逐字有效，只需把 (K1) 换成 `[ε(p),K_{−m}] = pη(ε,b)δ = 0`，
即 (T)。这正是 DDF 模和需要横向性的地方。）

### 3.3 指数的两条有限递推

**引理 B.1.** 对一切 `r ∈ ℤ`、`L ∈ ℤ`：

```
r·Φ_r = n Σ_{m ≥ 1} K_{−m}·Φ_{r−m}       （右端至多 r 项非零）,                    (3.9)
−L·Ψ_L = n Σ_{l ≥ 1} K_l·Ψ_{L−l}         （右端至多 L 项非零）.                   (3.10)
```

*证明.* 设 `G(z) := n Σ_{m≥1}K_{−m}z^m/m ∈ A[[z]]`，`A := R[K_{−1},K_{−2},…]`（交换环，
由 (K1)）。`G` 无常数项且 `ℚ ⊆ R`，故 `F(z) := exp G(z) ∈ A[[z]]` 良定义，
且形式导数满足 `F′ = G′·F`（形式幂级数上 `exp` 的标准性质，逐项验证）。
`G′(z) = nΣ_{m≥1}K_{−m}z^{m−1}`，`F = Σ_rΦ_rz^r`；比较 `z^{r−1}` 的系数得 (3.9)（`r ≥ 1`）。
`r = 0`：左端 `0`，右端 `nΣ_{m≥1}K_{−m}Φ_{−m} = 0`（`Φ_{<0} = 0`）。`r < 0`：两端皆 `0`。
(3.10)：置 `u := z^{−1}`，`E_+^{(n)} = exp(−nΣ_{l≥1}K_lu^l/l) = Σ_LΨ_Lu^L`，
在交换环 `A_+ := R[K_1,K_2,…]`（由 (K1) 交换）上同法得 `L·Ψ_L = −nΣ_{l≥1}K_lΨ_{L−l}`，
即 (3.10)；`L ≤ 0` 同上平凡。∎

**注 B.2.** (3.9)(3.10) 是**有限**恒等式（每个 `Φ_r`、`Ψ_L` 是具体多项式），
不涉及无穷和的收敛或形式级数的完备化。下面的推导只用它们。

### 3.4 关键恒等式

> **引理 B.3.** 设 (R)(N)(S)。对一切 `M ∈ ℤ`、`x ∈ F(p_j)`、`n ∈ ℤ`：
> ```
> M · V_M x = n [ Σ_{m ≥ 1} K_{−m}·V_{M−m}x + Σ_{l ≥ 1} K_l·V_{M+l}x ] ,          (★★)
> ```
> 两个和都只有有限项非零。

*证明.* 由 (3.6)（有限和，`0 ≤ L ≤ N_x`），把 `M` 写成 `(M+L) − L`：

```
M·V_Mx = Σ_L [ (M+L)Φ_{M+L} ]·Ψ_Lx  −  Σ_L Φ_{M+L}·[ L·Ψ_L ]x .
```

对第一项用 (3.9)（`r = M+L`），对第二项用 (3.10)（`−LΨ_L = nΣ_lK_lΨ_{L−l}`）：

```
M·V_Mx = n Σ_{m≥1} K_{−m} Σ_L Φ_{(M−m)+L}Ψ_Lx  +  n Σ_{l≥1} Σ_L Φ_{M+L}·K_l·Ψ_{L−l}x .
```

第一块按 (3.6) 正是 `n Σ_{m≥1}K_{−m}V_{M−m}x`。
第二块：`Ψ_{L−l} = 0`（`L < l`），故可置 `L = L′ + l`（`L′ ≥ 0`），得

```
n Σ_{l≥1} Σ_{L′≥0} Φ_{(M+l)+L′}·K_l·Ψ_{L′}x
  = n Σ_{l≥1} K_l Σ_{L′≥0} Φ_{(M+l)+L′}Ψ_{L′}x        （K_l 与 Φ 对易，(3.5)）
  = n Σ_{l≥1} K_l·V_{M+l}x .
```

有限性：第一个和由 (3.7) 在 `m > M + N_x` 时为零；第二个和由 `K_lV_{M+l}x = V_{M+l}(K_lx)`
（(3.5)）在 `l > N_x` 时为零。∎

### 3.5 引理 B

> **引理 B.** 设 (R)(D)(F1)(N)(S)。则在 `T(a;b)` 上
> ```
> A^b_n = 0   （∀ n ∈ ℤ∖{0}） ,        A^b_0 = id .
> ```

*证明.* 固定 `n ≠ 0`、`x ∈ F(p_j)`。由 (3.1) 与 (K3)，置 `p := J`、`M := J − n`：

```
A^b_n x = Σ_{J∈ℤ} K_J·S_n·V_{J−n}x = S_n·( Σ_{p∈ℤ} K_p·V_{p−n}x ) ,               (3.11)
```

右端由 §3.2 是有限和。把 `p = 0` 的项单独拿出，用 (K2) `K_0 = id`：

```
Σ_{p∈ℤ} K_p V_{p−n}x = V_{−n}x + Σ_{p ≠ 0} K_p V_{p−n}x .                          (3.12)
```

另一方面，在 (★★) 中取 `M = −n`：

```
−n·V_{−n}x = n [ Σ_{m≥1}K_{−m}V_{−n−m}x + Σ_{l≥1}K_lV_{−n+l}x ] .
```

`n` 是非零整数，由 `ℚ ⊆ R` 在 `R` 中可逆，两边除以 `n`：

```
−V_{−n}x = Σ_{m≥1}K_{−m}V_{(−m)−n}x + Σ_{l≥1}K_lV_{l−n}x = Σ_{p ≠ 0} K_p V_{p−n}x
```

（第一个和令 `p := −m`，第二个和令 `p := l`；两者合起来恰好跑遍 `p ∈ ℤ∖{0}`）。
代回 (3.12)：`Σ_{p}K_pV_{p−n}x = V_{−n}x − V_{−n}x = 0`，再由 (3.11) 得 `A^b_nx = 0`。

`n = 0`：`E_-^{(0)} = E_+^{(0)} = 1`，故 `Φ^{(0)}_r = δ_{r,0}`、`Ψ^{(0)}_L = δ_{L,0}`，
`V^{(0)}_M = δ_{M,0}`，于是 `A^b_0 = K_0·S_0 = id`（(K2)）。∎

**注 B.4（这是什么）.** 物理上 `A^b_n` 是流 `b·∂X(z)·V(nb,z)` 的模，而
`b·∂X(z)V(nb,z) = (1/n)∂_z V(nb,z)` 是全导数（因 `η(b,b) = 0` 使 `V(nb,z)` 权为零，
无反常项），故其非零模积分为零。上面的证明是这句话的**无围道、无形式级数完备化**版本：
(★★) 恰是 `∂_z` 与模指标的关系 `M·V_M = n·[b·∂X·V]_M` 的模级形式，而
`Σ_pK_pV_{p−n}` 是 `[b·∂X·V]_{−n}` 的正规序展开。
**本注不承重**，引理 B 的证明不依赖它。

**注 B.4′（(S) 是引理 B 的充要条件——锐化形式，`rev-no-tprime` 审查 2026-09-25 给出）.**
把 (S) `η(a,b) = 1` 换成 `η(a,b) = s`（保留 (N)(T)(O)，`c` 任意），追踪上面的证明：
(K2) 变成 `K_0 = η(b, p_j) = η(b,a) + j·η(b,b) = s·id`，于是 (3.12) 的首项是 `s·V_{−n}x`；
而 (★★) 给出的 `Σ_{p≠0}K_pV_{p−n}x = −V_{−n}x` **不含 `s`**（(★★) 只用 `η(b,b) = 0`）。
两者相加得

```
A^b_n  =  (η(a,b) − 1) · S_n · V^{(n)}_{−n}          （∀ n ≠ 0）。          (3.13)
```

**后果三条**：
1. **(S) 不是"顺便用到"，而是充要**：障碍恰好是标量 `s − 1`，`s = 1` 时归零，任何别的值都不归零。
