## 2. Lemma B.1（换元的双射性）

**引理 B.1.** 设 d ≥ 1 是正整数，S_d := {(n,m,ℓ) ∈ ℤ³ : Ω^{(4|4)}_1(n,m,ℓ) ≠ 0}。定义映射
φ_d : S_d → ℤ³ 为 φ_d(n,m,ℓ) = (n, d²m, dℓ)，其像为

    T_d := {(n,M,L) ∈ ℤ³ : d²|M, d|L, Ω^{(4|4)}_1(n, M/d², L/d) ≠ 0}.

则 φ_d : S_d → T_d 是双射。等价地，换元 (m,ℓ) ↦ (m',ℓ') := (m/d², ℓ/d) 建立 T_d 与 S_d 之间的双射，
且对固定 d，它不引入重复或遗漏。

**证明.** 构造逆映射。对 (n,M,L) ∈ T_d，定义 ψ_d(n,M,L) = (n, M/d², L/d)。
由 T_d 的定义，d²|M 且 d|L，故 M/d² 与 L/d 均为整数，ψ_d 的值域在 ℤ³ 内。

验证 ψ_d ∘ φ_d = id_{S_d}：对 (n,m,ℓ) ∈ S_d，
    ψ_d(φ_d(n,m,ℓ)) = ψ_d(n,d²m,dℓ) = (n, d²m/d², dℓ/d) = (n,m,ℓ). ✓

验证 φ_d ∘ ψ_d = id_{T_d}：对 (n,M,L) ∈ T_d，
    φ_d(ψ_d(n,M,L)) = φ_d(n,M/d²,L/d) = (n, d²·(M/d²), d·(L/d)) = (n,M,L). ✓

因此 φ_d 和 ψ_d 互逆，φ_d : S_d → T_d 是双射。

**格点完整性（无重复无遗漏）.** 上述双射确保：对固定 d，以 (m',ℓ') 对所有使 Ω_1(n,m',ℓ') ≠ 0 的
格点 (n,m',ℓ') 求和，与以 (m,ℓ) 对 T_d 中格点求和，枚举的项完全相同（一一对应）。∎

## 3. Lemma B.2（指数恒等式）

**引理 B.2.** 设 d ≥ 1 是正整数，z ∈ ℂ，令 y = e^{2πiz}。对任意整数 ℓ' ∈ ℤ，令

    z_new := dz + (d−1)/2.

则以下等式在 ℂ 中对所有 ℓ' ∈ ℤ 成立：

    (−1)^{dℓ'} · y^{dℓ'} = (−1)^{ℓ'} · e^{2πi z_new ℓ'}.

**证明.** 逐步展开右端：

**第 1 步.** 代入 z_new 的定义：

    e^{2πi z_new ℓ'} = e^{2πi(dz + (d−1)/2)ℓ'}
                     = e^{2πi·dz·ℓ'} · e^{2πi·(d−1)/2·ℓ'}.

**第 2 步.** 化简第一因子。由 y = e^{2πiz}：

    e^{2πi·dz·ℓ'} = (e^{2πiz})^{dℓ'} = y^{dℓ'}.

**第 3 步.** 化简第二因子：

    e^{2πi·(d−1)/2·ℓ'} = e^{iπ(d−1)ℓ'} = (e^{iπ})^{(d−1)ℓ'} = (−1)^{(d−1)ℓ'}.

**第 4 步.** 合并：

    (−1)^{ℓ'} · e^{2πi z_new ℓ'} = (−1)^{ℓ'} · y^{dℓ'} · (−1)^{(d−1)ℓ'}
                                  = (−1)^{ℓ' + (d−1)ℓ'} · y^{dℓ'}
                                  = (−1)^{dℓ'} · y^{dℓ'}.

此即左端。∎

**注 B.2.1（唯一性）.** 使等式成立的 z_new（模整数周期）唯一由 y^{dℓ'} 的系数与 (−1)^{ℓ'} 的比较确定：
需要 e^{2πi(z_new − dz)ℓ'} = (−1)^{(d−1)ℓ'} = e^{iπ(d−1)ℓ'} 对所有 ℓ' 成立，
故 z_new − dz ≡ (d−1)/2 (mod 1)，即 z_new = dz + (d−1)/2 + k 对某整数 k，
但 k 对 1/Φ₁₀ 的展开式无影响（由整周期性，模整数平移等价）。

## 4. Lemma B.3（Φ₁₀ 的半整平移分析）

**引理 B.3.** 设 d ≥ 1，z_new = dz + (d−1)/2，则：

**(a) d 奇时：** (d−1)/2 ∈ ℤ（因 d−1 是偶数，(d−1)/2 为整数）。
由周期性 [周期性]，对任意整数 k：Φ₁₀(τ, z+k, σ) = Φ₁₀(τ,z,σ)。取 k=(d−1)/2 ∈ ℤ，得

    Φ₁₀(τ, dz+(d−1)/2, d²σ) = Φ₁₀(τ, dz, d²σ).

即奇 d 的平移在 Φ₁₀ 的值上无效果（由整周期性消去）。

**(b) d 偶时：** d−1 是奇数，(d−1)/2 ∉ ℤ 是半整数（即形如整数加 1/2）。
整周期性不能消去半整平移，因此

    Φ₁₀(τ, dz+(d−1)/2, d²σ) ≠ Φ₁₀(τ, dz, d²σ)

一般地成立（平移非平凡）。具体地：d=2 时平移为 1/2，d=4 时平移为 3/2，d=6 时平移为 5/2，均为半整数。

**证明.** (a) 整除性：d 奇则 d−1 偶，故 (d−1)/2 = (d−1)/2 ∈ ℤ。整周期性逐次用整数 1 叠加即得。
(b) d 偶则 d−1 奇，故 (d−1)/2 = (整数)+1/2，即半整数，不在整数平移格内。
不等式：反设对所有 (τ,z,σ) 均有 Φ₁₀(τ, dz+1/2, d²σ)（以 d=2 为例）= Φ₁₀(τ, dz, d²σ)，
则将 z↦z+1/2 代入 Φ₁₀(τ,z,σ)（令 z=dz）得 Φ₁₀(τ,z+1/2,σ) = Φ₁₀(τ,z,σ) 对一切 z，
即 Φ₁₀ 在 z 方向有 1/2-周期。但 Φ₁₀ 作为 index-1 Jacobi 形式，其 Laurent 展开含 y^{奇数} 项
（例如 y^{-1} 或 y^1 项，由 Borcherds 乘积的 c(4mn−ℓ²) 在 ℓ 奇时非零保证），
而 y^{ℓ} 在 y↦e^{iπ}y = −y 即 z↦z+1/2 下变为 (−1)^ℓ y^ℓ，对奇 ℓ 差一个负号，矛盾。∎

**支撑 B.3(b) 的前提（Φ₁₀ 展开式含奇 ℓ 项，已坐实）：** 上述矛盾论证用到"Φ₁₀ 的
Fourier-Laurent 展开含 y^{奇数} 项"，即 Borcherds 乘积中 ℓ 为奇时系数 c(4mn−ℓ²) 非零。
两条独立逐字来源坐实之：

1. `kawai-1997` eq.(4.32)（逐字）：c(0)=20, c(−1)=2, c(N)=0 (N<−1)。在乘积 eq.(5.13) 中取
   三元组 (k,l,r)=(0,1,1)（判别式 4·0·1 − 1² = −1，奇 ℓ=1），得指数 c(−1)=2≠0，故乘积含
   因子 (1 − q^0 p^1 y^1)² = (1−py)²，展开含非零 y^1 项（奇 ℓ）。(k,l,r)=(0,1,1) 满足乘积指标集
   （k=0, l=1>0），详见抽取记录 §E2。
2. `dabholkar-murthy-zagier-2012`（DMZ）§4.3 eq.(85)（逐字）：φ_{−2,1}(τ,z)=(y−2+y⁻¹)+O(q)，
   Table 1 C_{−2}(−1)=1≠0。二重佐证。(ℓ=1 对应判别式 −1，C_{−2}(−1)=1≠0。)

**约定注（关键，避免混淆）：** 本 proof 中乘积公式所用的 c(k) 指**指标 1 弱 Jacobi 形式
φ_{−2,1} 的 Fourier 系数**（即 DMZ 记号 C_{−2}(k)，Table 1 给 C_{−2}(−1)=1）。而 `kawai-1997`
的 c(−1)=2 是 **K3 椭圆亏格**系数（= φ_{−2,1} 系数乘 −2 的整体归一化）。两套系数相差整体因子 −2，
但均给 c(−1)≠0；B.3(b) 的非平凡性只需**非零性**，与归一化无关。

此为 Lemma B.3(b) 的严格性所需；(a) 部分无此需求。

## 5. 命题 B 的证明

**命题 B.** 在上述记号下，∀ 正整数 I，∀ (τ,z,σ) 在形式 Fourier 展开收敛的域内：

    Z^{(4|4)}_I(τ,z,σ) = Σ_{d|I} d / Φ₁₀(τ, dz+(d−1)/2, d²σ).    (**)

**证明.**

**第 1 步（代入 eq(2.13) 并交换求和序）.**

由定义（eq(2.11)）：

    Z^{(4|4)}_I(τ,z,σ) = Σ_{n,m,ℓ ∈ ℤ} (−1)^ℓ Ω^{(4|4)}_I(n,m,ℓ) q^n y^ℓ p^m.

将 eq(2.13) 代入：

    Z^{(4|4)}_I = Σ_{n,m,ℓ} (−1)^ℓ [Σ_{d|I} d · Ω_1(n, m/d², ℓ/d)] q^n y^ℓ p^m.

交换求和序（在形式幂级数层面合法，因为对固定 d，内部和是有限重组）：

    = Σ_{d|I} d · Σ_{n,m,ℓ} (−1)^ℓ Ω_1(n, m/d², ℓ/d) q^n y^ℓ p^m.    (I)

注意：当 d²∤m 或 d∤ℓ 时，Ω_1(n, m/d², ℓ/d) = 0（因 Ω_1 只在整数三元组上非零），
故和式实际上只对满足 d²|m 和 d|ℓ 的 (n,m,ℓ) 有贡献。

**第 2 步（对固定 d 换元）.**

对固定 d，令 m = d²m', ℓ = dℓ'（其中 m', ℓ' ∈ ℤ）。由 Lemma B.1，此换元建立所有使
Ω_1(n, m/d², ℓ/d) 非零的格点 (n,m,ℓ) 与所有使 Ω_1(n,m',ℓ') 非零的格点 (n,m',ℓ') 之间的
双射（对固定 d），不引入重复或遗漏。代入 (I)：

    Σ_{n,m,ℓ} (−1)^ℓ Ω_1(n, m/d², ℓ/d) q^n y^ℓ p^m
    = Σ_{n,m',ℓ'} (−1)^{dℓ'} Ω_1(n, m', ℓ') q^n y^{dℓ'} p^{d²m'}.    (II)

**第 3 步（应用 Lemma B.2 改写指数因子）.**

由 Lemma B.2（取 ℓ' 为当前求和变量）：

    (−1)^{dℓ'} · y^{dℓ'} = (−1)^{ℓ'} · e^{2πi z_new ℓ'},    z_new = dz+(d−1)/2.

令 y_new = e^{2πi z_new} = e^{2πi(dz+(d−1)/2)}，则 e^{2πi z_new ℓ'} = y_new^{ℓ'}。代入 (II)：

    Σ_{n,m',ℓ'} (−1)^{ℓ'} Ω_1(n, m', ℓ') q^n y_new^{ℓ'} (p^{d²})^{m'}.    (III)

**第 4 步（识别为 Z^{(4|4)}_1）.**

令 p_new = e^{2πi d²σ} = p^{d²}，则 (III) 正是：

    Σ_{n,m',ℓ'} (−1)^{ℓ'} Ω_1(n,m',ℓ') q^n y_new^{ℓ'} p_new^{m'} = Z^{(4|4)}_1(τ, z_new, d²σ).

由 eq(2.11)（第二等式）：

    Z^{(4|4)}_1(τ, dz+(d−1)/2, d²σ) = 1/Φ₁₀(τ, dz+(d−1)/2, d²σ).

**第 5 步（合并）.**

代回 (I)：

    Z^{(4|4)}_I(τ,z,σ) = Σ_{d|I} d · Z^{(4|4)}_1(τ, dz+(d−1)/2, d²σ)
                        = Σ_{d|I} d / Φ₁₀(τ, dz+(d−1)/2, d²σ).

此即 (**) 式。∎

## 6. 推论 B1（与 DGM eq(51) 的比较）

**推论 B1.** 用 DGM/Rosselló 记号，令 s = d 为除子，则命题 B 在 DGM 记号下写为：

    𝒵_I(ρ,σ,v) = Σ_{s|I} s / Φ₁₀(s²ρ, σ, sv+(s−1)/2).    (**)_DGM

**变量字典（2026-09-18 订正，见本节末「订正」）.** 对应关系**不是**按书写顺序左右对齐的。
A-N 把三元组写成 (τ,z,σ) 且被 d² 重标的是**第三个**槽位 σ；本项目/DGM 写成 (ρ,σ,v)
且被 s² 重标的是**第一个**槽位 ρ。故对应关系由"谁被重标"唯一确定：

| 在 𝒱_s 下的角色 | DGM / 本项目 | A-N |
|---|---|---|
| 指标变量，乘 s² | ρ | σ |
| 椭圆变量，乘 s（并带平移） | v | z |
| 旁观者，不变 | σ | τ |

即 **ρ ↔ σ_AN（带 d² 重标）、v ↔ z_AN、σ ↔ τ_AN**。代入命题 B 的
`Φ₁₀(τ, dz+(d−1)/2, d²σ)`：第一槽 τ ↦ 本项目的 σ，第二槽 ↦ sv+(s−1)/2，
第三槽 d²σ ↦ s²ρ；按本项目的参数顺序 (ρ,σ,v) 重排即得 (**)_DGM。

**与 DGM eq(51) 的精确差别（来自 `literature/extractions/dabholkar-gomes-murthy-2008.md` §S2）：**

DGM eq(51)（逐字）：`𝒵_I(ρ,σ,v) = Σ_{s|I} s · 1/Φ₁₀(s²ρ, σ, sv)`。
按上表翻译后，(**)_DGM 与 eq(51) 的参数**槽位完全一致**（都是 (s²ρ, σ, ·)，
Jacobi 指标都挂在 ρ 上），两式只差椭圆变量上的平移：

**注（约定差异与本质差别的分离）.** 经上表翻译后已在同一约定下，两式的差别只有一处：
- 命题 B（(**) 式）：Φ₁₀ 的椭圆变量参数为 sv + (s−1)/2。
- DGM eq(51)：Φ₁₀ 的椭圆变量参数为 sv（无平移）。

**奇偶分析（由 Lemma B.3）：**

- s 奇时：(s−1)/2 ∈ ℤ，由 Φ₁₀ 整周期性：Φ₁₀(s²ρ, σ, sv+(s−1)/2) = Φ₁₀(s²ρ, σ, sv)。
  即奇除子项两公式结果相同——(s−1)/2 是整平移，被 Φ₁₀ 吸收。

- s 偶时：(s−1)/2 是半整数（不在 ℤ 内），平移不可消去。
  两公式的 s 偶除子项一般给出不同值（见 torsion-immortal-positivity-hecke/proof.md §5 的显式整数见证，
  I=2, s=2, (m,n,ℓ)=(4,1,2) 处两读法差 101412 = 4·d_*(1,1,1)）。

**结论：** DGM eq(51) 与从 A-N eq(2.11)+(2.13) 纯代数导出的 (**) 式，在所有偶数除子 s 上均有差别，
差别恰好是半整平移 (s−1)/2；在奇数除子 s 上（通过整周期性）两式等价。

**订正（2026-09-18，lead）.** 本节此前把字典写成「ρ 对应 A-N 的 τ，σ 对应 A-N 的 σ」，
并据此把 (**)_DGM 写成 `Φ₁₀(ρ, sv+(s−1)/2, s²σ)`。这是**错的**：它把 A-N 的三元组
按书写顺序左右对齐，于是 d² 重标落到了 σ 上，而本项目/DGM 约定里被 s² 重标的是 ρ。
正确对应是 ρ ↔ σ_AN（带重标）、σ ↔ τ_AN（不重标），见上表。
**本节的结论完全不变**（奇 s 等价、偶 s 差半整平移、见证数字），受影响的只是变量标注；
但旧写法让 (**)_DGM 与 eq(51) 看起来还差一个"指标挂在哪个变量上"的约定差，
掩盖了两式其实**槽位一致、只差平移**这一更干净的事实。
本尝试的 `captain_confirmed: true` 早于此订正；数学结论未变，故不撤销确认，仅在此备案。
同一错误的镜像出现在 `research/papers/torsion-dyon-shift-positivity/paper.md` §4 的散文里
（那里的公式是对的，散文是错的），已于同日一并订正。

**精确命题表述（GAP-BKM Conjecture）：**

设 G 为以 Φ₁₀ 为分母函数所构造的 BKM 超代数（Gritsenko-Nikulin [alg-geom/9611028]），正根由
三元组 (k,l,r)（对应变量 p^k q^l y^r，(k,l,r)>0 为 Borcherds 乘积指标集）参数化，根重数
mult(k,l,r) = c(4kl−r²)（c(n) 为 K3 椭圆亏格系数）。

**断言（量化形式）：**

∃ 阶为 2 的代数自同构 ω: G → G，满足：
  (i) ω 在根空间 g_{(k,l,r)} 上作用为乘以 (−1)^r；
  (ii) 对应的扭转分母函数等于 Φ₁₀ 在半整平移处的取值：

      Den_ω(τ,z,σ) = C · Φ₁₀(τ, z+1/2, σ)，

  其中 C 是不依赖 (τ,z,σ) 的常数（通常为 ±1）。

  **⚠ 注（2026-09-15 更正，勿直接引用上式）：** 下方 S3 分析证明此 `Den_ω = C·Φ₁₀` 表述对
  GN1998 代数 G **权重不匹配、为假**（G 的分母是 ψ₅ 权重 5，Φ₁₀=ψ₅² 权重 10）。对 G 成立的
  正确等式是 `Den_ω = (−i)·ψ₅(τ,z+½,σ)`（权重 5）与 `Φ₁₀(τ,z+½,σ) = −Den_ω²`（权重 10），
  详见本节 S3。

**等价的纯模形式表述：**

上述断言的乘积侧等价于初等变量替换 y → −y（即 z → z+1/2）：

    Φ₁₀(τ, z+1/2, σ) = pq(−y) ∏_{(k,l,r)>0} (1 − (−1)^r p^k q^l y^r)^{c(4kl−r²)}.

弱命题（纯代数，已验）：上式是平凡恒等式——把 kawai-1997 eq.(5.13) 中 y 替换为 −y 立得，

∃ Cartan 元素 H_r ∈ h 满足 [H_r, e_{(k,l,r)}] = r · e_{(k,l,r)}，

**S2 证明：Cartan 元素 H_r 的存在性**

**设定.** 根格 M₁ 的 Gram 矩阵（GN1998 §5.1 E2，逐字）在基 {f₂, f₃, f₋₂} 下为

    G = [[0, 0, -4], [0, 2, 0], [-4, 0, 0]],

即 (f₂,f₋₂) = -4，(f₃,f₃) = 2，其余内积为零。Cartan 子代数 h = M₁ ⊗_ℤ ℂ。对 h ∈ h 和根 α ∈ M₁，BKM 代数的根空间作用规则为

    [h, e_α] = (h, α) · e_α.    (★)

（(★) 是 BKM 代数（广义 Kac-Moody 代数）的标准定义，见 Borcherds 1988 §1；对格型 BKM 代数，h = L⊗ℂ 且作用由内积给出。）

**命题 S2.** 令 H_r := f₃/2 ∈ M₁ ⊗_ℤ ℚ ⊂ h。则对所有根 α = (n,l,m) = nf₂+lf₃+mf₋₂：

    [H_r, e_{(n,l,m)}] = l · e_{(n,l,m)}.

**证明.** 直接由 Gram 矩阵计算：

    (H_r, (n,l,m)) = (f₃/2, nf₂+lf₃+mf₋₂)
                   = ½[(f₃,f₂)·n + (f₃,f₃)·l + (f₃,f₋₂)·m]
                   = ½[0·n + 2·l + 0·m] = l.

由 (★) 立得所求。∎

注：这里 l 是 GN1998 的 r-坐标（即 r = e^{2πiz} 方向的指数），与任务表述中的"r"对应。

**命题 S2b（ω 的阶为 2）.** 令 ω := exp(πi · ad(H_r))。则 ω 是 G 的代数自同构，且：

(i) ω 在 g_{(n,l,m)} 上作用为 (-1)^l；
(ii) ω 的阶恰为 2。

**证明.** (i) ad(H_r) 在 g_{(n,l,m)} 上的本征值为 l（命题 S2），故 ω = exp(πi·l)·id = (-1)^l·id。

(ii) 同态性：对 x ∈ g_α, y ∈ g_β，ω([x,y]) = (-1)^{l(α)+l(β)}[x,y] = [ωx,ωy]（因括号积 [g_α,g_β]⊂g_{α+β} 且 l(α+β)=l(α)+l(β)）；故 ω 是代数同态。

阶：ω² = exp(2πi·ad(H_r)) 在每个 g_{(n,l,m)} 上作用为 (-1)^{2l} = 1，故 ω² = id，阶 ≤ 2。

阶 ≠ 1：由 kawai-1997 eq.(4.32)（已坐实，见 §4），c(-1) = 2 ≠ 0，故存在根 (n,l,m)=(0,1,1) 使 l=1 奇，此时 ω|_{g_{(0,1,1)}} = -id ≠ id；故 ω ≠ id，阶恰为 2。∎

**S3 分析：扭转分母 Den_ω 与 Φ₁₀ 的关系——发现权重不匹配**

**计算.** G 的未扭转分母为 ψ₅（权重 5）：

    ψ₅(τ,z,σ) = (qrs)^{1/2} ∏_{(n,l,m)>0} (1 - q^n r^l s^m)^{f₁(nm,l)}

（GN1998 eq.(2.16)，Weyl 向量 ρ=(½,½,½)，q=e^{2πiτ}，r=e^{2πiz}，s=e^{2πiσ}）。

在 ω 下，每个正根空间 g_{(n,l,m)} 的本征值为 (-1)^l（命题 S2b(i)）。扭转分母（BKM 扭转分母恒等式的乘积侧，将每个因子加入 ω 的本征值权重）：

    Den_ω(τ,z,σ) = e^{πi(τ+z+σ)} ∏_{(n,l,m)>0} (1 - (-1)^l · q^n r^l s^m)^{f₁(nm,l)}.

对比 ψ₅ 在 z+½ 处的值（令 r → e^{iπ}r = -r）：

    ψ₅(τ, z+½, σ) = (q·(-r)·s)^{1/2} ∏_{(n,l,m)>0} (1 - (-1)^l q^n r^l s^m)^{f₁(nm,l)}
                  = e^{iπ/2}·(qrs)^{1/2} ∏_{(n,l,m)>0} (1 - (-1)^l q^n r^l s^m)^{f₁(nm,l)}
                  = i · e^{πi(τ+z+σ)} ∏_{(n,l,m)>0} (1 - (-1)^l q^n r^l s^m)^{f₁(nm,l)}.

因此：

    Den_ω(τ,z,σ) = (-i) · ψ₅(τ, z+½, σ).    [S3-result]

（常数因子 -i 来自 Weyl 向量 ρ 在 r→-r 下的贡献：(−r)^{1/2} = e^{iπ/2}r^{1/2} = i·r^{1/2}。）

**权重不匹配（原命题 Den_ω = C·Φ₁₀ 表述有误）.** 由 [S3-result]：

- Den_ω = (-i)·ψ₅(τ,z+½,σ) 是**权重 5** 的 Siegel 模形式；
- Φ₁₀(τ,z+½,σ) = ψ₅(τ,z+½,σ)² 是**权重 10** 的 Siegel 模形式。

两者权重差 5，不可能相差一个常数（常数只能在同权重的非零形式之间建立比例关系）。

的内部结论"，未标引用；现补上逐字来源：`gritsenko-nikulin-1996`（alg-geom/9611028 的姊妹篇

**结论：强命题原文 "Den_ω = C·Φ₁₀(τ,z+½,σ)"（如上节命题（量化形式）所写）对 GN1998 代数 G 不成立。**

**正确表述（对 GN1998 代数 G，在收敛域内）：**

**约定**：采用 Weyl 向量 ρ=(½,½,½) 的典范前因子形式（GN1998 §5.1 分母恒等式 eq.(5.1) 标准写法）：

    Den_ω(τ,z,σ) = e^{2πi(ρ,Z)} · ∏_{(n,l,m)>0} (1 - (-1)^l q^n r^l s^m)^{f₁(nm,l)}
    ψ₅(τ,z,σ)    = e^{2πi(ρ,Z)} · ∏_{(n,l,m)>0} (1 - q^n r^l s^m)^{f₁(nm,l)}

其中 Z=[[τ,z],[z,σ]], (ρ,Z) = ½(τ+z+σ)（Weyl 向量与 Siegel 上半空间变量的内积）。

在该约定下（详见下方"严格论证"）：

    Den_ω(τ,z,σ) = (−i) · ψ₅(τ, z+½, σ)    [权重 5 = 权重 5，ε = −i 是恒等式常数]

    Φ₁₀(τ, z+½, σ) = ψ₅(τ,z+½,σ)² = (−1) · Den_ω(τ,z,σ)²    [权重 10 = 权重 10，与分支无关]

**严格论证（P2: 从数值证据升级为证明）**：

(1) **前因子的典范性**：GN1998 分母恒等式 eq.(5.1)（§5.1, p.55–56）对所有 BKM 超代数给出统一形式

    Φ(Z) = q^{ρ₁} r^{ρ₂} s^{ρ₃} ∏_{(n,l,m)>0} (1 - q^n r^l s^m)^{f(n,l,m)}
         = e^{2πiρ₁τ} e^{2πiρ₂z} e^{2πiρ₃σ} · [乘积]
         = e^{2πi(ρ,Z)} · [乘积]

其中 ρ=(ρ₁,ρ₂,ρ₃) 是格 M_t ⊗ ℚ 中的 Weyl 向量，由 (ρ,α) = −(α,α)/2 对所有简单实根 α∈P(M) 唯一确定
（GN1998 §5.1 E4，逐字）。对 ψ₅，根格 M₁=U(4)⊕ℤ₂ 的 Weyl 向量为 ρ=(½,½,½)（GN1998 §2.2 eq.(2.16)）。
**因此 e^{2πi(ρ,Z)} = e^{πi(τ+z+σ)} 是该 BKM 代数的典范前因子，不是任意记号选择**——它直接来自
Weyl–Kac–Borcherds 分母公式中的 e^{ρ} 项。

(2) **单连通域上的全纯性**：Siegel 乘积在 τ,z,σ 虚部充分大时收敛（GN1996 Appendix B, p.37：
"the given infinite product absolutely converges for all Im(Z)>C for a large C>0"），收敛域同构于凸锥
上的管状域（tube domain over a convex cone），**单连通**。在该域上：
  - e^{2πi(ρ,Z)} 是**单值全纯函数**（指数函数在单连通域上单值）；
  - 乘积 ∏(1−q^n r^l s^m)^{f₁(nm,l)} 全纯非零（乘积展开收敛保证）；
  - 若采用多值记号 (qrs)^{1/2}，其主值分支在域内被 arg(qrs)=±π 的切割线切开，不是单值。

因此 ψ₅ 与 Den_ω **在典范约定 e^{2πi(ρ,Z)} 下才是单值全纯的**；(qrs)^{1/2} 记号隐含了分支选择。

(3) **比值的恒等计算**：在收敛域内，Den_ω 与 ψ₅(z+½) 均全纯非零，比值全纯。逐点计算：

    Den_ω(τ,z,σ) / ψ₅(τ, z+½, σ)
    = [e^{πi(τ+z+σ)} · ∏(1−(−1)^l q^n r^l s^m)^{f₁}] / [e^{πi(τ+z+½+σ)} · ∏(1−q^n (−r)^l s^m)^{f₁}]
    = e^{πi(τ+z+σ) − πi(τ+z+½+σ)} · [∏(1−(−r)^l ...)^{f₁} / ∏(1−(−r)^l ...)^{f₁}]
    = e^{−πi/2} · 1
    = −i.

**结论**：Den_ω/ψ₅(z+½) 在单连通收敛域上处处等于 −i，这是全纯函数恒等式，不是 4 个采样点的巧合。
ε = −i 是由 Weyl 向量 ρ=(½,½,½) 唯一确定的常数。

### 9.2 引理 9.1（换元的双射性，就地重新证明，不引用引理 B.1）

**引理 9.1.** 设 d≥1 为正整数。代换 m=d²m′, ℓ=dℓ′（m′,ℓ′∈ℤ）在
{(n,m,ℓ)∈ℤ³ : d²|m, d|ℓ} 与 ℤ³（对固定 n 的 (m′,ℓ′) 部分）之间建立双射，逆映射为
m′=m/d², ℓ′=ℓ/d。

**证明.** 直接验证互逆：由 (m,ℓ)=(d²m′,dℓ′) 得 (m/d²,ℓ/d)=(m′,ℓ′)；由
(m′,ℓ′)=(m/d²,ℓ/d)（d²|m, d|ℓ 保证此为整数）得 (d²m′,dℓ′)=(m,ℓ)。当 d²∤m 或 d∤ℓ 时，
Ω^{(4|4)}_1(n,m/d²,ℓ/d) 不在 Ω_1 的整数格点定义域内，按惯例取值 0，故对固定 d 的求和
Σ_{n,m,ℓ} d·Ω_1(n,m/d²,ℓ/d) q^n y^ℓ p^m 自动限制在上述双射的像上，不引入重复也不遗漏
任一项。∎

### 9.3 引理 9.2（字面读法否证：命题 P 判否，AN 原生记号）

**引理 9.2.** 设 ρ_W=(½,½,½)（§7 S1/S2，GN1998 M₁=U(4)⊕ℤ₂ 的 Weyl 向量，三分量按
(τ,z,σ) 顺序排列），典范前因子 e^{2πi(ρ_W,Z)} = e^{iπ(τ+z+σ)}。设 𝒱_d 为 A-N eq(2.13)
本身给出的重标度 (τ,z,σ)↦(τ,dz,d²σ)（τ 不变、z 方向乘 d、σ 方向乘 d²——这正是本文
§5 第 2 步换元 m=d²m′,ℓ=dℓ′ 所隐含的坐标伸缩）。则

    e^{2πi(ρ_W,𝒱_dZ)} = e^{iπ[τ+dz+d²σ]} = e^{2πi(ρ_W',Z)},   ρ_W' = (½, d/2, d²/2).

即 𝒱_d 把典范前因子映为对应"新 Weyl 向量" ρ_W'=(½,d/2,d²/2) 的前因子——ρ_W 的
**乘性重标**（τ 分量不变、z 分量乘 d、σ 分量乘 d²），不含任何与 Z 无关的加性相位。

**证明.** 直接代入计算：(ρ_W,𝒱_dZ) = ½τ + ½(dz) + ½(d²σ) = ½τ + (d/2)z + (d²/2)σ =
(ρ_W',Z)，其中 ρ_W'=(½,d/2,d²/2)。∎

**推论（命题 P 判否）.** 假设存在与 Z 无关的常数 δ=(δ_τ,δ_z,δ_σ) 使
e^{2πi(ρ_W,𝒱_dZ)} = C·e^{2πi(ρ_W,Z+δ)} 对所有 Z 恒成立（C 与 Z 无关）。比较两边关于 σ
的系数：左边 d²/2，右边 ρ_{W,σ}=½。此式要求 d²/2=½ 对所有 d 成立，仅当 d=1。故对
d≥2，不存在纯加性平移 δ 能吸收 𝒱_d 对裸前因子的作用：𝒱_d 读出的是 Weyl 向量的
乘性重标度，不是可以写成"(τ,z,σ)↦(τ,z,σ)+δ"的加性平移。∎

（脚注：`weyl-shift-diagnostic/proof.md` §2 原文用 DGM 矩阵形式计算此结果，因槛位
对齐 bug 得到互换了 τ、σ 角色的三元组 (d²/2,d/2,½)；该处已在原文件订正。本节直接在

### 9.4 引理 9.3（A-N 符号惯例即 Weyl 分量平移）

**引理 9.3.** 定义"裸"（无符号）生成函数

    Z̃^{(4|4)}_1(τ,z,σ) := Σ_{n,m,ℓ} Ω^{(4|4)}_1(n,m,ℓ) q^n y^ℓ p^m

（与 A-N eq(2.11) 的 Z_1 相比，去掉 (−1)^ℓ 因子）。记 ρ_{W,z}:=½（ρ_W 的椭圆分量，
§9.3 已确立）。则

    Z^{(4|4)}_1(τ,z,σ) = Z̃^{(4|4)}_1(τ, z+ρ_{W,z}, σ),   等价地   Z̃_1(τ,w,σ) = Z_1(τ,w−ρ_{W,z},σ).

**证明.** (−1)^ℓ = e^{iπℓ} = e^{2πi·ρ_{W,z}·ℓ}（ρ_{W,z}=½）。代入 A-N eq(2.11)：

    Z_1(τ,z,σ) = Σ (−1)^ℓ Ω_1 q^n y^ℓ p^m = Σ Ω_1 q^n (e^{2πiρ_{W,z}}y)^ℓ p^m
               = Σ Ω_1 q^n e^{2πi(z+ρ_{W,z})ℓ} p^m = Z̃_1(τ,z+ρ_{W,z},σ). ∎

**要点.** A-N 选择用 (−1)^ℓ 打包符号这一约定，等价于把"裸"生成函数在椭圆方向平移了
ρ_{W,z}=½——这个平移量恰好数值等于 GN1998 Weyl 向量的椭圆分量（§7 S1/S2 已确立的
独立事实），但引理 9.3 本身的证明**不需要**引用 GN1998 或 Weyl 向量——即使不知道
"½ 恰好是某个 BKM 代数的 Weyl 向量分量"，纯从 (−1)^ℓ=e^{iπℓ} 这条初等恒等式出发也
能得到同样的结论。"ρ_{W,z}" 这个名字只是给这个恒等出现的常数 ½ 一个有意义的名字。

### 9.5 引理 9.4（裸函数的除子和公式没有平移）

**引理 9.4.** 对所有正整数 I，

    Z̃^{(4|4)}_I(τ,z,σ) = Σ_{d|I} d · Z̃^{(4|4)}_1(τ, dz, d²σ).

**证明.** 由 A-N eq(2.13)（与符号无关的定义）：

    Z̃_I = Σ_{n,m,ℓ} Ω_I(n,m,ℓ) q^n y^ℓ p^m = Σ_{n,m,ℓ} [Σ_{d|I} d·Ω_1(n,m/d²,ℓ/d)] q^n y^ℓ p^m
        = Σ_{d|I} d · Σ_{n,m,ℓ} Ω_1(n,m/d²,ℓ/d) q^n y^ℓ p^m.

对固定 d，用引理 9.1 的双射换元 m=d²m′,ℓ=dℓ′：

    Σ_{n,m,ℓ} Ω_1(n,m/d²,ℓ/d) q^n y^ℓ p^m = Σ_{n,m',ℓ'} Ω_1(n,m',ℓ') q^n (y^d)^{ℓ'} (p^{d²})^{m'}
        = Σ_{n,m',ℓ'} Ω_1(n,m',ℓ') q^n y^{dℓ'} p^{d²m'} = Z̃_1(τ,dz,d²σ).

代回即得 Z̃_I = Σ_{d|I} d·Z̃_1(τ,dz,d²σ)。∎

**要点.** 这一步比引理 B.2 更简单——不需要分析任何符号因子，因为裸生成函数没有
(−1)^ℓ 需要处理：**裸的除子和恒等式是纯伸缩，没有加性平移**。(d−1)/2 的出现完全是
引理 9.3 所述"A-N 选择用 (−1)^ℓ 打包符号"这一约定的后果，不是 Φ₁₀ 或除子和组合结构
本身固有的性质。

### 9.6 定理 9（= 命题 B，第二条证明）

**定理 9.** 对所有正整数 I，

    Z^{(4|4)}_I(τ,z,σ) = Σ_{d|I} d · Z^{(4|4)}_1(τ, dz+(d−1)/2, d²σ) = Σ_{d|I} d/Φ₁₀(τ,dz+(d−1)/2,d²σ),

即命题 B 的 (**) 式。

**证明.** 由引理 9.3（取 I 的下标，同一引理对任意整数值数组 {Ω_I(n,m,ℓ)} 都成立，与
Ω_I 具体是什么无关）：

    Z_I(τ,z,σ) = Z̃_I(τ,z+ρ_{W,z},σ) = Z̃_I(τ,z+½,σ).

代入引理 9.4：

    Z̃_I(τ,z+½,σ) = Σ_{d|I} d·Z̃_1(τ, d(z+½), d²σ) = Σ_{d|I} d·Z̃_1(τ, dz+d/2, d²σ).

再用引理 9.3 的逆关系 Z̃_1(τ,w,σ)=Z_1(τ,w−½,σ)，取 w=dz+d/2：

    Z̃_1(τ,dz+d/2,d²σ) = Z_1(τ,dz+d/2−½,d²σ) = Z_1(τ,dz+(d−1)/2,d²σ).

代回：

    Z_I(τ,z,σ) = Σ_{d|I} d·Z_1(τ,dz+(d−1)/2,d²σ) = Σ_{d|I} d/Φ₁₀(τ,dz+(d−1)/2,d²σ). ∎

**机制小结.** 位移 (d−1)/2 分解为两项：
- **+d/2**：来自"先在原坐标平移 ρ_{W,z}=½，再作用椭圆伸缩 z↦dz"——伸缩在平移之后，
  平移量被放大了 d 倍：½↦d·½=d/2（平移经伸缩共轭的标准规律：T_a 后接伸缩-by-d，
  等于伸缩-by-d 后接 T_{da}，对任意 d 严格成立）。
- **−½**：来自"用 Z_1（已内嵌 ρ_{W,z} 平移）而非裸生成函数 Z̃_1 表出等式右边"这一步
  反过来减去了一个原始的 ρ_{W,z}。

净结果 d·ρ_{W,z}−ρ_{W,z} = (d−1)ρ_{W,z} = (d−1)/2，**对所有正整数 d 同时成立**（一般
d 的代数恒等式，不是逐个 d 凑出来的数值巧合；`weyl-shift-diagnostic/scripts/weyl_shift_check.py`
§3 用 SymPy 对符号 d 精确验证过这一点，见 §9.9）。

### 9.7 交叉验证：与 ε=−i 吻合（本文 §7 S3）

### 9.9 本节 GAP 记录
