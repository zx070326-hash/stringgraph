## 2. Lemma B.1（换元的双射性）

**引理 B.1.** 设 d ≥ 1 是正整数，S_d := {(n,m,ℓ) ∈ ℤ³ : Ω^{(4|4)}_1(n,m,ℓ) ≠ 0}。定义映射
φ_d : S_d → ℤ³ 为 φ_d(n,m,ℓ) = (n, d²m, dℓ)，其像为

    T_d := {(n,M,L) ∈ ℤ³ : d²|M, d|L, Ω^{(4|4)}_1(n, M/d², L/d) ≠ 0}.

则 φ_d : S_d → T_d 是双射。等价地，换元 (m,ℓ) ↦ (m',ℓ') := (m/d², ℓ/d) 建立 T_d 与 S_d 之间的双射，
且对固定 d，它不引入重复或遗漏。

**证明.** 构造逆映射。对 (n,M,L) ∈ T_d，定义 ψ_d(n,M,L) = (n, M/d², L/d)。
由 T_d 的定义，d²|M 且 d|L，故 M/d² 与 L/d 均为整数，ψ_d 的值域在 ℤ³ 内。

验证 ψ_d ∘ φ_d = id_{S_d}：对 (n,m,ℓ) ∈ S_d，
    ψ_d(φ_d(n,m,ℓ)) = ψ_d(n,d²m,dℓ) = (n, d²m/d², dℓ/d) = (n,m,ℓ). ✓

验证 φ_d ∘ ψ_d = id_{T_d}：对 (n,M,L) ∈ T_d，
    φ_d(ψ_d(n,M,L)) = φ_d(n,M/d²,L/d) = (n, d²·(M/d²), d·(L/d)) = (n,M,L). ✓

因此 φ_d 和 ψ_d 互逆，φ_d : S_d → T_d 是双射。

**格点完整性（无重复无遗漏）.** 上述双射确保：对固定 d，以 (m',ℓ') 对所有使 Ω_1(n,m',ℓ') ≠ 0 的
格点 (n,m',ℓ') 求和，与以 (m,ℓ) 对 T_d 中格点求和，枚举的项完全相同（一一对应）。∎

## 3. Lemma B.2（指数恒等式）

**引理 B.2.** 设 d ≥ 1 是正整数，z ∈ ℂ，令 y = e^{2πiz}。对任意整数 ℓ' ∈ ℤ，令

    z_new := dz + (d−1)/2.

则以下等式在 ℂ 中对所有 ℓ' ∈ ℤ 成立：

    (−1)^{dℓ'} · y^{dℓ'} = (−1)^{ℓ'} · e^{2πi z_new ℓ'}.

**证明.** 逐步展开右端：

**第 1 步.** 代入 z_new 的定义：

    e^{2πi z_new ℓ'} = e^{2πi(dz + (d−1)/2)ℓ'}
                     = e^{2πi·dz·ℓ'} · e^{2πi·(d−1)/2·ℓ'}.

**第 2 步.** 化简第一因子。由 y = e^{2πiz}：

    e^{2πi·dz·ℓ'} = (e^{2πiz})^{dℓ'} = y^{dℓ'}.

**第 3 步.** 化简第二因子：

    e^{2πi·(d−1)/2·ℓ'} = e^{iπ(d−1)ℓ'} = (e^{iπ})^{(d−1)ℓ'} = (−1)^{(d−1)ℓ'}.

**第 4 步.** 合并：

    (−1)^{ℓ'} · e^{2πi z_new ℓ'} = (−1)^{ℓ'} · y^{dℓ'} · (−1)^{(d−1)ℓ'}
                                  = (−1)^{ℓ' + (d−1)ℓ'} · y^{dℓ'}
                                  = (−1)^{dℓ'} · y^{dℓ'}.

此即左端。∎

**注 B.2.1（唯一性）.** 使等式成立的 z_new（模整数周期）唯一由 y^{dℓ'} 的系数与 (−1)^{ℓ'} 的比较确定：
需要 e^{2πi(z_new − dz)ℓ'} = (−1)^{(d−1)ℓ'} = e^{iπ(d−1)ℓ'} 对所有 ℓ' 成立，
故 z_new − dz ≡ (d−1)/2 (mod 1)，即 z_new = dz + (d−1)/2 + k 对某整数 k，
但 k 对 1/Φ₁₀ 的展开式无影响（由整周期性，模整数平移等价）。

## 4. Lemma B.3（Φ₁₀ 的半整平移分析）

**引理 B.3.** 设 d ≥ 1，z_new = dz + (d−1)/2，则：

**(a) d 奇时：** (d−1)/2 ∈ ℤ（因 d−1 是偶数，(d−1)/2 为整数）。
由周期性 [周期性]，对任意整数 k：Φ₁₀(τ, z+k, σ) = Φ₁₀(τ,z,σ)。取 k=(d−1)/2 ∈ ℤ，得

    Φ₁₀(τ, dz+(d−1)/2, d²σ) = Φ₁₀(τ, dz, d²σ).

即奇 d 的平移在 Φ₁₀ 的值上无效果（由整周期性消去）。

**(b) d 偶时：** d−1 是奇数，(d−1)/2 ∉ ℤ 是半整数（即形如整数加 1/2）。
整周期性不能消去半整平移，因此

    Φ₁₀(τ, dz+(d−1)/2, d²σ) ≠ Φ₁₀(τ, dz, d²σ)

一般地成立（平移非平凡）。具体地：d=2 时平移为 1/2，d=4 时平移为 3/2，d=6 时平移为 5/2，均为半整数。

**证明.** (a) 整除性：d 奇则 d−1 偶，故 (d−1)/2 = (d−1)/2 ∈ ℤ。整周期性逐次用整数 1 叠加即得。
(b) d 偶则 d−1 奇，故 (d−1)/2 = (整数)+1/2，即半整数，不在整数平移格内。
不等式：反设对所有 (τ,z,σ) 均有 Φ₁₀(τ, dz+1/2, d²σ)（以 d=2 为例）= Φ₁₀(τ, dz, d²σ)，
则将 z↦z+1/2 代入 Φ₁₀(τ,z,σ)（令 z=dz）得 Φ₁₀(τ,z+1/2,σ) = Φ₁₀(τ,z,σ) 对一切 z，
即 Φ₁₀ 在 z 方向有 1/2-周期。但 Φ₁₀ 作为 index-1 Jacobi 形式，其 Laurent 展开含 y^{奇数} 项
（例如 y^{-1} 或 y^1 项，由 Borcherds 乘积的 c(4mn−ℓ²) 在 ℓ 奇时非零保证），
而 y^{ℓ} 在 y↦e^{iπ}y = −y 即 z↦z+1/2 下变为 (−1)^ℓ y^ℓ，对奇 ℓ 差一个负号，矛盾。∎

**支撑 B.3(b) 的前提（Φ₁₀ 展开式含奇 ℓ 项，已坐实）：** 上述矛盾论证用到"Φ₁₀ 的
Fourier-Laurent 展开含 y^{奇数} 项"，即 Borcherds 乘积中 ℓ 为奇时系数 c(4mn−ℓ²) 非零。
两条独立逐字来源坐实之：

1. `kawai-1997` eq.(4.32)（逐字）：c(0)=20, c(−1)=2, c(N)=0 (N<−1)。在乘积 eq.(5.13) 中取
   三元组 (k,l,r)=(0,1,1)（判别式 4·0·1 − 1² = −1，奇 ℓ=1），得指数 c(−1)=2≠0，故乘积含
   因子 (1 − q^0 p^1 y^1)² = (1−py)²，展开含非零 y^1 项（奇 ℓ）。(k,l,r)=(0,1,1) 满足乘积指标集
   （k=0, l=1>0），详见抽取记录 §E2。
2. `dabholkar-murthy-zagier-2012`（DMZ）§4.3 eq.(85)（逐字）：φ_{−2,1}(τ,z)=(y−2+y⁻¹)+O(q)，
   Table 1 C_{−2}(−1)=1≠0。二重佐证。(ℓ=1 对应判别式 −1，C_{−2}(−1)=1≠0。)

**约定注（关键，避免混淆）：** 本 proof 中乘积公式所用的 c(k) 指**指标 1 弱 Jacobi 形式
φ_{−2,1} 的 Fourier 系数**（即 DMZ 记号 C_{−2}(k)，Table 1 给 C_{−2}(−1)=1）。而 `kawai-1997`
的 c(−1)=2 是 **K3 椭圆亏格**系数（= φ_{−2,1} 系数乘 −2 的整体归一化）。两套系数相差整体因子 −2，
但均给 c(−1)≠0；B.3(b) 的非平凡性只需**非零性**，与归一化无关。

此为 Lemma B.3(b) 的严格性所需；(a) 部分无此需求。

## 5. 命题 B 的证明

**命题 B.** 在上述记号下，∀ 正整数 I，∀ (τ,z,σ) 在形式 Fourier 展开收敛的域内：

    Z^{(4|4)}_I(τ,z,σ) = Σ_{d|I} d / Φ₁₀(τ, dz+(d−1)/2, d²σ).    (**)

**证明.**

**第 1 步（代入 eq(2.13) 并交换求和序）.**

由定义（eq(2.11)）：

    Z^{(4|4)}_I(τ,z,σ) = Σ_{n,m,ℓ ∈ ℤ} (−1)^ℓ Ω^{(4|4)}_I(n,m,ℓ) q^n y^ℓ p^m.

将 eq(2.13) 代入：

    Z^{(4|4)}_I = Σ_{n,m,ℓ} (−1)^ℓ [Σ_{d|I} d · Ω_1(n, m/d², ℓ/d)] q^n y^ℓ p^m.

交换求和序（在形式幂级数层面合法，因为对固定 d，内部和是有限重组）：

    = Σ_{d|I} d · Σ_{n,m,ℓ} (−1)^ℓ Ω_1(n, m/d², ℓ/d) q^n y^ℓ p^m.    (I)

注意：当 d²∤m 或 d∤ℓ 时，Ω_1(n, m/d², ℓ/d) = 0（因 Ω_1 只在整数三元组上非零），
故和式实际上只对满足 d²|m 和 d|ℓ 的 (n,m,ℓ) 有贡献。

**第 2 步（对固定 d 换元）.**

对固定 d，令 m = d²m', ℓ = dℓ'（其中 m', ℓ' ∈ ℤ）。由 Lemma B.1，此换元建立所有使
Ω_1(n, m/d², ℓ/d) 非零的格点 (n,m,ℓ) 与所有使 Ω_1(n,m',ℓ') 非零的格点 (n,m',ℓ') 之间的
双射（对固定 d），不引入重复或遗漏。代入 (I)：

    Σ_{n,m,ℓ} (−1)^ℓ Ω_1(n, m/d², ℓ/d) q^n y^ℓ p^m
    = Σ_{n,m',ℓ'} (−1)^{dℓ'} Ω_1(n, m', ℓ') q^n y^{dℓ'} p^{d²m'}.    (II)

**第 3 步（应用 Lemma B.2 改写指数因子）.**

由 Lemma B.2（取 ℓ' 为当前求和变量）：

    (−1)^{dℓ'} · y^{dℓ'} = (−1)^{ℓ'} · e^{2πi z_new ℓ'},    z_new = dz+(d−1)/2.

令 y_new = e^{2πi z_new} = e^{2πi(dz+(d−1)/2)}，则 e^{2πi z_new ℓ'} = y_new^{ℓ'}。代入 (II)：

    Σ_{n,m',ℓ'} (−1)^{ℓ'} Ω_1(n, m', ℓ') q^n y_new^{ℓ'} (p^{d²})^{m'}.    (III)

**第 4 步（识别为 Z^{(4|4)}_1）.**

令 p_new = e^{2πi d²σ} = p^{d²}，则 (III) 正是：

    Σ_{n,m',ℓ'} (−1)^{ℓ'} Ω_1(n,m',ℓ') q^n y_new^{ℓ'} p_new^{m'} = Z^{(4|4)}_1(τ, z_new, d²σ).

由 eq(2.11)（第二等式）：

    Z^{(4|4)}_1(τ, dz+(d−1)/2, d²σ) = 1/Φ₁₀(τ, dz+(d−1)/2, d²σ).

**第 5 步（合并）.**

代回 (I)：

    Z^{(4|4)}_I(τ,z,σ) = Σ_{d|I} d · Z^{(4|4)}_1(τ, dz+(d−1)/2, d²σ)
                        = Σ_{d|I} d / Φ₁₀(τ, dz+(d−1)/2, d²σ).

此即 (**) 式。∎

## 6. 推论 B1（与 DGM eq(51) 的比较）

**推论 B1.** 用 DGM/Rosselló 记号（ρ 对应 A-N 的 τ，v 对应 A-N 的 z，σ 对应 A-N 的 σ），
令 s = d 为除子，则命题 B 在 DGM 记号下写为：

    𝒵_I(ρ,σ,v) = Σ_{s|I} s / Φ₁₀(ρ, sv+(s−1)/2, s²σ).    (**)_DGM

（此处变量对应：τ↦ρ, z_new = dz+(d−1)/2 ↦ sv+(s−1)/2, d²σ ↦ s²σ。）

**与 DGM eq(51) 的精确差别（来自 `literature/extractions/dabholkar-gomes-murthy-2008.md` §S2）：**

DGM eq(51)（逐字）：`𝒵_I(ρ,σ,v) = Σ_{s|I} s · 1/Φ₁₀(s²ρ, σ, sv)`，
注意 DGM 的 Φ₁₀ 参数顺序为 (s²ρ, σ, sv)（即 Jacobi 指标挂在 ρ 上），
而 (**) 式中 Φ₁₀(ρ, sv+(s−1)/2, s²σ)（指标挂在 σ 上）。

**注（约定差异与本质差别的分离）.** DGM 与 A-N 在 ρ↔σ 位置上的约定差异是纯重标，不影响比较。
在相同约定下，两式的本质差别是：
- 命题 B（(**) 式）：Φ₁₀ 的椭圆变量参数为 sv + (s−1)/2。
- DGM eq(51)：Φ₁₀ 的椭圆变量参数为 sv（无平移）。

**奇偶分析（由 Lemma B.3）：**

- s 奇时：(s−1)/2 ∈ ℤ，由 Φ₁₀ 整周期性：Φ₁₀(ρ, sv+(s−1)/2, s²σ) = Φ₁₀(ρ, sv, s²σ)。
  即奇除子项两公式结果相同——(s−1)/2 是整平移，被 Φ₁₀ 吸收。

- s 偶时：(s−1)/2 是半整数（不在 ℤ 内），平移不可消去。
  两公式的 s 偶除子项一般给出不同值（见 torsion-immortal-positivity-hecke/proof.md §5 的显式整数见证，
  I=2, s=2, (m,n,ℓ)=(4,1,2) 处两读法差 101412 = 4·d_*(1,1,1)）。

**结论：** DGM eq(51) 与从 A-N eq(2.11)+(2.13) 纯代数导出的 (**) 式，在所有偶数除子 s 上均有差别，
差别恰好是半整平移 (s−1)/2；在奇数除子 s 上（通过整周期性）两式等价。

**命题 S2.** 令 H_r := f₃/2 ∈ M₁ ⊗_ℤ ℚ ⊂ h。则对所有根 α = (n,l,m) = nf₂+lf₃+mf₋₂：

**证明.** 直接由 Gram 矩阵计算：

    (H_r, (n,l,m)) = (f₃/2, nf₂+lf₃+mf₋₂)

**S3 分析：扭转分母 Den_ω 与 Φ₁₀ 的关系——发现权重不匹配**

**计算.** G 的未扭转分母为 ψ₅（权重 5）：

    ψ₅(τ,z,σ) = (qrs)^{1/2} ∏_{(n,l,m)>0} (1 - q^n r^l s^m)^{f₁(nm,l)}

（GN1998 eq.(2.16)，Weyl 向量 ρ=(½,½,½)，q=e^{2πiτ}，r=e^{2πiz}，s=e^{2πiσ}）。

在 ω 下，每个正根空间 g_{(n,l,m)} 的本征值为 (-1)^l（命题 S2b(i)）。扭转分母（BKM 扭转分母恒等式的乘积侧，将每个因子加入 ω 的本征值权重）：

    Den_ω(τ,z,σ) = e^{πi(τ+z+σ)} ∏_{(n,l,m)>0} (1 - (-1)^l · q^n r^l s^m)^{f₁(nm,l)}.

对比 ψ₅ 在 z+½ 处的值（令 r → e^{iπ}r = -r）：

    ψ₅(τ, z+½, σ) = (q·(-r)·s)^{1/2} ∏_{(n,l,m)>0} (1 - (-1)^l q^n r^l s^m)^{f₁(nm,l)}
                  = e^{iπ/2}·(qrs)^{1/2} ∏_{(n,l,m)>0} (1 - (-1)^l q^n r^l s^m)^{f₁(nm,l)}
                  = i · e^{πi(τ+z+σ)} ∏_{(n,l,m)>0} (1 - (-1)^l q^n r^l s^m)^{f₁(nm,l)}.

因此：

    Den_ω(τ,z,σ) = (-i) · ψ₅(τ, z+½, σ).    [S3-result]

（常数因子 -i 来自 Weyl 向量 ρ 在 r→-r 下的贡献：(−r)^{1/2} = e^{iπ/2}r^{1/2} = i·r^{1/2}。）

**权重不匹配（原命题 Den_ω = C·Φ₁₀ 表述有误）.** 由 [S3-result]：

- Den_ω = (-i)·ψ₅(τ,z+½,σ) 是**权重 5** 的 Siegel 模形式；
- Φ₁₀(τ,z+½,σ) = ψ₅(τ,z+½,σ)² 是**权重 10** 的 Siegel 模形式。

两者权重差 5，不可能相差一个常数（常数只能在同权重的非零形式之间建立比例关系）。

的内部结论"，未标引用；现补上逐字来源：`gritsenko-nikulin-1996`（alg-geom/9611028 的姊妹篇

**正确表述（对 GN1998 代数 G，在收敛域内）：**

**约定**：采用 Weyl 向量 ρ=(½,½,½) 的典范前因子形式（GN1998 §5.1 分母恒等式 eq.(5.1) 标准写法）：

    Den_ω(τ,z,σ) = e^{2πi(ρ,Z)} · ∏_{(n,l,m)>0} (1 - (-1)^l q^n r^l s^m)^{f₁(nm,l)}
    ψ₅(τ,z,σ)    = e^{2πi(ρ,Z)} · ∏_{(n,l,m)>0} (1 - q^n r^l s^m)^{f₁(nm,l)}

其中 Z=[[τ,z],[z,σ]], (ρ,Z) = ½(τ+z+σ)（Weyl 向量与 Siegel 上半空间变量的内积）。

在该约定下（详见下方"严格论证"）：

**严格论证（P2: 从数值证据升级为证明）**：

(1) **前因子的典范性**：GN1998 分母恒等式 eq.(5.1)（§5.1, p.55–56）对所有 BKM 超代数给出统一形式

    Φ(Z) = q^{ρ₁} r^{ρ₂} s^{ρ₃} ∏_{(n,l,m)>0} (1 - q^n r^l s^m)^{f(n,l,m)}
         = e^{2πiρ₁τ} e^{2πiρ₂z} e^{2πiρ₃σ} · [乘积]
         = e^{2πi(ρ,Z)} · [乘积]

其中 ρ=(ρ₁,ρ₂,ρ₃) 是格 M_t ⊗ ℚ 中的 Weyl 向量，由 (ρ,α) = −(α,α)/2 对所有简单实根 α∈P(M) 唯一确定
（GN1998 §5.1 E4，逐字）。对 ψ₅，根格 M₁=U(4)⊕ℤ₂ 的 Weyl 向量为 ρ=(½,½,½)（GN1998 §2.2 eq.(2.16)）。
**因此 e^{2πi(ρ,Z)} = e^{πi(τ+z+σ)} 是该 BKM 代数的典范前因子，不是任意记号选择**——它直接来自
Weyl–Kac–Borcherds 分母公式中的 e^{ρ} 项。

(2) **单连通域上的全纯性**：Siegel 乘积在 τ,z,σ 虚部充分大时收敛（GN1996 Appendix B, p.37：
"the given infinite product absolutely converges for all Im(Z)>C for a large C>0"），收敛域同构于凸锥
上的管状域（tube domain over a convex cone），**单连通**。在该域上：
  - e^{2πi(ρ,Z)} 是**单值全纯函数**（指数函数在单连通域上单值）；
  - 乘积 ∏(1−q^n r^l s^m)^{f₁(nm,l)} 全纯非零（乘积展开收敛保证）；
  - 若采用多值记号 (qrs)^{1/2}，其主值分支在域内被 arg(qrs)=±π 的切割线切开，不是单值。

因此 ψ₅ 与 Den_ω **在典范约定 e^{2πi(ρ,Z)} 下才是单值全纯的**；(qrs)^{1/2} 记号隐含了分支选择。

(3) **比值的恒等计算**：在收敛域内，Den_ω 与 ψ₅(z+½) 均全纯非零，比值全纯。逐点计算：

    Den_ω(τ,z,σ) / ψ₅(τ, z+½, σ)
    = [e^{πi(τ+z+σ)} · ∏(1−(−1)^l q^n r^l s^m)^{f₁}] / [e^{πi(τ+z+½+σ)} · ∏(1−q^n (−r)^l s^m)^{f₁}]
    = e^{πi(τ+z+σ) − πi(τ+z+½+σ)} · [∏(1−(−r)^l ...)^{f₁} / ∏(1−(−r)^l ...)^{f₁}]
    = e^{−πi/2} · 1
    = −i.

**结论**：Den_ω/ψ₅(z+½) 在单连通收敛域上处处等于 −i，这是全纯函数恒等式，不是 4 个采样点的巧合。
