- `𝔥 := ℂ^D`，`⟨u,v⟩ := Σ_μ η_μ u^μ v^μ`（= `η_{μν}u^μv^ν`，因 `η` 对角），在 `ℂ` 上非退化。
  对 `R^D` 中向量同样写 `x·y = ⟨x,y⟩`。
- **`α'`-无量纲化字典**：`q̃ := (2α')^{1/2} q`，于是 `⟨q̃_1, q̃_2⟩ = 2α'(q_1·q_2)`。
- `k_0 ∈ R^D \ {0}` **类光**：`k_0² = 0`。记 `k := k̃_0`，`L := Zk`（秩 1），故 `⟨·,·⟩|_L ≡ 0`。

### §1.2 物理侧（左端）：三个构件，全部取自 `formalized` 定义卡

**(P1) 逐层 Fock 空间与塔**（`worldsheet.momentum-tower-fock-space`、`worldsheet.bosonic-fock-space`）。

- `F := ℂ[X_{μ,l} : μ ∈ Fin D, l ≥ 1]`（多项式代数）。
  产生算子 `α^μ_{−l} :=` 乘以 `X_{μ,l}`；湮灭算子 `α^μ_{l} := l η_μ ∂/∂X_{μ,l}`（`l ≥ 1`）。
  由此 `[α^μ_m, α^ν_n] = m η^{μν} δ_{m+n,0}`。
- **振子能级**：`level(X_{μ_1,l_1}···X_{μ_r,l_r}) = l_1+⋯+l_r`，`F = ⊕_{M ≥ 0} F^{(M)}`，`F^{(0)} = ℂ·1`。
- `F(q) :=` 同一个 `F`，再装上零模 `α^μ_0 := (2α')^{1/2} q^μ · id`。
  🔴 该卡逐字：「**`F(q)` 作为 R-模与 `q` 无关**」——动量只经零模这一族标量进入。本证明多处用它。
- 塔 `T := T(p;k_0) := ⊕_{N ∈ Z} F(p + N k_0)`（代数直和，有限支撑）。第 `N` 层记 `T_N`，
  其真空记 `|0;N⟩ := |0; p+Nk_0⟩`（即 `T_N` 中的 `1`）。`T_N^{(M)}` 表第 `N` 层振子能级 `M` 的子空间。
- **移位算子** `S_n : T → T`（该卡 (1)）：把第 `N` 层的向量**逐字**送到第 `N+n` 层的同一个向量。
  `S_0 = id`，`S_m S_n = S_{m+n}`，`S_n^{−1} = S_{−n}`，`[α^μ_0, S_n] = n(2α')^{1/2}k_0^μ S_n`。
  🔴 **`S_n` 的「系数恰为 1」是这张 `formalized` 定义卡写死的**，不是本证明的选择（§2.4 会用到）。

**记号约定（本文全程）**：对 `h ∈ 𝔥` 与 `m ∈ Z` 记 `h·α_m := Σ_μ η_μ h^μ α^μ_m`。逐条展开（用 `η_μ² = 1`）：

- `h·α_{−l} =` 乘以 `Σ_μ η_μ h^μ X_{μ,l}`（`l ≥ 1`）；
- `h·α_{l} = l Σ_μ h^μ ∂/∂X_{μ,l}`（`l ≥ 1`）；
- `h·α_0|_{T_N} = ⟨h, p̃ + Nk⟩`（`h` 视为 `𝔥` 中已重标度的向量）；
- `[h·α_m, h'·α_{m'}] = m δ_{m+m',0} ⟨h,h'⟩`
  （一行核对：`Σ_{μν} η_μη_ν h^μ h'^ν · m η^{μν} δ = m δ Σ_μ η_μ h^μ h'^μ = mδ⟨h,h'⟩`）。

**(P2) 正规序指数的振子部分**（`worldsheet.exponential-vertex-operator-modes`）。对常向量 `b ∈ 𝔥`：
```
E₋(b;z) = exp( Σ_{l≥1} (b·α_{−l}/l) z^{ l} ) ,
E₊(b;z) = exp( − Σ_{l≥1} (b·α_{ l}/l) z^{−l} ) ,
E₋(b)_P := [z^P]E₋(b;z)  (P < 0 时为 0),   E₊(b)_Q := [z^Q]E₊(b;z)  (Q > 0 时为 0),
V^{(b)}_J := Σ_{P+Q=J} E₋(b)_P ∘ E₊(b)_Q      (J ∈ Z).
```
在代数 Fock 空间上逐向量是**有限和**；不需要完化、收敛性、围道。该卡的两条基本性质：

- **(E1) 级升**：`V^{(b)}_J (F^{(M)}) ⊆ F^{(M+J)}`；特别 `M + J < 0` 时 `V^{(b)}_J|_{F^{(M)}} = 0`。
- **(E2) 真空值**：`V^{(b)}_J(1) = E₋(b)_J`；特别 `V^{(b)}_0(1) = E₋(b)_0 = 1`。

🔴 `E₊` 指数上的负号是该卡写死的约定，不是本证明的选择（§5.2 会看到它恰好对上 Li–Wang 的 `−α`）。

### §2.2 引理群：真空刚性

**引理 2.1（真空的唯一性）。** 设 `v ∈ F` 满足 `(h·α_l) v = 0` 对一切 `h ∈ 𝔥` 与一切 `l ≥ 1`。
则 `v ∈ ℂ·1`。

*证明*。由 §1.2 的展开 `h·α_l = l Σ_μ h^μ ∂/∂X_{μ,l}`。取 `h = e_ν`（第 `ν` 个坐标向量，`h^μ = δ^μ_ν`）
得 `l · ∂v/∂X_{ν,l} = 0`；`ℂ` 的特征为 0 且 `l ≥ 1`，故 `∂v/∂X_{ν,l} = 0` 对一切 `ν` 与一切 `l ≥ 1`。
多项式环 `ℂ[X_{μ,l}]` 上全部一阶偏导为零的元素是常数。∎

**引理 2.2（生成性）。**
(i) `U = M(1,p̃)` 作为向量空间由 `1` 经 `{h(−m) : h ∈ 𝔥, m ≥ 1}` 反复作用张成。
(ii) `F` 由 `1` 经 `{h·α_{−m} : h ∈ 𝔥, m ≥ 1}` 反复作用张成。

*证明*。(i) 是诱导模的 PBW 描述：`U ≅ S(𝔥 ⊗ t^{−1}ℂ[t^{−1}])·1`（(V2)）。
(ii) 对每个 `m ≥ 1`，映射 `𝔥 → span_ℂ{X_{μ,m} : μ}`，`h ↦ Σ_μ η_μ h^μ X_{μ,m}`，是线性双射
（矩阵 `diag(η_μ)` 可逆，因 `η_μ = ±1`）。故 `{h·α_{−m} : h ∈ 𝔥}` 的像张成全部「乘以 `X_{μ,m}`」
的算子；而 `ℂ[X_{μ,l}]` 由 `1` 经乘变量张成。∎

**引理 2.3（典范识别 `Φ_0` 的存在唯一性）。** 存在唯一的线性映射 `Φ_0 : U → F` 满足
```
Φ_0(1) = 1 ,    Φ_0 ∘ h(m) = (h·α_m) ∘ Φ_0    (∀ h ∈ 𝔥, ∀ m ≠ 0) ,
```
且 `Φ_0` 是双射。

*证明*。记 `A := S(𝔥 ⊗ t^{−1}ℂ[t^{−1}])`，即 `{h ⊗ t^{−m} : m ≥ 1}` 上的对称代数。

*存在*。由引理 2.2(ii) 的线性双射 `𝔥 ≅ span{X_{μ,m}}`（对每个 `m ≥ 1`）诱导出对称代数的代数同构
`σ : A → F`，`h ⊗ t^{−m} ↦ Σ_μ η_μ h^μ X_{μ,m}`。又 `U` 作为 `A`-模自由、秩 1、由 `1` 生成，
故有唯一 `A`-模同构 `U ≅ A` 送 `1 ↦ 1`。令 `Φ_0` 为复合 `U ≅ A →^σ F`。
按构造 `Φ_0(1) = 1`，且对产生模（`m ≤ −1`）等变。

对湮灭模（`m ≥ 1`）的等变性：两侧的算子 `Φ_0 ∘ h(m)` 与 `(h·α_m) ∘ Φ_0` 都把 `1` 送到 `0`
（`h(m)1 = 0`；`(h·α_m)1 = 0`），且两侧满足**同一条**递推——由 §1.2 与 (V1) 的对易关系，
```
h(m)·(h'(−m')u)         = h'(−m')·h(m)u        + m δ_{m,m'}⟨h,h'⟩ u ,
(h·α_m)(h'·α_{−m'}w)    = (h'·α_{−m'})(h·α_m)w + m δ_{m,m'}⟨h,h'⟩ w ,
```
两条的常数项**逐字相同**（这正是「(V1) 的 level-1 Heisenberg 归一化 = §1.2 的 `α` 归一化」这件事；
它使 `α'`-字典在两侧一致，见 §1.1）。对 `u` 的 PBW 次数作归纳：次数 0 已核；次数 `r+1` 的元
`h'(−m')u` 由归纳假设与上面两条递推立即给出等式。故等变性成立。

*双射*。`σ` 与 `U ≅ A` 都是双射，复合仍是。

*唯一*。设 `Φ, Φ'` 都满足条件。`Φ − Φ'` 把 `1` 送到 `0` 且与一切产生模交换，
由引理 2.2(i) 它在 `U` 上恒为 `0`。∎

⚠ **`Φ_0` 与层无关**：它的定义只用到 `{h(m)}_{m≠0}` 与 `{h·α_m}_{m≠0}`，而 (P1) 明言
「`F(q)` 作为模与 `q` 无关」、非零模的作用逐层相同。故同一个 `Φ_0` 可以放在任何一层上。

### §2.3 规范刚性：分层等变同构恰好构成一个 `(ℂ^×)^Z`-旋子

**定义 2.4。** 对 `c = (c_j)_{j∈Z} ∈ (ℂ^×)^Z` 定义
```
Φ_c : W → T ,    Φ_c(e^{jk} ⊗ w) := c_j · Φ_0(w) ∈ T_j .
```
记 `Φ := Φ_1`（常值 `c_j ≡ 1`），即 `claim.md` §1.5 的那个映射。

**引理 2.5（分类）。** `Ψ : W → T` 是分层等变同构（定义 1.3）**当且仅当**存在唯一的
`c ∈ (ℂ^×)^Z` 使 `Ψ = Φ_c`。

*证明*。(⇐) 直接核对：(Φ1) 由构造；(Φ3) 由引理 2.3 的等变性，因 `c_j` 是标量、与算子交换，
且 `h(m)`（`m ≠ 0`）保持 `W` 的层指标（它只作用在 `U` 因子上）。

(⇒) 由 (Φ1) 与双射性，`Ψ` 逐层限制为双射 `Ψ_j : U → T_j = F`，且由 (Φ3) 对一切 `m ≠ 0` 等变。
令 `v := Ψ_j(1) ∈ F`。对 `l ≥ 1`：`(h·α_l)v = Ψ_j(h(l)·1) = Ψ_j(0) = 0`（(V2)：`h(l)1 = 0`，`l ≥ 1`）。

于是 `Ψ_j` 与 `c_j Φ_0` 都送 `1 ↦ c_j·1` 且都与全部产生模交换；由引理 2.2(i) 二者相等。
唯一性显然（`c_j` 由 `Ψ_j(1)` 读出）。∎

**引理 2.6（规范对结论的作用）。** 设 `Ψ = Φ_c`。则对一切 `n, K ∈ Z`，在第 `j` 层上
```
( Φ_c ∘ [x^K]𝒴_n(x) ∘ Φ_c^{−1} ) |_{T_j}  =  (c_{j+n}/c_j) · ( Φ ∘ [x^K]𝒴_n(x) ∘ Φ^{−1} ) |_{T_j} .

*证明*。`Φ_c = Φ ∘ D_c`，其中 `D_c : W → W` 在 `W_j` 上是标量 `c_j`。由 (3.14)，`𝒴_n` 把 `W_j`

**命题 2.7（规范刚性；本节主结果）。** 设 `Ψ` 是任一分层等变同构，写 `Ψ = Φ_c`（引理 2.5）。

且此时 `Ψ ∘ (·) ∘ Ψ^{−1} = Φ ∘ (·) ∘ Φ^{−1}`（共轭作用**与 `c` 的取值完全无关**）。

*证明*。本命题的陈述以 §5 的定理 5.7（它断言 `Φ ∘ [x^K]𝒴_n ∘ Φ^{−1} = 𝒫_{n,K}`）为输入；

### §3.2 本节的策略：把「一个约定」换成「三条可独立核对的性质」

### §3.3 刻画所用的三条性质

设 `n ∈ Z` 固定。称算子族 `A = {A_K}_{K ∈ Z} ⊆ End_ℂ(T)` 是 **`n`-型顶点族**，若：

- **(C1) 层移位 + 精确级升**：对一切 `N ∈ Z`、`M ≥ 0`、`K ∈ Z`，
  ```
  A_K ( T_N^{(M)} ) ⊆ T_{N+n}^{(M + K − nν)}
  ```
  （约定 `T_{N'}^{(M')} = 0` 当 `M' < 0`；故 `M + K − nν < 0` 时 `A_K|_{T_N^{(M)}} = 0`）。
- **(C2) 振子对易**：对一切 `h ∈ 𝔥` 与一切 `m ∈ Z`，
  ```
  [ h·α_m , A_K ] = ⟨h, n k⟩ · A_{K−m}     (∀K ∈ Z) .
  ```
- **(C3) 真空值归一**：`A_{nν} |0;N⟩ = |0;N+n⟩`，对一切 `N ∈ Z`。

**注 3.1（(C2) 在 `m = 0` 处是 (C1) 的推论，不是独立假设）。**
设 `A` 满足 (C1)，`v ∈ T_N`。由 §1.2，`h·α_0` 在 `T_N` 上是标量 `⟨h, p̃+Nk⟩`，在 `T_{N+n}` 上是
`⟨h, p̃+(N+n)k⟩`。而 (C1) 给 `A_K v ∈ T_{N+n}`。故
```
[h·α_m, A_K]v |_{m=0} = ⟨h, p̃+(N+n)k⟩A_K v − ⟨h, p̃+Nk⟩A_K v = ⟨h, nk⟩ A_K v ,
```
正是 (C2) 在 `m = 0` 的内容（`A_{K−0} = A_K`）。∎
⇒ 下面的唯一性证明**只用到 (C2) 的 `m ≠ 0` 部分**；`m = 0` 部分列在 (C2) 里只是为了让该性质
在物理侧读起来是熟悉的那一条（「与 `α^μ_m` 的对易子对一切 `m` 同一个形状」）。

### §3.4 刻画定理

**引理 3.2（逐层振子对易子）。** 设 `b ∈ 𝔥`。则在 `F` 上，对一切 `h ∈ 𝔥`、`m ≠ 0`、`J ∈ Z`，
```
[ h·α_m , V^{(b)}_J ] = ⟨h,b⟩ · V^{(b)}_{J−m} ;
```
而对 `m = 0`（在固定层 `F(q)` 上）`[h·α_0, V^{(b)}_J] = 0`。

*证明*。记生成级数 `V^{(b)}(z) := E₋(b;z)E₊(b;z) = Σ_J V^{(b)}_J z^J`（(P2)；逐向量有限和，
故可以在 `(End F)[[z,z^{−1}]]` 里做形式计算）。

**情形 `m ≥ 1`。** 由 §1.2 的对易关系，对 `l, l' ≥ 1` 有 `[h·α_m, b·α_{l'}] = m δ_{m+l',0}⟨h,b⟩ = 0`
（因 `m + l' ≥ 2 > 0`），故 `h·α_m` 与 `E₊(b;z)` 的指数逐项对易，从而与 `E₊(b;z)` 对易。
另一方面 `[h·α_m, b·α_{−l}] = m δ_{m,l}⟨h,b⟩`，是**标量**。故
```
[ h·α_m , Σ_{l≥1} (b·α_{−l}/l) z^{l} ] = (1/m)·m⟨h,b⟩·z^{m} = ⟨h,b⟩ z^{m} ,
```
仍是标量（因而与一切算子对易）。对 `exp` 用「`[A, B]` 中心 ⟹ `[A, e^B] = [A,B]e^B`」
（在形式幂级数层面即 `[A, B^r] = r[A,B]B^{r−1}`，逐项求和；本处 `B` 的每个齐次部分在每个向量上
只有有限多项非零，故求和合法）得
```
[ h·α_m , E₋(b;z) ] = ⟨h,b⟩ z^{m} E₋(b;z) .
```
于是 `[h·α_m, V^{(b)}(z)] = ⟨h,b⟩ z^m V^{(b)}(z)`。取 `z^J` 系数：`[h·α_m, V^{(b)}_J] = ⟨h,b⟩V^{(b)}_{J−m}`。

**情形 `m = −l ≤ −1`。** 对称地：`[h·α_{−l}, b·α_{−l'}] = 0`（因 `−l−l' < 0`），故 `h·α_{−l}` 与 `E₋` 对易；
而 `[h·α_{−l}, b·α_{l'}] = −l δ_{l,l'}⟨h,b⟩`，故
```
[ h·α_{−l} , − Σ_{l'≥1} (b·α_{l'}/l') z^{−l'} ] = −(1/l)·(−l⟨h,b⟩)·z^{−l} = ⟨h,b⟩ z^{−l} ,
```
标量，于是 `[h·α_{−l}, E₊(b;z)] = ⟨h,b⟩z^{−l}E₊(b;z)`，从而
`[h·α_{−l}, V^{(b)}_J] = ⟨h,b⟩V^{(b)}_{J+l} = ⟨h,b⟩V^{(b)}_{J−m}`。

**情形 `m = 0`。** `h·α_0` 在固定层 `F(q)` 上是标量，与一切算子对易。∎

⚠ 注意 `E₊` 指数上的负号（(P2) 的写死约定）在第二种情形里与 `[h·α_{−l}, b·α_{l}] = −l⟨h,b⟩` 的负号
**相消**，使两种情形得到**同一个**系数 `⟨h,b⟩`。这不是巧合，而是该约定的作用之一。

**引理 3.3（塔上的振子对易子）。** 对一切 `h ∈ 𝔥`、`m ∈ Z`、`n, K ∈ Z`，在 `T` 上
```
[ h·α_m , 𝒫_{n,K} ] = ⟨h, n k⟩ · 𝒫_{n,K−m} .
```

*证明*。记 `J := K − nν`，故 `𝒫_{n,K} = S_n ∘ V^{(b_n)}_J`（(★P)），且 `𝒫_{n,K−m} = S_n ∘ V^{(b_n)}_{J−m}`。

*`m ≠ 0`*：`h·α_m` 在每层上的表达式（§1.2）**不含该层的动量 `q`**，而 `S_n` 逐字地把第 `N` 层
搬到第 `N+n` 层；由 `momentum-tower-fock-space` 的「`F(q)` 作为模与 `q` 无关」，
两者对易：`[h·α_m, S_n] = 0`。于是
```
[h·α_m, S_n V^{(b_n)}_J] = S_n [h·α_m, V^{(b_n)}_J] = ⟨h, b_n⟩ S_n V^{(b_n)}_{J−m} = ⟨h,nk⟩ 𝒫_{n,K−m} ,
```
用了引理 3.2 与 `b_n = nk`。

*`m = 0`*：由 (P1)，`[h·α_0, S_n] = ⟨h, nk⟩ S_n`（该卡逐字 `[α^μ_0, S_n] = n(2α')^{1/2}k_0^μ S_n`，
与 `η_μ h^μ` 收缩即得）。又由引理 3.2 的 `m=0` 情形 `[h·α_0, V^{(b_n)}_J] = 0`。故
```
[h·α_0, S_n V^{(b_n)}_J] = ⟨h,nk⟩ S_n V^{(b_n)}_J = ⟨h,nk⟩ 𝒫_{n,K} = ⟨h,nk⟩𝒫_{n,K−0} . ∎
```

**命题 3.4（`𝒫` 是 `n`-型顶点族）。** 对每个 `n ∈ Z`，族 `{𝒫_{n,K}}_{K∈Z}` 满足 (C1)(C2)(C3)。

*证明*。(C1)：由 (E1)，`V^{(b_n)}_{K−nν}(F^{(M)}) ⊆ F^{(M+K−nν)}`；再复合 `S_n`（它保持振子能级、
把第 `N` 层送到第 `N+n` 层）。(C2)：引理 3.3。
(C3)：由 (E2)，`𝒫_{n,nν}|0;N⟩ = S_n V^{(b_n)}_0(1) = S_n(1) = |0;N+n⟩`。∎

**定理 3.5（刻画/唯一性）。** 固定 `n ∈ Z`。若 `A = {A_K}_{K∈Z}` 是 `n`-型顶点族，则
```
A_K = 𝒫_{n,K} = S_n ∘ V^{(b_n)}_{K − nν}     对一切 K ∈ Z 。
```
即：**满足 (C1)(C2)(C3) 的算子族恰有一个**（由命题 3.4，存在；由本定理，唯一）。

*证明*。令 `B_K := A_K − 𝒫_{n,K}`。由命题 3.4 与线性性，族 `{B_K}` 满足 (C1) 与 (C2)，且由 (C3)
```
B_{nν}|0;N⟩ = 0     对一切 N ∈ Z 。                                   (∗)
```
目标：`B_K = 0` 对一切 `K`。

**第一步：`B` 在全部真空上为零。** 固定 `N`，记 `w_K := B_K|0;N⟩`。由 (C1)（取 `M = 0`），
```
w_K ∈ T_{N+n}^{(K − nν)} ,      特别地   w_K = 0  当 K < nν 。          (1)
```
由 (C2) 取 `m ≥ 1`，并用 `(h·α_m)|0;N⟩ = 0`（`m ≥ 1`，(P1)）：
```
(h·α_m) w_K = (h·α_m)B_K|0;N⟩ = [h·α_m, B_K]|0;N⟩ = ⟨h,nk⟩ w_{K−m} .   (2)
```
对 `K` 作归纳（从 `K = nν` 起；`K < nν` 由 (1) 已成立）。设 `w_{K'} = 0` 对一切 `K' < K`。

- 若 `K = nν`：`w_{nν} = 0` 由 (∗)。
- 若 `K > nν`：由 (2) 与归纳假设，`(h·α_m)w_K = ⟨h,nk⟩w_{K−m} = 0` 对一切 `h ∈ 𝔥` 与一切 `m ≥ 1`
  （注意 `K − m < K`）。把 `T_{N+n}` 等同于 `F`（(P1)：作为模与动量无关），由**引理 2.1** 得
  `w_K ∈ ℂ·1 = F^{(0)}`。但由 (1) 又有 `w_K ∈ F^{(K−nν)}`，而 `K − nν > 0`，且 `F` 的能级分解是直和，
  故 `F^{(0)} ∩ F^{(K−nν)} = 0`，于是 `w_K = 0`。

归纳完成：`B_K|0;N⟩ = 0` 对一切 `K, N`。

**第二步：由真空传播到全空间。** 由引理 2.2(ii)（逐层应用），`T_N` 由形如
```
u = (h_1·α_{−m_1}) ⋯ (h_r·α_{−m_r}) |0;N⟩ ,     r ≥ 0, m_i ≥ 1, h_i ∈ 𝔥
```
的向量张成。对 `r` 归纳，**且对一切 `K` 同时**：断言 `B_K u = 0`。

- `r = 0`：第一步。
- `r → r+1`：写 `u' = (h·α_{−m})u`（`m ≥ 1`，`u` 为 `r` 次）。由 (C2) 取该式的 `m ↦ −m`（`−m ≠ 0`）：
  `[h·α_{−m}, B_K] = ⟨h,nk⟩ B_{K+m}`，故
  ```
  B_K u' = B_K (h·α_{−m}) u = (h·α_{−m}) B_K u − ⟨h,nk⟩ B_{K+m} u = 0 − 0 = 0 ,
  ```
  两项都由归纳假设（对 `r` 次向量、对一切洛朗指标）为零。

由线性性 `B_K = 0` 于每个 `T_N`，从而于 `T`。∎

### §5.1 核对 0：(3.14) 在 `v = 1` 处的塌缩

**引理 5.1。** 设 `n, j ∈ Z`，`α := nk`，`β := jk`，`w ∈ U = M(1,p̃)`。则在 `W = ℂ[L]⊗U` 中
```
𝒴_n(x)(e^{jk} ⊗ w)  =  e^{(n+j)k} ⊗ x^{nν} · E^-(−nk, x) E^+(−nk, x) w .      (5.1)
```

*证明*。从 Li–Wang Theorem 3.6 的 (3.14)（L1 逐字，`math-sources.md` §36.6 (d)）出发，取 `v = 1`：
```
Y_W(e^α⊗1, x)(e^β⊗w) = ε(α,β) e^{α+β} ⊗ x^{⟨α,β⟩} E^-(−α,x) Y_U(Δ̄(β,x)1, x) Δ̄(α,−x) w .
```
逐个因子处理：

1. **`ε(α,β) = 1`**：§1.5（`li-wang-2008` §4 p.21 L1 逐字；`gebert-nicolai-1995` §3.1 (3.1)）。
   🔴 **不重证**（`claim.md` §2.3 的纪律）。
2. **`x^{⟨α,β⟩} = 1`**：`⟨α,β⟩ = ⟨nk, jk⟩ = nj⟨k,k⟩ = 0`，由类光性 `⟨k,k⟩ = 2α'k_0² = 0`。
   🔴 **注意**：这个因子**恒为 1**，因此它**不可能**承载单值因子 `x^{nν}`。
   这正是桥卡推导 `--via-cocycle-triviality` 的 summary 出错的地方
   （lead 复核 `docs/reviews/bridge-card-index-shift-2026-09-18.md` §2 已 CONFIRMED）。
   单值因子的真正出处是第 4 项。
3. **`Δ̄(β,x)1 = 1`**：由 `Δ̄` 的定义（Li–Wang p.11 L1 逐字，`math-sources.md` §36.6 (b)）
   `Δ̄(β,x) = (−x)^{β(0)}E^+(−β,−x)`。在 `M(1)` 上 `β(0) = 0`
   （Li–Wang 在 (3.12) 后逐字："and `α(0) = 0` on `M(1)`"），故 `(−x)^{β(0)} = 1`；
   又 `E^+(−β,−x)` 只含湮灭模 `(−β)(m)`（`m ≥ 1`），它们湮灭 `M(1)` 的真空 `1`，
   故指数的非平凡项全部作用为 0，`E^+(−β,−x)1 = 1`。合起来 `Δ̄(β,x)1 = 1`。
   ⚠ 顺带：这一步**完全不依赖** `β`，所以 `𝒴_n` 在 `W` 的各层上是「同一个」算子——这件事后面再用。
4. **`Y_U(1,x) = id_U`**：模的真空公理。`U` 按 Theorem 3.6 是 `M(1)`-模（由 Condition `C_L`），
   而 `1 ∈ M(1)` 是顶点代数 `M(1)` 的真空向量。
   `[GAP-vac: 图节点 math.vertex-algebra-borcherds-identity 逐字列出了顶点代数的真空公理，
   但没有逐字列出模版本的真空公理 Y_U(1,x) = id_U。它是「是模」这一概念的标准定义的一部分
   （该卡承担「是顶点代数 / 是模」所指的公理体系），本证明按标准定义使用它；
   若审查员要求逐字承载，需要 curator 在该卡或新卡上补一行。这是记账缺口，不是数学缺口。]`
5. **`Δ̄(α,−x) = x^{α(0)} E^+(−α, x)`**：把 `Δ̄(α,y) = (−y)^{α(0)}E^+(−α,−y)` 在 `y = −x` 处求值：
   `(−(−x))^{α(0)} = x^{α(0)}`，`E^+(−α, −(−x)) = E^+(−α, x)`。
   🔴 **两个负号相消**——这是 `claim.md` §6 预警的「技术上最容易出错的一步」，此处逐字核过。
6. **`x^{α(0)}` 在 `U` 上是标量 `x^{nν}`**：`U = M(1,p̃)` 上 `h(0)` 作用为标量 `⟨h,p̃⟩`（(V2)），
   故 `α(0) = ⟨nk, p̃⟩ = n⟨k,p̃⟩ = nν`（用整性条件 (I)）。
   标量与一切算子对易，可以移到 `E^-` 左边。

代入即得 (5.1)。∎

⚠ **`ν ∈ Z` 在这里是本质的**：`Δ̄` 是 `(End W)[[x,x^{−1}]]` 的合法元素，其前提是
「`α(0)` 半单且**只有整数本征值**」（Li–Wang p.11 L1 逐字）。`ν ∈ Z` 正是 Condition `C_L`
在本设定下的内容（`free-boson-...-momentum-tower` 已核实）。若 `ν ∉ Z`，`x^{nν}` 不是形式洛朗单项式，
等式两端都不落在 `(End)[[x,x^{−1}]]` 里。

### §5.2 核对 (i)(ii)：两个指数因子逐项同一（含 Li–Wang 脚注 3 的符号陷阱）

**引理 5.2。** 设 `α = nk`，`b_n = nk`（同一个 `𝔥` 中向量）。则作为 `(End U)[[x,x^{−1}]]` 与
`(End F)[[x,x^{−1}]]` 之间经 `Φ_0` 的共轭：
```
Φ_0 ∘ E^-(−α, x) ∘ Φ_0^{−1} = E₋(b_n; x) ,      Φ_0 ∘ E^+(−α, x) ∘ Φ_0^{−1} = E₊(b_n; x) .
```

*证明*。**(i) 产生部分。** Li–Wang (3.2)（L1 逐字）取 `−` 分支：
`E^-(γ,x) = exp( Σ_{m≥1} (γ(−m)/(−m)) x^{m} )`。代 `γ = −α`，并用 `(−α)(−m) = −α(−m)`（模映射对 `𝔥` 线性）：
```
E^-(−α, x) = exp( Σ_{m≥1} ( −α(−m) / (−m) ) x^{m} ) = exp( Σ_{m≥1} ( α(−m)/m ) x^{m} ) .
```
物理侧 (P2)：`E₋(b_n;x) = exp( Σ_{l≥1} (b_n·α_{−l}/l) x^{l} )`。
由引理 2.3，`Φ_0 ∘ α(−m) ∘ Φ_0^{−1} = (α·α_{−m}) = b_n·α_{−m}`（因 `α = b_n` 是同一个 `𝔥` 向量）。
指数的 `x^P` 系数是产生算子的**有限**多项式（`Σ_{m≥1}(⋯)x^m` 只含正幂，故 `x^P` 系数是
`m_1+⋯+m_r = P`、`m_i ≥ 1` 的有限多个单项之和），`Φ_0` 是代数同构意义下的共轭，逐系数搬运合法。
故两者逐 `x^P` 系数相等。

**(ii) 湮灭部分。** (3.2) 取 `+` 分支：`E^+(γ,x) = exp( Σ_{m≥1} (γ(m)/m) x^{−m} )`。代 `γ = −α`：
```
E^+(−α, x) = exp( − Σ_{m≥1} ( α(m)/m ) x^{−m} ) .
```
物理侧 (P2)：`E₊(b_n;x) = exp( − Σ_{l≥1} (b_n·α_{l}/l) x^{−l} )`——**指数上带负号**。
由引理 2.3，`Φ_0 ∘ α(m) ∘ Φ_0^{−1} = b_n·α_m`。逐系数（`x^{−Q}` 系数是湮灭算子的有限多项式）相等。∎

🔴 **三条必须点名的核对结果：**

- **符号陷阱已处理**：Li–Wang 脚注 3 逐字说「`E^-(α,x)` 在 [Li3] 里是本文的 `E^-(−α,x)`」。
  本证明**全程**用 Li–Wang 2008 本身的约定；(3.14) 里出现的**就是** `E^-(−α,x)` 与（经 `Δ̄` 展开的）
  `E^+(−α,x)`，即**已经带了那个负号的形式**。
- **`E₊` 的负号不是巧合**：物理侧 (P2) 把负号写在指数上（`worldsheet.exponential-vertex-operator-modes`
  的写死约定），VOA 侧的负号来自 (3.14) 里的参数 `−α`。两侧的负号**各自独立地**存在，
  而本引理证明它们**恰好相消到同一个算子**。若 (P2) 的约定取成不带负号，本引理即为假。
- **`α'` 因子没有掉**：两侧的向量都是**同一个** `𝔥` 元素 `nk = (2α')^{1/2}nk_0`；
  `α'` 只经 §1.1 的字典 `q̃ = (2α')^{1/2}q` 进入，且在格向量与振子归一化上**同时**应用。
  这正是 Grotenhuis (6.5)→(6.6) 掉了 `√(α'/2)` 的那一步（§0.3 限定词 2），本证明在此处逐字核过。

### §5.3 核对 (iii)：单值因子

**引理 5.3。** 在 `W` 的第 `j` 层上，(5.1) 中的单值因子是 `x^{nν}`，**与 `j` 无关**；
经 `Φ` 搬到塔上即 (P3) 的 `Z_n(x) = x^{nν}·id_T`。

*证明*。由引理 5.1 的第 2、6 项，(3.14) 右端的两个 `x`-幂因子分别是
```
x^{⟨α,β⟩} = x^{nj⟨k,k⟩} = x^0 = 1     （层依赖的那个，因类光性塌缩为 1）,
x^{α(0)}  = x^{⟨nk, p̃⟩} = x^{nν}      （层无关的那个，来自 Δ̄(α,−x)）.
```
乘积 `x^{nν}`，与 `j` 无关。物理侧 (P3) 逐层算得的指数是
`2α' n k_0·(p + N k_0) = nν + nN·2α'k_0² = nν`，也与 `N` 无关，且数值相同。∎

🔴 **这条核对同时钉死了三件事**（`claim.md` §4 的「第六条门槛」要求显式处理本因子）：

1. **单值因子的 VOA 出处是 `Δ̄(α,−x)` 里的 `x^{α(0)}`，不是 `x^{⟨α,β⟩}`。**

2. **两侧对 `j`（层）的依赖各自消失，但机制不同**：VOA 侧靠 `⟨k,k⟩ = 0` 杀掉 `x^{nj⟨k,k⟩}`；

### §5.4 核对 (iv)：格元的乘法经 `Φ` 恰为 `S_n`

**引理 5.4。** 对一切 `n, j ∈ Z` 与 `u ∈ U`，`Φ(e^{(n+j)k} ⊗ u) = S_n( Φ(e^{jk} ⊗ u) )`。

*证明*。由定义 2.4（常值规范 `c ≡ 1`），`Φ(e^{mk}⊗u) = Φ_0(u) ∈ T_m` 对一切 `m`；

由 (P1)，`S_n` 把第 `j` 层的向量逐字送到第 `j+n` 层的同一个向量。二者相等。∎

⚠ **这里正是 `ε ≡ 1` 与 `S_n` 的「系数 1」相遇的地方**（§2.4）：

### §5.5 核对 (v)：两端每个 `x^K` 系数都是良定义的线性算子

**引理 5.5。** 对一切 `n, K ∈ Z`：
(a) `[x^K]𝒴_n(x)` 是 `W` 上处处有定义的线性算子；
(b) `𝒫_{n,K} = S_n V^{(b_n)}_{K−nν}` 是 `T` 上处处有定义的线性算子。

*证明*。(b)：由 (P2)，`V^{(b)}_J = Σ_{P+Q=J} E₋(b)_P E₊(b)_Q`。对 `v ∈ F^{(M)}`：`E₋(b)_P = 0` 当 `P < 0`
（`E₋` 只含 `x` 的非负幂）；`E₊(b)_Q` 把能级降低 `−Q`（`Q ≤ 0`），故 `E₊(b)_Q v = 0` 当 `−Q > M`，
即 `Q < −M`。于是 `P + Q = J` 的求和被限制在 `0 ≤ P` 与 `−M ≤ Q ≤ 0` 之内，是**有限**和。
`S_n` 是双射，故复合处处有定义。（这就是 `worldsheet.exponential-vertex-operator-modes` 的
「逐向量有限和」，`formalized`。）

(a)：由 (5.1)，`𝒴_n(x)(e^{jk}⊗w) = e^{(n+j)k} ⊗ x^{nν}E^-(−nk,x)E^+(−nk,x)w`。
`E^+(−nk,x)` 的 `x^{−Q}` 系数是湮灭模的有限多项式，作用在 `w ∈ U` 上时只有有限多个 `Q` 给出非零
（`U = M(1,p̃)` 上湮灭模局部幂零——这正是 Condition `C_L` 的一半，见 Li–Wang p.11 对 `Δ̄` 良定义性的
逐字要求「`α(n)` for `n ≥ 1` act locally nilpotently」）；`E^-(−nk,x)` 只含非负幂。
故每个 `x^K` 系数是有限和。∎

⚠ 两端的良定义性**各自独立地**成立，用的是各自框架内的有限性（右端：多项式代数的能级分解；
左端：Condition `C_L` 的局部幂零性）。这满足 `prior-art.md` §4 判据 1、2：两端各自独立构造。

### §5.6 主定理

**定理 5.7（= Claim A′ 的 (A′-a)）。** 在 §1 的设定下，对一切 `n ∈ Z`，
```
Φ ∘ 𝒴_n(x) ∘ Φ^{−1} = S_n ∘ ( ⊕_N E₋(b_n;x) E₊(b_n;x) ) ∘ x^{nν} = 𝒫_n(x)
```
在 `(End_ℂ T)[[x,x^{−1}]]` 中成立；等价地，对一切 `K ∈ Z`
```
Φ ∘ ( [x^K]𝒴_n(x) ) ∘ Φ^{−1} = S_n ∘ V^{(b_n)}_{K − nν} = 𝒫_{n,K} .
```

*证明*。`W = ⊕_j W_j`，`W_j = e^{jk}⊗U`，故只需在每个 `W_j` 上验证。取 `w ∈ U`，令 `t := Φ(e^{jk}⊗w) ∈ T_j`，
即 `t = Φ_0(w)` 放在第 `j` 层。由引理 5.5 两端在 `t` 上都有定义。计算：
```
( Φ ∘ 𝒴_n(x) ∘ Φ^{−1} ) t
  = Φ( 𝒴_n(x)(e^{jk}⊗w) )
  = Φ( e^{(n+j)k} ⊗ x^{nν} E^-(−nk,x)E^+(−nk,x) w )                      （引理 5.1）
  = S_n( Φ( e^{jk} ⊗ x^{nν} E^-(−nk,x)E^+(−nk,x) w ) )                    （引理 5.4）
  = S_n( x^{nν} · Φ_0( E^-(−nk,x)E^+(−nk,x) w ) )    ∈ T_j 上再移位        （定义 2.4；x^{nν} 是标量）
  = S_n( x^{nν} · E₋(b_n;x)E₊(b_n;x) Φ_0(w) )                              （引理 5.2）
  = S_n( x^{nν} · E₋(b_n;x)E₊(b_n;x) t )
  = 𝒫_n(x) t                                                               （定义 1.1）。
```
（第 4 步用到 `Φ` 在第 `j` 层上就是 `Φ_0`；第 5 步的两次共轭合法性由引理 5.2 的逐系数论证给出。）
由 `w`、`j` 任意，等式在 `W` 上成立。取 `x^K` 系数：由 `[x^K](x^{nν}F(x)) = [x^{K−nν}]F(x)` 与 (★P) 得
`Φ([x^K]𝒴_n)Φ^{−1} = S_n V^{(b_n)}_{K−nν}`。∎

**推论 5.8（= (A′-b)）。** 对每个 `n`，族 `{Φ([x^K]𝒴_n)Φ^{−1}}_{K∈Z}` 是唯一的 `n`-型顶点族；
特别地，对任何满足 (C1)(C2)(C3) 的族 `A` 有 `Φ([x^K]𝒴_n)Φ^{−1} = A_K`（∀K）。

*证明*。定理 5.7 + 命题 3.4（存在）+ 定理 3.5（唯一）。∎
