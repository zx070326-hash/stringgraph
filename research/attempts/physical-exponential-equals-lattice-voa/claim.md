### §0.4 🔴 cocycle 缺口（`prior-art.md` §3，本尝试必须正面处理，不得绕过）

| | 零模因子 |
|---|---|
| 物理侧 (6.6) | `e^{i k x₀^L}` —— **一个**因子 |
| VOA 侧 (3.15) | `e^α c_α` —— **两个**因子（平移算符 × cocycle 算符） |

Grotenhuis 的 "We recognise …" 一句**完全没有提到 `c_α`**，也没有讨论 `e^{ikx₀^L}` 是否满足他的存在性条件
(3.14) `e^α c_α e^β c_β = (−1)^{(α,β)} e^β c_β e^α c_α`（即 `(α,β)` 为奇时两个零模因子必须**反对易**）。
而物理侧的 `e^{ikx₀}` 是平移算符的指数，彼此**两两对易**（`[x₀^μ, x₀^ν] = 0`）。

**⇒ 在存在 `(α,β)` 为奇数的偶格上（Leech 格就有大量这样的对），物理侧的零模因子不可能满足 (3.14)，
因此 (6.6) 的右端不可能等于 (3.15)：Grotenhuis 的识别在他自己设定的一般偶格上是错的。**

`prior-art.md` §3 指出这个洞在本卡的设定下闭合，闭合它的那一步**就是本卡的断言 (1)**
（`ε(mk,nk) = 1`），该断言已有两条 L1 来源（Gebert–Nicolai 1995 §3.1 (3.1)；
Li–Wang 2008 §4 p.21 逐字 "the normalized 2-cocycle ε … is trivial in the sense that `ε(α,β) = 1`
for all `α,β ∈ L`"）。🔴 **纪律：断言 (1) 不重证，只引用。**

⚠ **本轮的一条细化**（本文件的独立观察，**不是**对 `prior-art.md` 的纠错，那份文件的论断针对的是
**一般偶格**、举的例子是 Leech，完全正确）：**在秩 1 上，闭合 cocycle 缺口的是「秩 1 + 偶」，
不是「类光」。** 理由是一行：对 `L = Zk` 与 `α = mk`、`β = nk`，
`⟨α,β⟩ = mn⟨k,k⟩`，而 (3.5) 要求 `⟨k,k⟩ ∈ 2Z`，故 `⟨α,β⟩` **恒为偶数**，
于是 (3.8) 的右端 `(−1)^{⟨α,β⟩} ≡ 1`，`ε ≡ 1` 合法——**即使 `⟨k,k⟩ ≠ 0`**。
类光性 `⟨k,k⟩ = 0` 在本命题里另有一个**更要紧、且此前没有被任何地方写下来**的作用，见 §2.5。
这条细化不削弱 `prior-art.md` §3 的结论（秩 ≥ 2 时确有奇配对，该处的反驳成立），
但它改变了「类光性是条件本身」这句话的**理由**，必须写进 `proof.md`，不能沿用错误的理由。

### §1.3 物理侧（左端）的构造——独立于任何顶点代数

物理侧的三个构件全部取自图中 **effective = `formalized`** 的定义卡，它们的定义里**不出现**
「顶点代数」「`Y(v,z)`」「格」这些词，构造是纯多项式代数的：

**(P1) 逐层 Fock 空间与塔**（`worldsheet.momentum-tower-fock-space`，`formalized`）。
对动量 `q` 记 `F(q)`，其上装零模 `α^μ₀ := (2α')^{1/2} q^μ · id`。
```
T(p;k₀) := ⊕_{N ∈ Z} F(p + N k₀)         （代数直和，有限支撑，不完化）
```
移位算子 `S_n : T → T`（`n ∈ Z`）把第 `N` 层的向量**逐字**送到第 `N+n` 层的同一个向量；
`S₀ = id`，`S_m S_n = S_{m+n}`，`[α^μ₀, S_n] = n(2α')^{1/2} k₀^μ S_n`。
⚠ 该卡 (2) 的塔上双线性型与层间正交是**约定式定义**；**本命题不使用它**（见 §5 (c)）。

**(P2) 正规序指数的振子部分**（`worldsheet.exponential-vertex-operator-modes`，`formalized`）。
对常向量 `b ∈ R^D`（记 `x·y = Σ_μ η_μ x^μ y^μ`）：
```
E₋(b;z) = exp( Σ_{l≥1} (b·α_{−l}/l) z^{ l} ) ,
E₊(b;z) = exp( − Σ_{l≥1} (b·α_{ l}/l) z^{−l} ) ,
V^{(b)}_J := Σ_{p+q=J} [z^p]E₋(b;z) ∘ [z^q]E₊(b;z)      (J ∈ Z)
```
在代数 Fock 空间上逐向量是**有限和**，不需要完化、不需要收敛性、不需要围道。
⚠ **`E₊` 指数上的负号不是任意选择**（该卡 notes【E₊ 的符号约定】），改它会同时改所有下游恒等式。

**(P3) 单值（zero-mode monodromy）因子。**
物理写法 `:e^{i c·X(z)}:` 里来自 `X^μ(z)` 的 `−i·2α' p^μ ln z` 项的因子 `z^{2α' c·p̂}`。
在塔上，`p̂` 逐层是标量：第 `N` 层给出指数 `2α' n k₀·(p + N k₀) = nν + nN·2α'k₀² = nν`（用了 `k₀² = 0`）。
故它是一个**层无关的标量单项式**
```
Z_n(z) := z^{nν} · id_T .
```
⚠ 🔴 **`Z_n(z)` 在本图中没有承载卡**：`exponential-vertex-operator-modes` 明言只管振子部分，
`momentum-tower-fock-space` 只给 `S_n`。本文件把它作为**本尝试自己写出的定义**引入（构造材料仍只用到
(P1) 的逐层零模），并在 §5 (e) 把「图里缺这张卡」登记为缺口。

**定义（物理侧算子）。** 对 `n ∈ Z`，记 `b_n := n k = (2α')^{1/2} n k₀`，令
```
𝒫_n(z) := S_n ∘ ( ⊕_N E₋(b_n;z) E₊(b_n;z) ) ∘ Z_n(z)  ∈ (End_ℂ T(p;k₀))[[z, z^{−1}]] ,
```
其 `z^K` 系数为
```
𝒫_{n,K} = S_n ∘ V^{(b_n)}_{K − nν}          (K ∈ Z) .          (★P)
```
（`Z_n` 是标量，与谁都对易，故摆放位置不影响 (★P)。）

**(P4) 与图内已有记号的对照（必须核对，不可默认）。**
`worldsheet.ddf-operators-v6` 的【顶点算子的模】一段与它的 Lean 字典逐字写
```
V^{(n)}_K  =  towerShift n ∘ towerDiag( Fock.vertexOsc η (n·b) (K − n) ) ,
```
即在归一化 (S) `ν = 1` 下 `V^{(n)}_K = S_n ∘ V^{(b_n)}_{K−n}`，**与本文的 (★P) 在 `ν = 1` 处逐字一致**。
⚠ 本文的 (★P) 是它在一般 `ν ∈ Z` 上的写法。

### §1.4 VOA 侧（右端）的构造——独立于任何物理记号

**(V1) 格点顶点代数**（`math.lattice-vertex-algebra`，`rigorous`；Li–Wang 2008 Theorem 3.6 前半）。

**(V3) 结构映射**（Li–Wang (3.2)、p.11、(3.14)；L1 逐字见
`literature/extractions/math-sources.md` §36.6 (a)(b)(d)）。对 `α ∈ 𝔥`：

E^±(α,x) = exp( Σ_{n≥1} (α(±n)/(±n)) x^{∓n} )                                   (3.2)

### §1.5 两侧之间的识别映射 `Φ`——必须显式给出，不能默认

`W` 与 `T(p;k₀)` 是**两个独立构造出来的空间**。目标卡的断言 (2) 是关于**算子**的等式，
因此必须先指定把它们等同起来的线性同构。本文件把它**写死**为：

> **定义（识别 `Φ`）。** `Φ : W → T(p;k₀)` 是唯一满足下面三条的 `ℂ`-线性同构：
> - **(Φ1) 分层**：`Φ( e^{jk} ⊗ U ) = F(p + j k₀)`，对一切 `j ∈ Z`；
> - **(Φ2) 基点**：`Φ( e^{jk} ⊗ 1 ) = |0 ; p + j k₀⟩`，对一切 `j ∈ Z`（**每一层都取真空到真空，系数 1**）；
> - **(Φ3) 振子等变**：`Φ ∘ h(m) = (h·α_m) ∘ Φ`，对一切 `h ∈ 𝔥` 与 `m ≠ 0`
>   （其中 `h·α_m := Σ_μ η_μ h^μ α^μ_m`，与 (P2) 的收缩同一个）。

**存在唯一性**：`M(1,p̃)` 由 `1` 经 `h(−m)`（`m ≥ 1`）自由生成，故 (Φ2)+(Φ3) 在每层上唯一确定 `Φ`；
零模的匹配是推论而非要求（Li–Wang (3.15)(3.16)：`h_W(0)(e^β⊗w) = e^β⊗(⟨β,h⟩+h(0))w`，
在第 `j` 层给出 `⟨h, p̃ + jk⟩ = 2α' h·(p + j k₀)`，正是 `F(p+jk₀)` 的零模）。
这一段与 `free-boson-...-momentum-tower` 卡 (3)(iii) 的「逐层识别」是同一件事，
本文件只是把那里的「↔」写成一个有名字、有唯一性刻画的映射。

🔴 **(Φ2) 是一个选择，不是定理。** 把它换成 `Φ(e^{jk}⊗1) = c_j |0;p+jk₀⟩`（`c_j ∈ ℂ^×`）同样给出合法的
分层等变同构；此时 §2 的等式两端会相差因子 `c_{j+n}/c_j`。故 §2 的命题**只对常值规范 `c_j ≡ 1` 成立**，

> 则**对一切 `n ∈ Z` 与一切 `K ∈ Z`**，作为 `T(p;k₀)` 上的 `ℂ`-线性算子，
>
> ```
>     Φ ∘ ( [z^K] 𝒴(e^{n k₀}, z) ) ∘ Φ^{−1}   =   S_n ∘ V^{(b_n)}_{K − nν} ,        (A)
> ```
>
> 其中 `b_n = (2α')^{1/2} n k₀`，右端按 (★P)。
> 等价地，作为 `(End_ℂ T)[[z,z^{−1}]]` 中的形式级数，
> ```
>     Φ ∘ 𝒴(e^{n k₀}, z) ∘ Φ^{−1}   =   𝒫_n(z)   =   S_n ∘ ( ⊕_N E₋(b_n;z)E₊(b_n;z) ) ∘ z^{nν} .
> ```

**量词与意义的逐条落实**（任务书 §2 的要求）：

| 问题 | 本命题的答案 |
|---|---|
| 对哪些 `n`？ | **一切 `n ∈ Z`**，含 `n = 0`（此时两端都是恒等算子乘 `z⁰`，是平凡情形，但不排除）。 |
| 在塔的哪些层？ | **一切层 `N ∈ Z`**，同时。等式是整个 `T(p;k₀)` 上的算子等式，不是逐层分别陈述。 |
| 「逐幂次」的幂次指什么？ | **形式变量 `z` 的整数幂 `z^K`，`K ∈ Z`**，按 (α) 约定取系数。两端都落在 `(End T)[[z,z^{−1}]]` 里。 |
| 等号在哪个空间上？ | 在 `End_ℂ(T(p;k₀))` 里（经 `Φ` 把 `End(W)` 搬过去）。两端的每个 `z^K` 系数都是**处处有定义的线性算子**（左端：Li–Wang 的局部幂零性；右端：(P2) 的逐向量有限性）。 |
| 哪种意义的相等？ | **形式级数的系数逐个相等**，即 `∀K` 的算子相等；**不是**收敛意义、**不是**弱意义、**不是**在某个稠密子空间上。 |

### §2.2 ⭐ 本轮最要紧的交付：目标卡断言 (2) 的**字面表述与 (A) 不同，且在其自身设定下不成立**

目标卡 `worldsheet.physical-exponential-equals-voa-vertex-operator` 的断言 (2) 逐字写：

按字面读，这说 `V^{(n)}_K = S_n ∘ V^{(b_n)}_K`，**没有指标移位**。与 (A) 相比缺了 `K ↦ K − nν`。

**⇒ 于是有两种读法，两种都是缺陷：**

- **读法 1（字面）**：左端 `= Σ_K (S_n ∘ V^{(b_n)}_K) z^K = S_n E₋E₊`，右端 `= z^{nν} S_n E₋E₊`。

### §2.5 ⭐ 类光性的真正作用（结构性判断，必须写进 `proof.md`）

`prior-art.md` §3 末写「类光性不是技术便利，而是该命题成立的条件本身」。本文件同意这个**结论**，
但按 §0.4 的细化，**理由要换**，并且换成的理由是一条此前没有被任何地方写下来的观察：

设暂时放松到**任意秩 1 偶格** `L = Zk`（`⟨k,k⟩ ∈ 2Z`，不必为 0）。逐项对照两侧的单值指数：

- VOA 侧（(3.14)）：`x^{⟨α,β⟩} · x^{α(0)} = x^{⟨nk, jk⟩ + ⟨nk, p̃⟩} = x^{⟨nk, jk + p̃⟩} = x^{nν + nj⟨k,k⟩}`；
- 物理侧（(P3)）：`z^{2α' n k₀·(p + j k₀)} = z^{nν + nj⟨k,k⟩}`。

**两者对任意秩 1 偶格都逐字相等**——所以类光性**不是**为了让两侧的单值因子对上。
类光性的实质作用是：

> **`⟨k,k⟩ = 0` ⟺ 单值指数与层指标 `j` 无关 ⟺ 存在一个层无关的整数移位 `K ↦ K − nν`，
> 使得 `𝒫_n(z)` 的 `z^K` 系数是「同一个」振子算子在所有层上的直和。**

而**图与 Lean 侧的物理算子恰恰是按层无关的单一指标写的**
（`towerDiag (fun _ => Fock.vertexOsc η (n·b) (K − n))`，那个 `fun _ =>` 就是层无关性）。
故：**`⟨k,k⟩ ≠ 0` 时，图/Lean 现有的 `towerVertex` 不再是物理顶点算子的 `z^K` 系数**
（真正的系数需要层依赖的移位 `K − n(ν + j⟨k,k⟩)`），(A) 的右端写不出来。
这就是「类光性是命题成立的条件本身」的**正确理由**：它保障的不是 cocycle，
而是**物理侧算子在整条塔上有一个统一的洛朗指标**。

同时保留 `prior-art.md` §3 对**高秩**的结论：秩 `≥ 2` 时存在 `⟨α,β⟩` 为奇的对，
(3.8) 强制两个零模因子反对易，而物理侧的平移算子两两对易 ⟹ 不存在合法识别。
🔴 把这两条合起来才是完整的边界刻画，`proof.md` 必须两条都写。
