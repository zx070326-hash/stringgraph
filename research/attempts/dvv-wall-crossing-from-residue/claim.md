# Claim: DVV 壁跨越公式从留数结构的定量复现

## 命题陈述

**背景**。`research/attempts/ell-zero-wall-degeneracy/proof.md` §2.5 已严格导出：吸引子围道穿越 Φ₁₀ 的二阶极点 v=1/2 时，被积函数 `𝒢·e^{−2πiℓv}` 在该极点的留数为
```
Res_{v=1/2} [𝒢·e^{−2πiℓv}] = (−1)^ℓ · 2πiℓ · (1/h₀(ρ,σ,1))
```
其中 `𝒢 := −1/Φ₁₀(ρ,σ,v+1/2)`，`h₀(ρ,σ,1)` 是 Φ₁₀ 在 u=1（即 v=1/2）的二阶零点首项系数：
```
Φ₁₀(ρ,σ,u) = (u−1)²·h(ρ,σ,u)，h(ρ,σ,1) =: h₀(ρ,σ,1)
```
该留数公式已过 `graph-reviewer` 裁定 `verified`，且含一处 lead 订正（符号与相位因子）。

**已知**。Sen 2008 (C.25)（`literature/extractions/sen-2008-precision-counting.md` S6，逐字引用）给出 Φ̂ 在 v=0 附近的展开：
```
Φ̂(ρ,σ,v) = −4π² v² g(ρ) g(σ) + O(v⁴)    … (C.25)
```
**关键观察**：首项 `−4π² v² g(ρ) g(σ)` 在 (ρ,σ) 上是**因子化的**（g(ρ)·g(σ)），不是一般的 (ρ,σ) 混合函数。

**标准公式**。DVV 壁跨越（`graph/statements/holography/dvv-wall-crossing-identification.yaml` line 12）：
```
Δd = (−1)^{Q·P+1}(Q·P) · d_{1/2}(Q²/2) · d_{1/2}(P²/2)
```
其中 Q·P 是 Dirac 配对（本项目记号 Q·P = ℓ），d_{1/2}(k) 是电荷平方 2k 的 1/2-BPS 态指标。

## 命题（定量复现）

**Proposition**. 设 m,n,ℓ ∈ ℤ，m,n ≥ 1，Δ := 4mn−ℓ² > 0。设壁跨越跳变定义为
```
Δd_*(m,n,ℓ) := 2πi · ∫∫_{[0,1]²} dρ dσ · e^{−2πi(mρ+nσ)} · Res_{v=1/2}[𝒢(ρ,σ,v)·e^{−2πiℓv}]
```
（Cauchy 留数定理：微扰围道 C_± 之差）。

则在以下三个外部前提下，Δd_* **精确复现** DVV 壁跨越公式的三个结构特征：

1. **正比 ℓ**：`Δd_* ∝ ℓ`（零当且仅当 Q·P=0）
2. **因子化**：`Δd_* = (常数) · ℓ · [∫dρ e^{−2πimρ}/g(ρ)] · [∫dσ e^{−2πinσ}/g(σ)]`
3. **符号**：整体符号含 `(−1)^{ℓ+1}`（与 DVV 公式的 `(−1)^{Q·P+1}` 一致）

**外部前提**（待独立核实或作为显式假设）：

- **[EXT-h-factorize]**：`h₀(ρ,σ,1)` 是 (ρ,σ) 的因子化形式，即存在函数 g₁(ρ), g₂(σ) 使得
  ```
  1/h₀(ρ,σ,1) = g₁(ρ) · g₂(σ)
  ```
  **推导路径**（本 claim 的核心任务）：连接 (C.25) 的 v=0 展开与 h₀ 在 u=1（v=1/2）的关系。

- **[EXT-g-eta]**：对 N=1（K3×T² 情形），`g(ρ) = η(ρ)²⁴`（Dedekind η 函数），其 Fourier 系数恰好是 1/2-BPS 简并度 `d_{1/2}`：
  ```
  1/η(ρ)²⁴ = Σ_{m≥−1} d_{1/2}(m) e^{2πimρ}
  ```
  **地位**：尚未在公开文献中找到 N=1 时的显式验证（researcher 已查，标记待查）。若本 Proposition 精确复现 DVV 公式，则**反过来**是 [EXT-g-eta] 成立的强证据。

- **[EXT-c]**：Φ̂ 与标准 Φ₁₀ 的归一化常数 `c`（见 `bss-rossello-dstar-normalization-constant` 若已合并）是 open 的，只影响整体常数，不影响结构。

## 证明策略

1. **§1 连接 (C.25) 与 h₀**
   - (C.25) 是 Φ̂ 在 **v=0** 的展开。
   - 我们需要 Φ₁₀ 在 **u=1**（v=1/2）的展开。
   - 桥梁：`ell-zero-wall-degeneracy` §2.4 引理（Φ₁₀ 的偶性+周期 1 ⇒ 关于每个整数点都偶）。
   - 目标：证明 `h₀(ρ,σ,1) ∝ 1/[g(ρ)·g(σ)]`（因子化）。

2. **§2 代入留数公式**
   - `Res_{v=1/2} = (−1)^ℓ · 2πiℓ · (1/h₀(ρ,σ,1))`（已知，ell0wall §2.5）
   - 若 `1/h₀ = g₁(ρ)·g₂(σ)`，则
     ```
     Δd_* = (−1)^ℓ · 2πiℓ · ∫∫ dρdσ · e^{−2πi(mρ+nσ)} · g₁(ρ)·g₂(σ)
          = (−1)^ℓ · 2πiℓ · [∫dρ e^{−2πimρ}g₁(ρ)] · [∫dσ e^{−2πinσ}g₂(σ)]
     ```
   - 每个因子是 Fourier 系数，若 [EXT-g-eta] 成立则 = `d_{1/2}(m) · d_{1/2}(n)`。

3. **§3 整体常数与符号核对**
   - DVV 公式 `Δd = (−1)^{Q·P+1}(Q·P)·d_{1/2}(Q²/2)·d_{1/2}(P²/2)`
   - 本推导 `Δd_* = (−1)^ℓ·(常数)·ℓ·d_{1/2}(m)·d_{1/2}(n)`
   - 核对：`(−1)^ℓ` vs. `(−1)^{ℓ+1}`（整体负号从 𝒢 定义的 −1 来）
   - 核对：`(Q²/2, P²/2)` vs. `(m,n)` 的指标对应（来自 T=[[m,ℓ/2],[ℓ/2,n]] 的物理意义）
   - **重要**：如果常数不匹配，如实报告差多少，不调参凑。

## 成功判据

证明**成功**当且仅当：
1. 严格证明 `1/h₀(ρ,σ,1) = g₁(ρ)·g₂(σ)`（因子化），或在显式标注的前提下使用它。
2. 代数推导 Δd_* 的形式，验证 ∝ℓ 与因子化。
3. 符号与 DVV 公式逐项对上（允许整体常数差，需报告）。
4. **未引入任何隐藏前提**——所有外部假设（[EXT-*]）显式列出。

**不算成功**的情形：
- "结构大致像"——必须是定量的、逐项的。
- 吞掉常数因子（4π²、2πi 等）不追踪。
- 捏造 g(ρ)=η²⁴ 当已知（它是 [EXT-g-eta]，待核实）。
