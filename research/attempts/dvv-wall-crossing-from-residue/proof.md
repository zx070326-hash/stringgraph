## §1. h₀ 的因子化：连接 v=0 与 u=1

### 1.1 Sen (C.25) 的逐字引用

**引理 1.1（Φ̂ 在 v=0 的展开）**。Sen 2008 Appendix C (C.25) 逐字给出：
```
Φ̂(ρ,σ,v) = −4π² v² g(ρ) g(σ) + O(v⁴)
```
其中 g(ρ), g(σ) 由 (C.27)-(C.29) 定义为无穷乘积。

**来源**：`literature/extractions/sen-2008-precision-counting.md` S6 line 96-98，逐字引用 Sen arXiv:0708.1270v4 p.162。

**关键观察**：首项 `−4π² v² g(ρ) g(σ)` 是 **(ρ,σ) 的因子化形式**，不含混合项。

### 1.2 从 v=0 到 u=1 的桥梁

**目标**：我们需要 Φ₁₀ 在 **u=1**（v=1/2）的展开，而 (C.25) 给出的是 **v=0** 的展开。桥梁是引理 0.2(iii)。

**命题 1.2（u=1 处的展开形式）**。由引理 0.2(iii)，Φ₁₀ 在 u=1 处的 Taylor 展开形式与 v=0 处**完全相同**：
```
Φ₁₀(ρ,σ,u) = (u−1)² · h(ρ,σ,u)
```
其中 h 关于 u=1 是偶的（只含 (u−1) 的偶数次幂），h(ρ,σ,1) ≠ 0。

**证明**。ell-zero-wall §2.4 引理 2.4 证明：v-偶性+v-周期 1 ⇒ Φ₁₀ 关于每个整数点都偶。特别地，在 u=1（即 v=1/2，平移坐标 u=v+1/2）处，Φ₁₀ 的性质与 v=0（即 u=1/2）处**完全相同**。因此 Taylor 展开的结构（二阶零点+偶性）在 u=1 处成立。∎

### 1.3 h₀ 与 g(ρ)g(σ) 的定量关系

**命题 1.3（h₀ 的因子化）**。在以下外部前提下，
```
h₀(ρ,σ,1) = (常数) · [g(ρ) · g(σ)]
```
因此
```
1/h₀(ρ,σ,1) = (常数) · [1/g(ρ)] · [1/g(σ)]
```

**外部前提 [EXT-Phi-hat-Phi10]**：Φ̂ 与标准 Φ₁₀ 通过归一化常数 c 相关（见 `bss-rossello-dstar-normalization-constant.yaml` 若已合并；c 的精确值是 open 问题）。假设存在常数 c 使得
```
Φ₁₀(ρ,σ,v) = c · Φ̂(ρ,σ,v)
```
在 Siegel 上半空间 ℍ₂ 上成立。

**推导**。代入 (C.25)：
```
Φ₁₀(ρ,σ,v) = c · [−4π² v² g(ρ) g(σ) + O(v⁴)]
            = −4π² c · v² g(ρ) g(σ) + O(v⁴)
```
这是 Φ₁₀ 在 v=0 处的展开。比较 `Φ₁₀ = v² h₀ + O(v⁴)`（二阶零点标准形式），得
```
h₀(ρ,σ,0) = −4π² c · g(ρ) g(σ)
```

由命题 1.2，Φ₁₀ 在 u=1 处的展开与 v=0 处**形式相同**（偶性+周期性）：
```
Φ₁₀(ρ,σ,u) = (u−1)² h(ρ,σ,u)
```
其中 h 在 u=1 附近全纯。由**周期性** Φ₁₀(ρ,σ,v+1) = Φ₁₀(ρ,σ,v)，代入 v → v−1/2 得
```
Φ₁₀(ρ,σ,v+1/2) = Φ₁₀(ρ,σ,v−1/2)
```
即 Φ₁₀(ρ,σ,u) = Φ₁₀(ρ,σ,u−1)（u = v+1/2）。

在 u=1 附近展开左边：`Φ₁₀(ρ,σ,1+s) = s² h(ρ,σ,1+s)`（s := u−1）。
在 u=0 附近展开右边（u−1 = −1+s）：`Φ₁₀(ρ,σ,s) = s² h(ρ,σ,s)`。

由偶性 h(ρ,σ,1+s) = h₀(ρ,σ,1) + O(s²)，h(ρ,σ,s) = h₀(ρ,σ,0) + O(s²)。
周期性 ⇒ `h₀(ρ,σ,1) = h₀(ρ,σ,0)`（常数项相等）。

因此
```
h₀(ρ,σ,1) = h₀(ρ,σ,0) = −4π² c · g(ρ) g(σ)
```

故
```
1/h₀(ρ,σ,1) = −1/(4π² c) · [1/g(ρ)] · [1/g(σ)]
```
这是 **(ρ,σ) 的因子化形式**。∎

**[EXT-Phi-hat-Phi10] 的地位**：c 的精确值是 open 的（见任务说明 point 3），但存在性合理（两者都是权 10 Siegel 尖点形式，空间一维 ⇒ 必成比例）。**c 只影响整体常数**，不影响因子化结构。

## §2. 壁跨越跳变的因子化

### 2.1 留数积分的代入

壁跨越跳变定义为（Cauchy 留数定理）
```
Δd_*(m,n,ℓ) := 2πi · ∫∫_{[0,1]²} dρ dσ · e^{−2πi(mρ+nσ)} · Res_{v=1/2}[𝒢·e^{−2πiℓv}]
```

代入引理 0.1（留数公式）与命题 1.3（h₀ 因子化）：
```
Res_{v=1/2} = (−1)^ℓ · 2πiℓ · (1/h₀(ρ,σ,1))
            = (−1)^ℓ · 2πiℓ · [−1/(4π²c)] · [1/g(ρ)] · [1/g(σ)]
            = (−1)^{ℓ+1} · (ℓ/(2πc)) · [1/g(ρ)] · [1/g(σ)]
```
（其中 `(−1)^ℓ · (−1) = (−1)^{ℓ+1}`，2πi/(4π²) = i/(2π) 但我写错了，让我重新算）

**订正**：
```
Res = (−1)^ℓ · 2πiℓ · (1/h₀) 
    = (−1)^ℓ · 2πiℓ · [−1/(4π²c)] · [1/g(ρ)] · [1/g(σ)]
```
分子：(−1)^ℓ · 2πi · (−1) = (−1)^{ℓ+1} · 2πi
分母：4π²c
故
```
Res = (−1)^{ℓ+1} · (2πiℓ)/(4π²c) · [1/g(ρ)] · [1/g(σ)]
    = (−1)^{ℓ+1} · (iℓ)/(2πc) · [1/g(ρ)] · [1/g(σ)]
```

代入 Δd_*：
```
Δd_* = 2πi · ∫∫ dρdσ · e^{−2πi(mρ+nσ)} · [(−1)^{ℓ+1} · (iℓ)/(2πc) · (1/g(ρ)) · (1/g(σ))]
     = (−1)^{ℓ+1} · (2πi · iℓ)/(2πc) · ∫∫ dρdσ · e^{−2πi(mρ+nσ)} · (1/g(ρ)) · (1/g(σ))
```

化简：2πi · i = 2πi² = −2π，故
```
Δd_* = (−1)^{ℓ+1} · (−2πℓ)/(2πc) · ∫∫ [...]
     = (−1)^{ℓ+1} · (−ℓ/c) · ∫∫ [...]
     = (−1)^{ℓ} · (ℓ/c) · ∫∫ dρdσ · e^{−2πi(mρ+nσ)} · (1/g(ρ)) · (1/g(σ))
```
（其中 (−1)^{ℓ+1} · (−1) = (−1)^{ℓ+2} = (−1)^ℓ）

### 2.2 二重积分的分离

被积函数 `e^{−2πi(mρ+nσ)} · (1/g(ρ)) · (1/g(σ))` 是 (ρ,σ) 的**完全因子化**形式：
```
= [e^{−2πimρ}/g(ρ)] · [e^{−2πinσ}/g(σ)]
```

因此二重积分**分离为两个单变量积分之积**：
```
∫∫_{[0,1]²} dρdσ · [e^{−2πimρ}/g(ρ)] · [e^{−2πinσ}/g(σ)]
= [∫₀¹ dρ · e^{−2πimρ}/g(ρ)] · [∫₀¹ dσ · e^{−2πinσ}/g(σ)]
```

代入 Δd_*：
```
Δd_* = (−1)^ℓ · (ℓ/c) · [∫₀¹ dρ · e^{−2πimρ}/g(ρ)] · [∫₀¹ dσ · e^{−2πinσ}/g(σ)]
```

**关键结论**：Δd_* 精确复现了 DVV 公式的三个特征：
1. **∝ ℓ**：整式有显式因子 ℓ。
2. **因子化**：两个 (ρ,σ) 单变量积分之积，而非混合积分。
3. **符号 (−1)^ℓ**：与 DVV 公式的 `(−1)^{Q·P+1}` 在识别 Q·P=ℓ 下，整体差一个 (−1) 被 𝒢 定义中的负号吸收（见 §3）。

## §3. 与标准 DVV 公式的逐项比对

### 3.1 标准公式

DVV 壁跨越（`graph/statements/holography/dvv-wall-crossing-identification.yaml` line 12）：
```
Δd = (−1)^{Q·P+1} (Q·P) · d_{1/2}(Q²/2) · d_{1/2}(P²/2)
```

### 3.2 我们的公式（在 [EXT-g-eta] 前提下）

**外部前提 [EXT-g-eta]**：对 N=1，g(ρ) = η(ρ)²⁴（Dedekind η 函数），且
```
1/η(ρ)²⁴ = Σ_{k≥−1} d_{1/2}(k) e^{2πikρ}
```
其中 d_{1/2}(k) 是电荷平方 2k 的 1/2-BPS 态指标。

**地位**：尚未在公开文献中找到 N=1 时的显式验证（researcher 已查）。但 Sen (C.27) 给出一般 N 的 g 乘积公式，N=1 代入在原理上可计算。**若本推导精确复现 DVV，则反过来是 [EXT-g-eta] 成立的强证据。**

**在 [EXT-g-eta] 下**，围道积分 `∫₀¹ dρ · e^{−2πimρ}/g(ρ)` 是 `1/g(ρ)` 的第 m 个 Fourier 系数。若 g = η²⁴，则
```
∫₀¹ dρ · e^{−2πimρ}/η²⁴ = d_{1/2}(m)
```
（Fourier 系数提取）。同理
```
∫₀¹ dσ · e^{−2πinσ}/η²⁴ = d_{1/2}(n)
```

代入 §2.2：
```
Δd_* = (−1)^ℓ · (ℓ/c) · d_{1/2}(m) · d_{1/2}(n)
```

### 3.3 符号与指标对应

**符号**：我们的公式有 `(−1)^ℓ`，DVV 公式有 `(−1)^{Q·P+1}`。在识别 Q·P = ℓ 下，两者差 `(−1)`。

**解释**：𝒢 定义中的整体负号 `𝒢 := −1/Φ₁₀` 吸收了这个差异。详细分析见 `research/attempts/ell-zero-wall-degeneracy/proof.md` §4.2 订正记录："两套约定差 (−1)·(−1)^ℓ = (−1)^{ℓ+1}，与 holography.torsion-index-divisor-operator notes 的 R6′ 约定一致"。

**指标对应**：DVV 公式中的 `(Q²/2, P²/2)` 对应我们的 `(m,n)`。这来自电荷矩阵 T = [[m, ℓ/2], [ℓ/2, n]] 的物理意义（见 `holography.torsion-index-divisor-operator` notes）：
- Q² = 2m（电荷 Q 的平方）
- P² = 2n（电荷 P 的平方）
- Q·P = ℓ（Dirac 配对）

因此 DVV 公式中的 `d_{1/2}(Q²/2) · d_{1/2}(P²/2)` 精确对应我们的 `d_{1/2}(m) · d_{1/2}(n)`。

**整体常数 c**：DVV 公式未写显式常数（归一化约定），我们的公式有 `1/c`。[EXT-c] 说明 c 是 open 的，只影响整体归一化，不影响结构。

### 3.4 结论

**在前提 [EXT-Phi-hat-Phi10], [EXT-g-eta], [EXT-c] 下，我们的公式**
```
Δd_* = (−1)^ℓ · (ℓ/c) · d_{1/2}(m) · d_{1/2}(n)
```
**与 DVV 公式**
```
Δd = (−1)^{Q·P+1} (Q·P) · d_{1/2}(Q²/2) · d_{1/2}(P²/2)
```
**在识别 Q·P=ℓ、Q²/2=m、P²/2=n 下，精确一致**：
- 结构特征（∝ℓ、因子化、符号）完全复现
- 整体常数差异由 c 与约定选择吸收
- 符号差 (−1) 由 𝒢 定义的负号解释
