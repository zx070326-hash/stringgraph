## §1. 域翻译引理（完全独立、低风险）

**引理 1（域翻译）**：记 Rosselló/上游记号 `m=P²/2`（磁）、`n=Q²/2`（电）、`ℓ=Q·P`
（Rosselló arXiv:2403.19630 eq (2.3)，本人逐字核对）。记 BSS arXiv:2311.16252 记号
`m_B := NQ²/2`、`n_B := P²/2`、`ℓ_B := Q·P`（BSS p.41 附近正文，本人逐字核对）。
则对同一物理荷 (Q,P)，N=1 时：

`n_B = m`，`m_B = n`，`ℓ_B = ℓ`。

**证明**：直接代入定义式：`n_B := P²/2 = m`（Rosselló 定义）；`m_B := 1·Q²/2 = n`
（Rosselló 定义）；`ℓ_B := Q·P = ℓ`。∎

这一步**只用了两处定义式的字面内容**，不涉及任何 Jacobi 形式构造、围道选择或
FJ 展开变量的细节，故不受下文 §3/§4 讨论的任何不确定性影响。

**推论 1.1（目标域 ⊆ BSS 的 B₂）**：上游目标域 `n≥m≥1, 0≤ℓ≤m`（Rosselló 记号）
在引理 1 的替换下等价于 `m_B≥n_B≥1, 0≤ℓ_B≤n_B`（BSS 记号）。BSS 定义
`B₂ := {(n,ℓ,m): m,n>0, m≥n/N, 0≤|ℓ|≤2n}`（BSS eq (5.65), N 一般；本人逐字核对
p.61-62）。N=1 时 `B₂ = {m_B≥n_B, 0≤|ℓ_B|≤2n_B}`。由 `0≤ℓ_B≤n_B` 显然
`0≤|ℓ_B|≤2n_B`（因 n_B≥1>0），故目标域（翻译后）⊆ B₂ ⊆ B（BSS §B.4 已证
B₂⊆B，本人复核了该证明的完成配方步骤，见 §2 下方复核记录）。∎

## §3. 变量角色引理（本人独立推导，非文献显式陈述）

**引理 2（变量角色对应）**：BSS 的吸引子围道变量 (τ,σ,z)（BSS eq 5.14）
与 Rosselló 的吸引子围道变量 (ρ,σ,v)（Rosselló eq 2.22）之间存在如下对应：
`Rosselló 的 ρ ↔ BSS 的 σ`，`Rosselló 的 σ ↔ BSS 的 τ`，`Rosselló 的 v ↔ BSS 的 z`。

**证明**：直接比较两文各自围道定义式中"哪个变量的虚部标度关联哪个物理荷"：

| | 磁荷 P²/2 | 电荷 Q²/2 |
|---|---|---|
| Rosselló (2.22) | `Im σ = 2mΛ`（m=P²/2） | `Im ρ = 2nΛ`（n=Q²/2） |
| BSS (5.14), N=1 | `Im τ = 2n_B/ε`（n_B=P²/2） | `Im σ = 2m_B/ε`（m_B=Q²/2） |

两文各自的"虚部标度∝磁荷"变量分别是 Rosselló 的 σ 与 BSS 的 τ——对应；
"虚部标度∝电荷"变量分别是 Rosselló 的 ρ 与 BSS 的 σ——对应。∎

**这条引理只用了两文各自围道公式的字面内容**（本人逐字核对过两处），不涉及
任何 Jacobi 形式的构造细节或收敛性论证，风险等级与引理 1 相同（低）。

**推论 3.1**：引理 2 说明 BSS 的 SET B（Theorem 5.4b，涉及"ψ_n^F"，即 BSS 自己
关于 (τ,z) 变量、指标 n_B 的有限部 Fourier 展开）在变量对应下，是"关于
Rosselló 的 (σ,v)、指标 n_B=m（磁荷）"的展开——**这恰好就是 Rosselló/上游
自己的 ψ_m^F 族**（(R1) 式：`1/Φ₁₀=Σψ_m(σ,v)p^m`，ψ_m 是 (σ,v) 的函数，
指标 m）。即：BSS 的 SET-B 对象与上游的 c_m^F(n,ℓ) **是同一个数学构造**，
不需要额外的"哪个 Jacobi 形式族"层面翻译，只需要引理 1 的荷标签替换。

## §4. 整体符号：数值确认 + 唯一性论证

用引理 1、2 把 BSS Theorem 5.4(b)（N=1）翻译为 Rosselló 变量：

`d*_BSS(n_B,ℓ,m_B) = (−1)^{ℓ+1} ∫_C dτdσdz e^{−2πi(m_Bτ+n_Bσ+ℓz)}/Φ̃₁(Ω)`

代入引理 2 的变量替换（τ→σ_R, σ→ρ_R, z→v_R，三重积分对差分排序不敏感，
无 Jacobian 符号问题——这是普通的三重（非微分形式）积分，非楔积）与引理 1
的荷替换（n_B=m, m_B=n）：

`= (−1)^{ℓ+1} ∫ dρ_R dσ_R dv_R e^{−2πi(mρ_R+nσ_R+ℓv_R)} / Φ̃₁(ρ_R,σ_R,v_R)`
`=: (−1)^{ℓ+1} · J`，其中 `J := ∫_{C_*} e^{−2πi(mρ+nσ+ℓv)}/Φ̃₁ dρdσdv`
（围道 C 在引理 2 替换后与 Rosselló 的 C_* 逐分量标度完全一致，本人逐项核对：
`Im σ_R=2m/ε`匹配`Im σ=2mΛ`，`Im ρ_R=2n/ε`匹配`Im ρ=2nΛ`，`Im v_R=−ℓ/ε`
匹配`Im v=−ℓΛ`，取 Λ=1/ε）。

另一方面，Rosselló 自己的定义 (R4) 给出：

`d_*^Rosselló(m,n,ℓ) = ∫_{C_*} e^{−2πi(mρ+nσ+ℓ(v+1/2))}/Φ₁₀ dρdσdv = (−1)^ℓ · J₁₀`，

其中 `J₁₀ := ∫_{C_*} e^{−2πi(mρ+nσ+ℓv)}/Φ₁₀ dρdσdv`（同一被积函数、同一围道，
只是把 Φ̃₁ 换成 Φ₁₀）。

**引理 3（唯一性论证）**：Φ̃₁ 与 Φ₁₀ 都是 Sp(4,ℤ) 的权 10 尖点形式（BSS 正文
明确写 N=1 时 `Φ̃_k⁻¹` "exactly the inverse of the Igusa cusp form Φ₁₀"，
这蕴含二者权相同、零点除子相同）。**权 10 的 Sp(4,ℤ) 尖点形式空间是一维的**
（经典事实，Igusa 1962/1964；Gritsenko–Nikulin 1996 也以此为出发点使用
"the" Igusa cusp form 这一说法，隐含唯一性）。故存在常数 c 使 `Φ̃₁ = c·Φ₁₀`，
从而 `J = J₁₀/c`（同一分子、同一围道，分母相差常数 c）。代入：

`d*_BSS(平移后) = (−1)^{ℓ+1}·J₁₀/c`，而要求它等于 `d_*^Rosselló = (−1)^ℓ·J₁₀`，
即需 `(−1)^{ℓ+1}/c = (−1)^ℓ` ⟺ `c = −1`（对**一切** ℓ 同时成立，因为 c 是
不依赖 (m,n,ℓ) 的全局常数——这是引理 3 的关键：只要在**一个**非零 Fourier
系数处验证 c=−1，就对所有 (m,n,ℓ) 同时确立）。

**数值验证**（本人独立用本项目已有、已自测的 `torsion-immortal-positivity-hecke/
scripts/coefficients.py` 计算，见 `scripts/bss_crosscheck.py` 运行记录，附于下方）：
在对称代表元 (m,n,ℓ)=(1,1,0) 处（Δ=4>0，属目标域 n≥m≥1,0≤ℓ≤m，取等号），

- 本项目脚本给出（此前已有自测：`|c_1(1,0)|=50064` 对应文献公认的
  Q²=P²=2, Q·P=0 简并度）：`d_*^Rosselló(1,1,0) = (−1)^{0+1}c_1^F(1,0) = +50064`
  （用 Rosselló 自己的 (1.4) 式，`c_1^F(1,0)=−50064`）。
- Rosselló 本人在其 Table 1（本人读到的正文引用，Rosselló p.13 附近）报告
  同一代表元值为 `+50064`。
- BSS 在其 §5.3（eq 5.69 附近，p.51-52，本人逐字读到）报告翻译后同一代表元
  （BSS 记号 (n_B,ℓ,m_B)=(1,0,1)）的值同样是 `+50064`。

三者吻合，且 ℓ=0 处 `(−1)^{ℓ+1}/(−1)^ℓ=−1` 这一符号关系与 c=−1 的要求
**在该点确实需要且确实体现**（若 c=+1，代入会给出 BSS 应报告 −50064，
与其实际报告的 +50064 矛盾；只有 c=−1 才吻合三方数值）。

结合引理 3 的一维性论证（c 是全局常数，不随 ℓ 变化），**这一个非零系数处的
吻合足以确立 c=−1 对一切 (m,n,ℓ) 成立**，从而

**`d*_BSS(平移后，对一切 (m,n,ℓ)) = d_*^Rosselló(m,n,ℓ)`（无额外符号差）。**

**[GAP：一维性论证的第一性原理独立性]** 本人**信任** BSS 正文"Φ̃_k⁻¹ exactly
the inverse of Φ₁₀"这句话蕴含二者权相同、零点除子相同（从而适用经典一维性），
但未从 BSS 自己的一般乘积公式 (5.2) 出发、独立算出 N=1 时的具体权与零点结构
来做第一性原理确认——这是**信任转述**而非**本人独立算出**的一处，性质上比
§1/§3 的两条引理（纯字面定义比对，无信任风险）弱。但即使不借助引理 3 的
理论论证，仅凭数值验证结果本身（三方数值吻合，且只有 c=−1 吻合）已经是
**强证据**（不是"没有证据、纯粹猜"），只是未升格为"第一性原理证明"。

## §5. 定理（组装）

**定理（GAP 10.2b 的证明）**：设整数 m,n,ℓ 满足 m,n≥1、n≥m、0≤ℓ≤m、Δ=4mn−ℓ²>0。
则 `d_*(m,n,ℓ) = (−1)^{ℓ+1} c_m^F(n,ℓ)`。

**证明**：由引理 1 推论 1.1，翻译后的荷 (n_B,ℓ_B,m_B)=(m,ℓ,n) 落在 BSS 的
B₂⊆B 内。由 BSS Theorem 5.4(b)（§2 复核过的证明，只用 Prop B.1/B.2 的纯数学
围道论证）：`d*_BSS(n_B,ℓ_B,m_B) = (−1)^{ℓ_B+1} c_{n_B}^F(m_B,ℓ_B)`
（BSS 自己记号下的 ψ_{n_B}^F 系数）。由引理 2 推论 3.1，`c_{n_B}^F(m_B,ℓ_B)`
在变量对应下就是上游自己的 `c_m^F(n,ℓ)`（同一 Jacobi 形式族，同一变量，
只是荷标签替换 n_B→m, m_B→n, ℓ_B→ℓ）。由 §4 的符号分析（数值确认 + 一维性
论证，[GAP: 一维性论证的第一性原理独立性] 之外无其它缺口），
`d*_BSS(平移后) = d_*^Rosselló(m,n,ℓ)` 恰好、无额外符号。合并：

`d_*(m,n,ℓ) = d*_BSS(平移后) = (−1)^{ℓ+1} c_{n_B}^F(m_B,ℓ) = (−1)^{ℓ+1} c_m^F(n,ℓ)`。∎
