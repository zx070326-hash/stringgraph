## 2. 重标算子及其 Fourier 系数

对 s ≥ 1 令 A_s := diag(s,1) ∈ M₂(ℤ)，Ψ_s(Ω) := A_s Ω A_sᵀ，即

> Ψ_s : (ρ,σ,v) ↦ (s²ρ, σ, sv).

由 Im(A_sΩA_sᵀ) = A_s(Im Ω)A_sᵀ ≻ 0，Ψ_s 把 ℍ₂ 双全纯地映入 ℍ₂。对 ℍ₂ 上的函数 F 记
(𝒱_s F)(Ω) := F(Ψ_s Ω)，并令 𝒯_I := Σ_{s|I} s·𝒱_s。

**Lemma 2.1.** 设 F 在 ℍ₂ 上亚纯并满足 F(Ω+S) = F(Ω) 对一切整对称 S（Φ₁₀、1/Φ₁₀、𝒢 都满足）。则

(i) 𝒱_s F 亦满足同一周期性，并且额外满足 (𝒱_sF)(ρ+1/s², σ, v) = (𝒱_sF)(ρ,σ,v) 与
    (𝒱_sF)(ρ,σ,v+1/s) = (𝒱_sF)(ρ,σ,v)。

(ii) 若 F 在某区域有收敛 Fourier 展开 F = Σ a(m,n,ℓ)e^{2πi(mρ+nσ+ℓv)}，则在 Ψ_s 的原像区域
     𝒱_sF = Σ a(m,n,ℓ) e^{2πi(s²mρ + nσ + sℓv)}；特别地 𝒱_sF 的 (M,N,L) 系数为
     a(M/s², N, L/s)（当 s²|M 且 s|L），否则为 0。

(iii)（**FJ 层的身份**）若 F = 1/Φ₁₀ 且 1/Φ₁₀ = Σ_M ψ_M(σ,v)p^M，则
     `𝒱_s(1/Φ₁₀) = Σ_M (ψ_M | U_s)(σ,v) · p^{s²M}`，
     其中 (φ|U_s)(σ,v) := φ(σ,sv) 是 Eichler–Zagier 算子 U_s : J_{k,M} → J_{k,s²M}。
     换言之 𝒱_s(1/Φ₁₀) 的第 M′ 个 FJ 系数是 ψ_{M′/s²}|U_s，指标 (M′/s²)·s² = M′ 正确。

*证明.* (i) 周期性：Ψ_s(Ω+S) = A_s(Ω+S)A_sᵀ = Ψ_s(Ω) + A_sSA_sᵀ，而 A_sSA_sᵀ 对整对称 S
仍整对称，故 F 不变。额外周期性：ρ→ρ+1/s² 给 s²ρ → s²ρ+1；v→v+1/s 给 sv → sv+1，
均被 F 的 1-周期性吸收。
(ii) 直接代入 Ψ_s。给定 (M,N,L)，(m,n,ℓ) 需满足 s²m = M, n = N, sℓ = L，有整数解当且仅当
s²|M 且 s|L。
(iii) 1/Φ₁₀(s²ρ,σ,sv) = Σ_M ψ_M(σ,sv)e^{2πiMs²ρ}，重新按 p 的幂 M′ = s²M 整理即得。∎

**注 2.2（关于 claim.md 的记号警告）.** Lemma 2.1(iii) 之所以给出 U_s（而不是别的算子），
完全依赖"指标挂在 ρ 上"这一约定。若误用 DMZ 的标号（指标挂在 σ 上），同一重标会变成
ψ_m(σ,v) ↦ ψ_m(s²σ, sv)，那是一个只对子格 sℤσ+ℤ 保持椭圆性的算子，整个论证结构会不同。
这是本课题最容易出错的一步。

## 3. 伴随矩阵的协变性

对 (m,n,ℓ) ∈ ℤ³ 记半整 Gram 矩阵 T = T(m,n,ℓ) := [[m, ℓ/2],[ℓ/2, n]]，
则 det T = Δ/4，adj(T) = [[n, −ℓ/2],[−ℓ/2, m]]。

**Lemma 3.1.** 设 det T ≠ 0，s ≥ 1，T′ := A_s^{-1} T A_s^{-T}。则

> (a) `T′ = T(m/s², n, ℓ/s)`（作为实对称矩阵；当 s²|m, s|ℓ 时它是半整的）；
> (b) `A_s · adj(T) · A_sᵀ = s² · adj(T′)`；
> (c) `det T′ = det T / s²`，即 `Δ′ = Δ/s²`。

*证明.* (a) A_s^{-1} = diag(1/s,1) 对称，故 A_s^{-1}TA_s^{-T} = diag(1/s,1)·T·diag(1/s,1)
= [[m/s², ℓ/(2s)],[ℓ/(2s), n]] ✓。
(c) det T′ = det(A_s)^{-2}det T = det T/s²。
(b) 对可逆 2×2 矩阵 adj(X) = det(X)·X^{-1}。于是
adj(T′) = det(T′)·T′^{-1} = (det T/s²)·(A_sᵀ T^{-1} A_s) = (1/s²)·A_s adj(T) A_s
（用 A_sᵀ = A_s）。两边乘 s² 即得。直接验算亦可：
A_s adj(T) A_s = [[s²n, −sℓ/2],[−sℓ/2, m]] = s²[[n, −ℓ/(2s)],[−ℓ/(2s), m/s²]] = s² adj(T′)。∎

## 4. 吸引子围道协变性（核心定理）

对 (m,n,ℓ) 与 Λ > 0 定义（Rosselló (R5)/(R5′)）

> `C_*(m,n,ℓ; Λ) := { Ω ∈ ℍ₂ : Re ρ, Re σ, Re v ∈ [0,1], Im Ω = 2Λ·adj(T(m,n,ℓ)) }`

（当 m,n ≥ 1 且 Δ > 0 时 adj(T) 正定，故 Im Ω ≻ 0，围道确在 ℍ₂ 内。）对亚纯 F 记

> `𝔉[F; m,n,ℓ; Λ] := ∫_{C_*(m,n,ℓ;Λ)} F(Ω) · e^{−2πi(mρ+nσ+ℓv)} dρ dσ dv`

（三重实积分，实部各跑 [0,1]。）Rosselló 的免死指标是 d_*(m,n,ℓ) = 𝔉[𝒢; m,n,ℓ; Λ]，Λ 充分大。

> **引用的既有事实 (R9)**（Rosselló 定义 (R4)(R5) 的合法性所隐含，Sen 的吸引子围道处方）：
> 对 m,n ≥ 1, Δ > 0 存在 Λ₀(m,n,ℓ) 使得 ∀Λ > Λ₀，C_*(m,n,ℓ;Λ) 避开 1/Φ₁₀ 的全部极点，
> 且 𝔉[𝒢;m,n,ℓ;Λ] 与 Λ 无关。

**Theorem 4.1（吸引子围道协变性）.** 设 F 在 ℍ₂ 上亚纯且对一切整对称 S 满足 F(Ω+S)=F(Ω)。
设 (m,n,ℓ) 满足 m,n ≥ 1, Δ = 4mn−ℓ² > 0，s ≥ 1，Λ > 0。记 (m′,n′,ℓ′) := (m/s², n, ℓ/s)
（作为有理数），Λ′ := s²Λ。设 C_*(m′,n′,ℓ′;Λ′) 避开 F 的极点。则

> **(a)** 若 s²|m 且 s|ℓ（故 m′,ℓ′ ∈ ℤ）：
> `𝔉[𝒱_s F; m,n,ℓ; Λ] = 𝔉[F; m′, n′, ℓ′; Λ′]`.
>
> **(b)** 否则 `𝔉[𝒱_s F; m,n,ℓ; Λ] = 0`.

*证明.*

**第 1 步（围道的像）.** 作变量替换 (ρ′,σ′,v′) := Ψ_s(ρ,σ,v) = (s²ρ, σ, sv)。在
C_*(m,n,ℓ;Λ) 上 Im Ω = 2Λ adj(T)，故像的虚部是

  Im Ω′ = A_s (2Λ adj T) A_sᵀ = 2Λ·s²·adj(T′)  (Lemma 3.1(b))
        = 2Λ′·adj(T(m′,n′,ℓ′))  ,   Λ′ = s²Λ .

即**像恰好落在重标电荷 (m′,n′,ℓ′) 的吸引子围道所在的虚部切片上**，且 Λ′ = s²Λ > Λ > 0。
这是本定理的全部内容：先验地，像可以落在任意别的切片上（那就会与 C_*(m′,n′,ℓ′) 之间隔着
一些极点，两者相差多心留数），而事实上它精确落在吸引子切片上。

实部方面，像的实部区域是 Re ρ′ ∈ [0,s²], Re σ′ ∈ [0,1], Re v′ ∈ [0,s]。记该区域为 R。

**第 2 步（Jacobi 行列式与相位）.** dρ′dσ′dv′ = s²·1·s·dρ dσ dv = s³ dρdσdv。又作为复数恒等式

  m ρ + n σ + ℓ v = (m/s²)·(s²ρ) + n σ + (ℓ/s)·(sv) = m′ρ′ + n′σ′ + ℓ′v′ ,

（对任意实/有理 m′,ℓ′ 都成立，不需要整性）。于是

  𝔉[𝒱_sF; m,n,ℓ; Λ] = s^{−3} ∫_{R} F(Ω′) e^{−2πi(m′ρ′+n′σ′+ℓ′v′)} dρ′dσ′dv′ . (★)

**第 3 步（(a)：整性情形）.** 若 m′,ℓ′ ∈ ℤ，则 (★) 的被积函数在 Re ρ′、Re v′ 上都是周期 1 的
（F 由假设周期 1，指数因子因 m′,n′,ℓ′ ∈ ℤ 也周期 1）。故

  ∫_R = (∫_0^{s²}dρ′₁)(∫_0^1 dσ′₁)(∫_0^{s}dv′₁) = s²·1·s·∫_{[0,1]³} = s³·𝔉[F;m′,n′,ℓ′;Λ′] ,

与 (★) 的 s^{−3} 相消，得 (a)。

**第 4 步（(b)：非整性情形）.** 直接在原变量里论证。由 Lemma 2.1(i)，𝒱_sF 在
ρ ↦ ρ + 1/s² 与 v ↦ v + 1/s 下不变。把 𝒱_sF 限制在围道的实三维环面上，它是 (ρ₁,σ₁,v₁) 的
连续（**极点回避对任意实正定 T′ 均成立**：在 C_*(m,n,ℓ;Λ) 上，Im(Ψ_sΩ) = A_s(2Λ adj T)A_sᵀ = 2s²Λ adj(T′)（Lemma 3.1(b)）；由 m,n≥1, Δ>0 知 T 正定，故 T′ = A_s^{-1}TA_s^{-T} 亦正定，与 T′ 是否整值无关；因此 Im(Ψ_sΩ) ≻ 0 且各分量随 Λ→∞ 均匀趋于无穷；而 Φ₁₀ 的极点超平面（由 v=0 在 Sp(4,ℤ) 下的有限多个像给出）上至少一个 Im Ω 分量受线性约束、不能趋于无穷，故存在 Λ₀（仅依赖 s,m,n,ℓ）使 ∀Λ>Λ₀ 切片 Im Ω = 2s²Λ adj(T′) 避开 𝒢 的全部极点）周期函数，展成 Fourier 级数

  𝒱_sF|_{C_*} = Σ_{M,N,L ∈ ℤ} b(M,N,L) e^{2πi(Mρ₁+Nσ₁+Lv₁)}   （L² 意义下）,

则 𝔉[𝒱_sF;m,n,ℓ;Λ] = b(m,n,ℓ)·（虚部带来的常数相位因子，非零）。而上述额外周期性给出
b(M,N,L)·(e^{2πiM/s²} − 1) = 0 与 b(M,N,L)·(e^{2πiL/s} − 1) = 0，故 b(M,N,L) = 0 除非
s²|M 且 s|L。取 (M,N,L) = (m,n,ℓ) 即得 (b)。∎

**Corollary 4.2.** 取 F = 𝒢（它满足 Theorem 4.1 的周期性假设：Φ₁₀(Ω+S)=Φ₁₀(Ω) 对整对称 S，
因为 Φ₁₀ 的 Fourier 展开只含半整对称 T，Tr(ST) = am+bℓ+cn ∈ ℤ）：

> 对 m,n ≥ 1, Δ > 0, s²|m, s|ℓ：`𝔉[𝒱_s𝒢; m,n,ℓ; Λ] = d_*(m/s², n, ℓ/s)`。

（合法性：由 (R9)，Λ 充分大则 Λ′ = s²Λ 亦充分大，切片 Im Ω = 2Λ′adj(T′) 上无 1/Φ₁₀ 的极点，
从而由 Ψ_s 的双射性，切片 Im Ω = 2Λ adj(T) 上无 𝒱_s𝒢 的极点。

> **注（𝒢 与 1/Φ₁₀ 的极点集）**：𝒢(Ω) = −1/Φ₁₀(Ω+B)，B = [[0,1/2],[1/2,0]] 是**实**矩阵，
> 而集合 {Ω : Im Ω = Y} 在实平移下不变。因此"整个虚部切片 Im Ω = Y 上无极点"这一条件
> 对 𝒢 与对 1/Φ₁₀ 完全相同。故 (R9) 直接适用于 𝒢。围道 C_* 的实部取 [0,1]³ 只是取了该切片
> 上的一个基本域（被积函数在实部方向周期 1），不影响上述条件。）

**Proposition 4.4（d_* 的 S-对偶不变性，纯数学证明）.** 把 𝔉 的标号改用 Gram 矩阵：
对半整正定 T 记 `𝔉[F; T; Λ] := ∫_{C_*(T;Λ)} F(Ω)e^{−2πi Tr(ΩT)}dρdσdv`（与前面记号一致，
因 Tr(ΩT) = mρ + nσ + ℓv）。设 A ∈ SL(2,ℤ)，S_A F := F∘(Ω↦AΩAᵀ)。则对一切满足
Theorem 4.1 周期性假设的亚纯 F、一切正定半整 T 与 Λ > 0（切片无极点时）：

> `𝔉[S_A F; T; Λ] = 𝔉[F; A^{−T} T A^{−1}; Λ]` .

特别地（取 F = 𝒢 并用 S_A 𝒢 = 𝒢，Prop 7.1(a)）：

> `d_*(T) = d_*(A^{−T} T A^{−1})` ∀A ∈ SL(2,ℤ)，且 `d_*(m,n,ℓ) = d_*(m,n,−ℓ)`（Φ₁₀ 对 v 为偶）。
> **即 d_* 只依赖 T 的 GL(2,ℤ)-轨道。**

*证明.* 令 Ω′ = AΩAᵀ，T′ := A^{−T}TA^{−1}。
(1) *相位*：Tr(ΩT) = Tr(A^{−1}Ω′A^{−T}T) = Tr(Ω′·A^{−T}TA^{−1}) = Tr(Ω′T′)。
(2) *围道*：Im Ω′ = A(2Λ adj T)Aᵀ。而
   adj(T′) = det(T′)·T′^{−1} = (det T/det(A)²)·(A T^{−1}Aᵀ) = det(A)^{−2}·A adj(T) Aᵀ。
   由 det A = 1 得 A adj(T)Aᵀ = adj(T′)，故 Im Ω′ = 2Λ adj(T′)，**Λ 不变**。
(3) *实部与 Jacobi 行列式*：Ω ↦ AΩAᵀ 是 Sym₂(ℝ) 上的线性同构，行列式 det(A)³ = 1；
   它把整对称矩阵格 Sym₂(ℤ) 双射到自身（A S Aᵀ 与 A^{−1}S A^{−T} 都整），故把实部环面
   Sym₂(ℝ)/Sym₂(ℤ) 双射到自身，基本域映为基本域。被积函数在该环面上周期（F 周期 1；
   且 Ω′ ↦ Ω′+S 使 Tr(Ω′T′) 变化 Tr(ST′) ∈ ℤ，因 T′ 半整而 S 整对称）。故积分区域可换回
   标准基本域，值不变。
三条合起来即得。ℓ → −ℓ 一条：取 A = diag(1,−1)（det = −1），(2) 只用到 det(A)² = 1 仍成立，
T′ = T(m,n,−ℓ)，而 Φ₁₀(ρ,σ,−v) = Φ₁₀(ρ,σ,v) 保证 S_A𝒢 = 𝒢。∎

## 5. DGM eq(51) 与 eq(52) 不相容

记 D(m,n,ℓ) := 𝔉[1/Φ₁₀; m,n,ℓ; Λ]（吸引子围道下 1/Φ₁₀ 的系数），
则按 (R6′) d_*(m,n,ℓ) = (−1)^{ℓ+1}D(m,n,ℓ)。DGM 的三条式子（claim.md §0 逐字）：

- eq(51): `𝒵_I = Σ_{s|I} s/Φ₁₀(s²ρ,σ,sv) = 𝒯_I(1/Φ₁₀)`
- eq(52): `Ω_I(m,n,ℓ) = Σ_{s|I} s·Ω₁(m/s², n, ℓ/s)`，其中 Ω₁(m′,n′,ℓ′) = (−1)^{ℓ′+1}D(m′,n′,ℓ′)

**Proposition 5.1.** 设 (m,n,ℓ) 满足 I²|m, I|ℓ, m,n ≥ 1, Δ > 0。则

> (a) 由 eq(50)+(51)： `Ω_I(m,n,ℓ) = Σ_{s|I} s·(−1)^{ℓ − ℓ/s}·d_*(m/s², n, ℓ/s)`

## 7. 𝒢_I 的模性质：Γ₀(I) 不变性

**Proposition 7.1.** 对 A = [[a,b],[c,d]] ∈ SL(2,ℤ) 记 (S_A F)(Ω) := F(AΩAᵀ)（S-对偶作用）。则

> (b) `S_A 𝒢_I = 𝒢_I` 当且仅当…… 至少当 `A ∈ Γ₀(I) := {A ∈ SL(2,ℤ) : I | c}` 时成立。

(b) 若 I|c 则对每个 s|I 有 s|c，于是

## 8. crux 1 的答案：𝒯_I **不是**标准 Hecke 算子（否定回答）

任务书 crux 1 希望：若 `Z_I = Σ_{s|I}s/Φ₁₀(s²ρ,σ,sv)` 恰是某个 Siegel/Jacobi Hecke 算子作用在
1/Φ₁₀ 上的结果，则 eq(51) 自动是纯数学恒等式。本节给出**否定回答**，并说明它到底是什么。

**8.1 它在 Jacobi 层是 U_s 的正权组合。** 由 Lemma 2.1(iii)，𝒯_I 在第 M 个 FJ 系数上的作用是
`ψ_M ↦ Σ_{s|I, s²|M} s·(ψ_{M/s²}|U_s)`，U_s 是标准 Eichler–Zagier 算子 J_{k,M/s²}→J_{k,M}，
保持满模群级别。这一点是**肯定**的、纯数学的。

**8.2 但整体不是 Hecke 算子。** 两条理由：

(i) *与 Eichler–Zagier 的 T_p 对不上。* J_{k,m} 上的 Hecke 算子 T_p（p 素数，p∤m）在系数层
   同时含把判别式映到 p²Δ、Δ、Δ/p² 的三类项（Eichler–Zagier《The Theory of Jacobi Forms》§4）。
   而 𝒯_I 只含 Δ ↦ Δ/s² 一类（Lemma 3.1(c)），故 𝒯_I 至多是 Hecke 算子的"降幂部分"，
   不是任何 T_n 的标量倍。
   **[引用强度]** 这里 T_p 的三项结构是依记忆转述 EZ Thm 4.5，本轮未取得逐字原文；
   但理由 (ii) 是自足的、已证的，(i) 只是佐证。

(ii) *模性降级。* Hecke 算子把 Sp(4,ℤ)-形式送回 Sp(4,ℤ)-形式。而 Prop 7.1 表明
   𝒯_I(1/Φ₁₀) 与 𝒢_I 只在 Γ₀(I) 下不变，I > 1 时**不**是 Sp(4,ℤ)-不变的：
   取 A = [[1,0],[1,1]] ∉ Γ₀(I)（I>1），则 γ_s = [[1,0],[1/s,1]] ∉ M₂(ℤ) 对 s>1，
   论证断裂。（严格地说这只证明了 Prop 7.1 的论证对 A ∉ Γ₀(I) 失效，不构成"确实不变性破缺"
   的证明；**[GAP 8.3]** 严格证明 𝒢_I 对 I>1 不是 Sp(4,ℤ)-不变的，需要显式给出一个被破坏的
   系数等式——数值上应当容易做，本轮未做。）

**结论**：eq(51)（或其更正版 Prop 5.4）**不是**关于 Φ₁₀ 的 Hecke 恒等式，因此
"把 eq(51) 升级为纯数学定理"这条路**按 crux 1 设想的方式走不通**。真正可纯数学化的是
**免死投影与除子和的交换性**（Theorem 4.1），而除子和本身的**形式**（哪些 s、权重为何）
仍然是物理输入 (P)。这是本尝试对测绘「缝 A」两点未闭合的重新划界：
- 未闭合点 (i)（总简并度 vs 免死）：**已闭合**（Theorem 4.1 + Theorem 6.1）。
- 未闭合点 (ii)（归约公式本身的纯数学地位）：**未闭合，且本节表明它不可能靠 Hecke 理论闭合**——
  除子和不是模形式恒等式，而是一个定义。

## 9. crux 2：DMZ 分解与 U_t 是否交换（未闭合，障碍已定位）

本节给出把问题化到一条可陈述引理的完整推导，并证明"形式化论证必然失败"。

**9.1 平均算子。** 对指标 m ≥ 1 与 v 的函数 F 定义

> `Av^{(m)}[F](v) := Σ_{λ∈ℤ} q^{mλ²} e^{4πi m λ v} F(v + λσ)` .

Av^{(m)}[F] 满足指标 m 的椭圆变换律，且若 F 在 v₀ 有极点则 Av^{(m)}[F] 的极点集为
v₀ + ℤσ + ℤ。直接验算给出 DMZ 的权 2 Appell–Lerch 和：

> **Lemma 9.1.** `𝒜_{2,m} = Av^{(m)}[F₀]`，其中 `F₀(v) = y/(1−y)²`（y = e^{2πiv}）。

*证明.* Av^{(m)}[F₀](v) = Σ_λ q^{mλ²}y^{2mλ}·(q^λy)/(1−q^λy)² = Σ_λ q^{mλ²+λ}y^{2mλ+1}/(1−q^λ y)²
= 𝒜_{2,m}(σ,v)（与 claim.md (R3) 逐项相同）。∎

**Lemma 9.2（Av 与 U_t 的精确交换公式）.** 对 m ≥ 1, t ≥ 1 与任意 F，

> `Av^{(m)}[F](tv) = Σ_{r=0}^{t−1} q^{m r²} · Av^{(t²m)}[G_r](v)` ,  `G_r(v) := e^{4πi m t r v} F(tv + rσ)` .

*证明.* 把 λ = tμ + r（μ∈ℤ, 0≤r<t）代入：

 Av^{(m)}[F](tv) = Σ_r Σ_μ q^{m(tμ+r)²} e^{4πim(tμ+r)tv} F(t v + (tμ+r)σ)
                 = Σ_r q^{mr²} Σ_μ q^{(t²m)μ²} e^{4πi(t²m)μ v} ·
                       [ q^{2mtrμ} e^{4πi m r t v} F(t(v+μσ) + rσ) ] .

而 G_r(v+μσ) = e^{4πimtr(v+μσ)}F(t(v+μσ)+rσ) = e^{4πimtrv} q^{2mtrμ} F(t(v+μσ)+rσ)，
恰是方括号。故内和 = Av^{(t²m)}[G_r](v)。∎

**Lemma 9.3（theta 缺陷非零）.** 取 F = F₀。则
`G_r(v) = y^{2mtr}·(q^r y^t)/(1 − q^r y^t)²`，作为 y 的有理函数，分子次数 2mtr + t，
分母次数 2t。于是

> (a) r = 0 时 G_0 = y^t/(1−y^t)² 是**真分式**（在 y=0 与 y=∞ 处都为零），其部分分式分解无多项式部分；
> (b) 对 1 ≤ r ≤ t−1 且 m ≥ 1，2mtr + t ≥ 2t + t > 2t，G_r 是**非真分式**，其部分分式分解
>     `G_r = (各极点处的主部) + P_r(y)`，多项式部分 P_r ≠ 0，deg P_r = t(2mr − 1) ≥ t。

*证明.* 次数比较即得；非真分式的多项式商必非零。∎

**推论（障碍）.** 由 Lemma 9.1–9.3，

> `𝒜_{2,m}|U_t = Σ_{r=0}^{t−1} q^{mr²}·( Σ_{极点轨道} Av^{(t²m)}[主部] ) + Θ_{m,t}` ,
> `Θ_{m,t} := Σ_{r=1}^{t−1} q^{mr²} Av^{(t²m)}[P_r]` ,

而 Av^{(M)}[y^k] = Σ_λ q^{Mλ²+kλ}y^{2Mλ+k} 是**全纯**的（指标 M 的 theta 型函数）。
因此 𝒜_{2,m}|U_t **不是**纯粹的"Appell–Lerch 主部平均"，它比典范极部多出一个显式的、非零的
全纯 theta 组合 Θ_{m,t}（t ≥ 2 且 m ≥ 1 时非零）。既然 DMZ 典范分解把全纯部分归入**有限部**，
这意味着

> `(ψ_m|U_t)^F = (ψ_m^F)|U_t + (p₂₄(m+1)/Δ_{cusp}(σ))·Θ_{m,t} + （典范化差异项）` ,

即 **U_t 与 DMZ 分解不是形式上交换的**。t = 1 时 Θ ≡ 0，交换平凡成立。

**[GAP 9.4]（精确定位的障碍）.** 要把上式变成定理，还缺一步：

> 形式所取的**典范主部归一化**是什么？具体地，对每个极点 v₀，典范极部取
> `Av^{(t²m)}[F_{v₀}]` 中的 F_{v₀} 是哪一个（与 F₀(y)=y/(1−y)² 在 y↦1/y 下对称的归一化类比）？
> 不同的（同样"自然"的）归一化相差全纯 theta 项，恰好与 Θ_{m,t} 同型。

本 agent 未能从公开渠道抽取到 DMZ §8 的逐字定义（arXiv PDF 为压缩流，ar5iv 抽取在 §8 处截断），
故**无法判定** Θ_{m,t} 是被典范化吸收掉、还是真实的非交换缺陷。可攻性评估：
- 这是一条**有限、显式、可机器验证**的恒等式检验（给定 DMZ 的 F_{v₀}，两边都是显式级数）；
- 只要拿到 DMZ 1208.4074 §8（或 Cheng–Duncan–Harvey 1307.5793 §3.4，其中明确讨论

**注 9.5（为什么这条路比围道路难）.** 即使 L 成立，仍需第二步：把 "𝒢_I 的第 M 个 FJ 系数的

## 10. 还剩多少物理

**10.1 前提 (P) 的精确剩余。** Theorem 6.1 是关于 Φ₁₀ 的定理。把它读成
"挠 I 的单心黑洞指标为正"，只需要 (P) 的下述**最弱形式**：

> **(P′)**：挠 I 的单心（免死）BPS 指标等于 `Σ_{s|I} s · d_*(Q²/(2s²), P²/2, (Q·P)/s)`。

注意 (P′) 比 DGM 的整套论证弱：
- 不需要 eq(51)（按 Prop 5.1 它与 eq(52) 矛盾，应以 eq(52) 为准）；
- 不需要"免死投影与除子和交换"这一步——那已由 Theorem 4.1 变成定理；
- 只需要 eq(52) 本身，即"挠 I 的**总**指标 = 正权除子和"。

所以本尝试把缝 A 的物理依赖从"eq(51)+eq(52)+免死投影三件套"压缩到**单独一条 eq(52)**。

**10.2 一个新的数学限制（对 I=1 也成立）.** 数值扫描（§12）显示：

> 在扫描范围（m ≤ 16, n ≤ 4, 0 ≤ ℓ ≤ 2m, Δ>0，共 188 点）内：恒等式
> `d_*(m,n,ℓ) = (−1)^{ℓ+1} c_m^F(n,ℓ)` 的**全部 96 个反例都满足 n < m**；
> 换言之 **n ≥ m ⟹ 恒等式成立**（其逆不真：n < m 时也可能恰好成立，例如 (4,1,2)）。
> 显式反例：(m,n,ℓ) = (5,1,4) 与 (1,1,0) 属同一 GL(2,ℤ) 轨道，故 d_* = 50064 > 0，
> 但 (−1)^{4+1}c_5^F(1,4) = −2023536 < 0。

原因是结构性的：c_m^F(n,ℓ) 只依赖 (Δ, ℓ mod 2m)（指标 m 的 theta 分解），而这不是
SL(2,ℤ)-不变的标号；d_* 由吸引子围道定义，是 SL(2,ℤ)-不变的。两者只在 Gauss 约化型
(0 ≤ ℓ ≤ m ≤ n) 上必然一致——这恰好是 Rosselló Thm 1 的假设域。
这与 arXiv:2510.05219 摘要"for fixed m the coefficients d_*(m,n,ℓ) are known to be Fourier
coefficients of a mock Jacobi form of index m **with some restrictions**"吻合。

**推论**：任何在"总系数"或"未约化的 mock 系数"上做除子和的论证都是错的。Theorem 6.1
的每一项 d_*(m/s²,n,ℓ/s) 必须理解为**吸引子系数**（等价地，先做 Gauss 约化再读 mock 系数）。

## 11. 另一读法（若 eq(51) 才是对的）

为完整起见：若将来证实 DGM eq(51) 才是正确的、eq(52) 有笔误，则

> `d_*^{(I)}(m,n,ℓ) = Σ_{s|I} s·(−1)^{ℓ−ℓ/s}·d_*(m/s², n, ℓ/s)` (Prop 5.1(a))

此时正性**不再是 Rosselló Cor 1.1 的直接推论**，因为部分权为负。它归结为：

> **[GAP 11.2]（支配性引理）**：对 m,n ≥ 1, Δ > 0, I ≥ 1, I²|m, I|ℓ，
> `d_*(m,n,ℓ) > Σ_{s|I, s≥2} s · d_*(m/s², n, ℓ/s)` .

可攻性：由 Lemma 3.1(c)，右端各项的判别式是 Δ/s² ≤ Δ/4，而 Cardy/Rademacher 渐近
d_* ≍ exp(π√Δ)（主 polar 项主导，正是 Cardoso–Nampuri–Rosselló 2112.10023 与 Rosselló 2403.19630
的解析引擎），故右端相对左端指数压低，(GAP 11.2) 在大 Δ 区显然成立；难点只在小 Δ 的有限检验。
**本轮数值检验**（§12）：I ∈ {1,2,3,4,6}，219 个可计算的电荷点，(GAP 11.2) 无反例，
且两种读法都给出正值（最小的相对差约 6×10⁻³，见 (4,1,2) 行）。
**因此本尝试的正性结论对两种读法都稳健**，只是在 eq(51) 读法下需要额外的 GAP 11.2。

## 14. 结论

- **闭合的部分**：测绘「缝 A」未闭合点 (i)（"总简并度 vs 免死指标"的投影是否与除子和交换）
  已由 Theorem 4.1 严格闭合，主命题 Theorem 6.1 由此 + Rosselló Cor 1.1 给出
  **全挠免死正性的纯数学定理**（以 claim.md 定义 D 为免死指标的定义）。
- **未闭合的部分**：未闭合点 (ii)（除子和公式本身的纯数学地位）**仍未闭合**，并且 §8 给出了
  它为何不能靠 Hecke 理论闭合的理由——它不是模形式恒等式，而是一个 Γ₀(I)-形式的定义。
- **附带产出**：DGM eq(51) 与 eq(52) 的符号矛盾（含显式整数见证）与其唯一相容修正（Prop 5.4）；
  "mock 系数 = 免死指标"在 n < m 处失效的显式反例。
