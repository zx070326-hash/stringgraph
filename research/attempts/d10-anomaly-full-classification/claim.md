# claim: 十维反常自由候选规范代数的完整分类

## 背景与出处（本文件不是文献转录，是原创证明的起点命题）

对应图节点 `consistency.d10-anomaly-conditions-completeness-claim`（目前 `status: conjecture`）。
该图节点记录的文献状况（2026-09-12 Phase-0 复核结论）：

- GSW (1987) 原始出处 §13.5.3 只给出 SO(n) 与 E₈ 两支的具体验证，然后**裸断言**"这是仅有的候选"，不含候选集论证。
- antonelli-2015（唯一自称给出完整证明的来源）候选集框架正确（覆盖 Killing-Cartan 分类下所有紧致李代数，非人为限定子集），但计算执行有实质性错误：SU(3)/SU(4)/SU(5)/F₄/E₆ 的迹系数算错，F₄ 支所用方法本身无效。**不能作为该命题的 rigorous 来源。**
- 结论：候选集限定不是缺口（Killing-Cartan 分类是经典定理），真正缺口是**在这个经典候选集上正确执行有限排除计算**。

本文件的目的：把这条缺口写成一个精确到量词的命题，作为 `proof.md` 的证明目标。

## 记号与约定

- 沿用图中 `conv.gauge-trace-normalization`：对紧致（半单+阿贝尔）李代数 𝔤 及其上取值的二形式场强 F，**tr** 记某个固定"基本表示"上的迹（对单李代数指标准基本表示；对 u(1) 因子指该因子在整个规范群里的某个荷生成元），**Tr** 记伴随表示上的迹。両者都是 𝔤 上的（当 F 变化时）齐次多项式不变量：`tr F^k`、`Tr F^k` 是 F 的 k 次齐次对称不变函数。
- 𝔤 允许直和分解 𝔤 = 𝔤₁ ⊕ ⋯ ⊕ 𝔤_r ⊕ 𝔲，其中每个 𝔤_i 是紧致单李代数（Killing-Cartan 分类：A_n, B_n, C_n, D_n, G₂, F₄, E₆, E₇, E₈ 之一），𝔲 = u(1)^m 是阿贝尔部分（m ≥ 0）。F = (F₁, …, F_r, F_𝔲) 相应分块，Tr F^k = Σᵢ Trᵢ Fᵢ^k + Tr_𝔲 F_𝔲^k（伴随表示在直和下是各因子伴随表示的直和 ⊕ 平凡表示的重数，迹可加）。
- 条件 (i)（六阶反常因子化条件，adjoint 迹）：
  Tr F⁶ = (1/48)·Tr F⁴·Tr F² − (Tr F²)³ / 14400 ,   对**该 𝔤 上取值的一切** F 成立（多项式恒等式，非"存在 F"）。
- 条件 (ii)：dim 𝔤 = 496。

## 精确命题（要证的东西）

**命题（S）**：设 𝔤 是紧致李代数，dim 𝔤 = 496，且 (i) 作为 𝔤 上六次齐次多项式恒等式成立。则
𝔤 同构于下列四者之一：

1. so(32)（即 D₁₆ 型单李代数）
2. e₈ ⊕ e₈
3. e₈ ⊕ u(1)²⁴⁸
4. u(1)⁴⁹⁶

**量词展开**：
∀ 紧致李代数 𝔤，若 dim 𝔤 = 496 且 [∀ F ∈ 𝔤, Tr F⁶ = (1/48) Tr F⁴ Tr F² − (Tr F²)³/14400 （作为 F 的多项式恒等式，即两边作为 Sym⁶(𝔤*) 中的元素相等）]，则 𝔤 ≅ so(32) 或 e₈⊕e₈ 或 e₈⊕u(1)²⁴⁸ 或 u(1)⁴⁹⁶。

反过来"这四个确实满足 (i)(ii)"已经是图中节点 `consistency.d10-four-groups-satisfy-anomaly-conditions`
（effective status: `physical-argument`，被二手系数表卡压低，见该卡 notes），本命题不重复证明这一半，只证"没有第五个"。

- `math.tr-f6-coefficient-vanishing-u-n`（physical-argument，尚未升级，**暂不能当 rigorous 砖块用**——本证明若需要 U(n) 支的系数公式，必须自己重新推导或找可靠来源独立核实，不能直接引用这个未升级节点）。
- `consistency.abelian-factorization-is-not-cancellation`（Adams–DeWolfe–Taylor 2010）：阿贝尔方向的 GS 抵消项写不下来——这与本命题（只关心 (i)(ii) 两个条件，不管"抵消"）无直接依赖关系，但可用于验证 u(1)⁴⁹⁶、e₈⊕u(1)²⁴⁸ 两个解在条件 (i) 下的行为（阿贝尔因子对 Tr F⁶ 的贡献）。

## 证明可以怎么走（Phase-0 调研 agent 给出的骨架，仅供起步参考，需 theorem-prover 自行核实每一步）

1. **限制引理**：F 限制在极大环面（Cartan 子代数）上时，Tr F^k 的多项式恒等式若在环面上成立，则在全代数上也成立（用 Chevalley 限制定理：伴随不变多项式环由环面上的 Weyl-不变多项式环像同构给出，是环同态意义下的双射）。因此条件 (i) 可以只在 Cartan 子代数（对每个直和因子取各自 Cartan 生成元的线性组合）上检验。
2. **直和展开与交叉项**：Tr、tr 在直和下可加，六次幂展开后 Tr F⁶ 只有"来自单个因子的纯项"，而 Tr F⁴·Tr F²、(Tr F²)³ 会产生**跨因子的交叉项**（因为 Tr F⁴ 和 Tr F² 各自都是直和可加的，其乘积不是）。要求 (i) 对**任意** F（即任意因子分别取任意值）恒成立，逐个次数/因子模式比较系数，可以推出：非阿贝尔单因子的个数至多为 2（多于两个非阿贝尔因子时会产生无法被左边抵消的三次交叉项 (Tr F²)³ 里的混合项，除非某些因子的 Tr F² ≡ 0，但紧致李代数的 Killing 型正定，Tr F² 是正定二次型，不能恒为零，矛盾）。
3. **单因子的六阶不变量约化**：对每个允许出现的紧致单李代数类型（A_n…E₈, G₂, F₄），adjoint 表示的六次不变量 Tr F⁶ 通常可以用 tr F⁶、tr F⁴·tr F²、(tr F²)³ 的组合表出（因为大部分类型的独立六阶 Casimir 不变量个数有限，可查阅经典不变量论/Casimir本征值文献，如 Okubo 1982 或 van Ritbergen–Schellekens–Vermaseren hep-ph/9802376 附表），代入条件 (i) 后变成关于维数 N（或秩）的**代数方程**，逐类求解。
4. **逐类穷举**：A_n (su(n+1)), B_n (so(2n+1)), C_n (usp(2n)), D_n (so(2n)), G₂, F₄, E₆, E₇, E₈ 九个无穷/有限族，对每一类代入具体的迹恒等式系数（需要每一类的 tr F⁶、tr F⁴ tr F²、(tr F²)³ 之间的确切线性关系——**这是本证明需要独立核实的具体数值计算**，不能照抄 antonelli-2015 的表，因为那里的部分系数是错的），解出条件 (i) 在什么维数/秩下成立。已知：so(N)（N=32 时）、E₈ 成立；G₂/F₄/E₆/E₇ 及所有其他 A_n/C_n/D_n(N≠32) 需重新逐一验证是否有解。
5. **维数配分**：把第4步筛出的"允许出现的单因子候选列表"（大概率只剩 so(32) 单独、E₈ 单独）与阿贝尔因子做 496 维的整数配分组合，逐个检查条件 (i) 的**跨因子交叉项**是否也满足（不只是每个因子自己满足），得到最终四解。
