# Claim: ℓ=0 壁穿越自动良定（二阶极点留数恒为零）

## §0. 背景与动机

`research/attempts/gap-102b-route-a/proof.md` §3 发现：Rosselló 吸引子围道 `C_*(m,n,ℓ;Λ)` 在 ℓ=0 时退化为纯实围道（v 无虚部），可能命中 Φ₁₀ 的零点。定义 D 中 `𝒢 := −1/Φ₁₀(ρ,σ,v+1/2)` 的半周期平移使得 Φ₁₀ 零点在 v∈ℤ 对应 `𝒢` 极点在 **v∈ℤ−1/2**。由 Φ₁₀ 的周期性（Fourier 展开指标为整数 ⇒ 周期 1）与 Sen (D.19) 零点分支的 m₂ 自由性，极点集包含全体 v∈ℤ−1/2，特别地 **v=1/2 在围道 v₁∈[0,1] 内部**。

本项目另一条独立证实的事实：**Div(Φ₁₀) = 2H₁**（来源 Gritsenko–Nikulin 1996），即 Φ₁₀ 在 v=0 是**二阶零点**，故 `𝒢` 在 v=1/2（平移后）是**二阶极点**。

初等留数论：对 `1/(w^k h(w))` 型被积函数配指数核 `e^{−2πiℓw}`，
- k=1（一阶极点）⇒ Res = f(0)，**与 ℓ 无关**；
- k=2（二阶极点）⇒ Res 含指数核的导数项 ∝ ℓ·f(0)（精确常数因子见 §3，为 `(−1)^ℓ·2πi`），**线性正比于 ℓ**。

图里已登记的壁跨越跳变 `Δd ∝ (Q·P) = ℓ` 只与 k=2 相容（ℓ≠0 时留数非零，产生跳变）。

**核心结论（本 attempt 已证明）**：ℓ = Q·P = 0 时，v=1/2 处二阶极点的留数**恒等于零**（因为 Φ₁₀ 在 v 方向是偶函数，二阶极点本身不产生 v^{−1} 项；指数核 e^{−2πiℓv} 的导数 ∝ ℓ 在 ℓ=0 时退化为常数），因此围道从壁两侧穿过给出的值相同，对每个固定的 Λ>Λ₀，`d_*(m,n,0;Λ)` 不依赖于把围道推向哪一侧（即不依赖微扰参数 ε 的正负与大小），自动良定。**该公共值是否与 Λ 无关，本 attempt 未证**（[GAP-Λ]，见 §1 与 §5）。

## §1. 精确命题（量词级，可检验）

**Proposition A（ℓ=0 壁穿越的自动良定性）**。记 Rosselló 2403.19630 的吸引子围道
```
C_*(m,n,ℓ;Λ) := {Ω = (ρ v; v σ) : ρ=ρ₁+2inΛ, σ=σ₁+2imΛ, v=v₁+iℓΛ, (ρ₁,σ₁,v₁)∈[0,1]³}
```
以及 `𝒢(ρ,σ,v) := −1/Φ₁₀(ρ,σ,v+1/2)`（定义见 `graph/statements/holography/torsion-index-divisor-operator.yaml` 定义 D）。

设 m,n ≥ 1 为整数，ℓ=0。则围道 C_*(m,n,0;Λ) 退化为 v=v₁∈[0,1]（纯实数），**穿过** 𝒢 的二阶极点 v=1/2。但对任意 ε>0 充分小，定义两个微扰围道
```
C_±(ε,Λ) := {Ω : ρ=ρ₁+2inΛ, σ=σ₁+2imΛ, v=v₁±iεΛ, (ρ₁,σ₁,v₁)∈[0,1]³}
```
（v 的虚部从 0 微扰到 ±εΛ，避开实轴上的极点）。

断言：**存在 Λ₀ = Λ₀(m,n) > 0，使得对每一个 Λ > Λ₀，存在 ε₀ = ε₀(m,n,Λ) > 0，使得对所有 0<ε<ε₀**，
```
∫_{C_+(ε,Λ)} dρ dσ dv · 𝒢(ρ,σ,v)·e^{−2πi(mρ+nσ)} = ∫_{C_−(ε,Λ)} dρ dσ dv · 𝒢(ρ,σ,v)·e^{−2πi(mρ+nσ)}
```
**原因**：留数定理给出两侧之差 = 2πi × Res_{v=1/2}[𝒢·e^{−2πi(mρ+nσ)}]，而该留数 ∝ ℓ = 0（由 Φ₁₀ 的 v-偶性与二阶零点结构），故两侧值相同。

> **量词订正（2026-09-20，第二轮审查 F-6）**。本断言首版逐字写作「存在 ε₀>0 与 Λ₀>0，
> 使得对所有 0<ε<ε₀ 与 Λ>Λ₀」——把 `∃ε₀` 放在 `∀Λ` **之外**，等于断言了一个**对 Λ 一致的**

> 而 K₀ **随 Λ 移动**（`Im ρ = 2nΛ`、`Im σ = 2mΛ` 都正比于 Λ），故 δ 是 Λ 的函数，
> 由此得到的 ε₀ 也是。现按实际证到的强度把 `∃ε₀` 移进 `∀Λ` 之内。

**该公共值的 ε-无关性与 Λ-无关性，必须分开陈述**（2026-09-20 补，承重）：

## §3. 核心机制（非正式陈述，精确证明在 proof.md）

**关键发现（proof.md §3）**：Φ₁₀ 的周期性（Fourier 展开指标为整数 ⇒ 周期 1）与 Sen (D.19) 零点分支的 m₂ 自由性 ⇒ 零点在全体 v∈ℤ ⇒ 平移后 𝒢 的极点在 v∈ℤ−1/2。围道 v₁∈[0,1]（基本域）**确实包含** v=1/2，即**围道穿过极点**。

**留数 ∝ ℓ 的机制（proof.md §2）**：由 [EXT-Div] 与 [EXT-Even]，Φ₁₀ 在 v=0（或任意整数点，由周期性与偶性传递，引理 2.4）附近展开：
```
Φ₁₀(ρ,σ,v) = v² · h(ρ,σ,v),   h 在 v=0 全纯且 h₀ := h(ρ,σ,0) ≠ 0
```
且由 v-偶性，h 也是 v 的偶函数 ⇒ `h(ρ,σ,v) = h₀(ρ,σ) + h₂(ρ,σ)v² + ...`（只含偶次项）。

因此 `𝒢 = −1/Φ₁₀` 在 v=1/2（对应 w=v+1/2=1，局部坐标 s=w−1=v−1/2）附近展开：
```
𝒢(ρ,σ,v) = −s^{−2}/h(ρ,σ,1+s) = −(1/h₀)·s^{−2} + (h₂/h₀²) + O(s²)
```
**不含 s^{−1} 项**（因 h 的展开只有偶次项）。

**但被积函数还有指数核**（`v = u − 1/2 = 1/2 + s`，ℓ 为整数）：
```
e^{−2πiℓv} = e^{−2πiℓ(1/2+s)} = e^{−πiℓ}·e^{−2πiℓs} = (−1)^ℓ·[1 − 2πiℓ·s + O(s²)]
```
乘起来（注意 `[−(1/h₀)s^{−2}]·[−2πiℓ·s]` 两个负号相乘得**正**）：
```
𝒢·e^{−2πiℓv} = [−(1/h₀)·s^{−2} + ...] · (−1)^ℓ·[1 − 2πiℓ·s + ...]
             = (−1)^ℓ·[−(1/h₀)·s^{−2} + 2πiℓ·(1/h₀)·s^{−1} + O(1)]
```
**留数（对 v 积分，围绕 v=1/2）= (−1)^ℓ·2πiℓ·(1/h₀)**，正比于 ℓ。

> **订正记录（2026-09-20，第二轮审查连带发现）**：本节首版逐字写作
> 「`e^{−2πiℓv} = … = 1 − 2πiℓ·s + O(s²)`」与「**留数 = −2πiℓ·(1/h₀)**」，有**两处**错误：
> (i) 丢掉了常数相位 `e^{−πiℓ} = (−1)^ℓ`；(ii) `[−(1/h₀)s^{−2}]·[−2πiℓ·s]` 的两负相乘
> 被算成了负号。这两处早先已在 proof.md §2.5 就地订正（见该处【订正记录】），
> **但 claim.md 当时未同步**，本次补齐。
> **两处都是与 ℓ 的零点无关的常数因子，`∝ ℓ` 这一核心结论以及下面 ℓ=0 的结论完全不受影响**；
> 但 proof.md §4.2 的壁跨越符号读法只能用订正后的式子。
> （本轮亲自重算确认：`v=1/2+s ⟹ e^{−2πiℓv}=(−1)^ℓ e^{−2πiℓ s}`，s^{−1} 系数
> `= (−1)^ℓ·(−1/h₀)·(−2πiℓ) = (−1)^ℓ·2πiℓ/h₀`。与图卡
> `holography.phi10-shifted-pole-residue-proportional-to-ell` 标题里的
> `Res = (−1)^ℓ·2πiℓ/h₀` 一致。）

**ℓ=0 的结论**：留数 = 0 ⇒ 围道两侧之差 = 2πi × 0 = 0 ⇒ `d_*(m,n,0)` 自动良定，不需要主值规定。
