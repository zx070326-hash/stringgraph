# Claim: ℓ=0 壁穿越自动良定（二阶极点留数恒为零）

## §0. 背景与动机

`research/attempts/gap-102b-route-a/proof.md` §3 证明了：ℓ=0 时，Rosselló 吸引子围道 `C_*(m,n,0;Λ)` 对任意 Λ>0 都恒过 Φ₁₀ 的零点 v=0。因此 `d_*(m,n,0)` 的定义式（围道积分 `∫ 𝒢·e^{−2πi(mρ+nσ+ℓv)}`，其中 `𝒢 = −1/Φ₁₀(ρ,σ,v+1/2)`）按字面理解是**穿过** `1/Φ₁₀` 的极点的积分。

本项目另一条独立证实的事实：**Div(Φ₁₀) = 2H₁**（来源 Gritsenko–Nikulin 1996），即 Φ₁₀ 在 v=0 是**二阶零点**，故 `1/Φ₁₀` 在那里是**二阶极点**。

初等留数论：对 `1/(w^k h(w))` 型被积函数配指数核 `e^{−2πi(Q·P)w}`，
- k=1（一阶极点）⇒ Res = f(0)，**与 Q·P 无关**；
- k=2（二阶极点）⇒ Res = f'(0) = −2πi(Q·P)·f(0) + (h 的导数项)，**线性正比于 Q·P**。

图里已登记的壁跨越跳变 `Δd ∝ (Q·P)` 只与 k=2 相容。

**核心猜想（本 attempt 要证或证伪）**：ℓ = Q·P = 0 时，v=0 处二阶极点的留数**恒等于零**（因为 Φ₁₀ 在 v 方向是偶函数，二阶极点的 1/v 项系数自动消失），因此围道从壁两侧穿过给出的值相同，`d_*(m,n,0)` 与 Λ 无关且无歧义。

## §1. 精确命题（量词级，可检验）

**Proposition A（ℓ=0 壁穿越的自动良定性）**。记 Rosselló 2403.19630 的吸引子围道
```
C_*(m,n,ℓ;Λ) := {Ω = (ρ v; v σ) : ρ=ρ₁+2inΛ, σ=σ₁+2imΛ, v=v₁+iℓΛ, (ρ₁,σ₁,v₁)∈[0,1]³}
```
以及 `𝒢(ρ,σ,v) := −1/Φ₁₀(ρ,σ,v+1/2)`（定义见 `graph/statements/holography/torsion-index-divisor-operator.yaml` 定义 D）。

设 m,n ≥ 1 为整数，ℓ=0。则对任意 ε>0 充分小，定义两个微扰围道
```
C_±(ε,Λ) := {Ω : ρ=ρ₁+2inΛ, σ=σ₁+2imΛ, v=v₁±iεΛ, (ρ₁,σ₁,v₁)∈[0,1]³}
```
（v 的虚部从 0 微扰到 ±εΛ；ρ,σ 的虚部保持不变）。

断言：存在 ε₀>0 与 Λ₀>0，使得对所有 0<ε<ε₀ 与 Λ>Λ₀，
```
∫_{C_+(ε,Λ)} dρ dσ dv · 𝒢(ρ,σ,v)·e^{−2πi(mρ+nσ)} = ∫_{C_−(ε,Λ)} dρ dσ dv · 𝒢(ρ,σ,v)·e^{−2πi(mρ+nσ)}
```
且该公共值与 ε,Λ 无关（在各自允许范围内）。

**Proposition B（更强形式：主值积分存在）**。若能证明主值积分
```
lim_{ε→0+} ∫_{C_+(ε,Λ)} dρ dσ dv · 𝒢(ρ,σ,v)·e^{−2πi(mρ+nσ)}
```
存在且与 Λ 无关（对 Λ>Λ₀），则该值自然定义为 `d_*(m,n,0)`。

## §3. 核心机制（非正式陈述，精确证明在 proof.md）

Φ₁₀ 在 v=0 的 Laurent 展开（由 [EXT-Div] 与 [EXT-Even]）：
```
Φ₁₀(ρ,σ,v) = v² · h(ρ,σ,v),   h 在 v=0 全纯且 h(ρ,σ,0) ≠ 0
```
且由 [EXT-Even]，`Φ₁₀(ρ,σ,v) = Φ₁₀(ρ,σ,−v)` ⇒ h 也是 v 的偶函数 ⇒ `h(ρ,σ,v) = h₀(ρ,σ) + h₂(ρ,σ)v² + ...`（只含 v 的偶次幂）。

因此 `1/Φ₁₀ = v^{−2} / h = v^{−2} · [h₀^{−1} − (h₂/h₀²)v² + ...]`，其 v^{−1} 项系数**恒为零**。

围道积分 `∫ 𝒢·e^{−2πi(mρ+nσ+ℓv)}` 在 ℓ=0 时，被积函数对 v 的依赖只剩 `𝒢(ρ,σ,v)` 本身（指数核 `e^{−2πiℓv} = 1` 常数）。v=0 处二阶极点的留数（对 v 积分）= 1/Φ₁₀ 展开里的 v^{−1} 项系数 = 0。

因此围道穿过 v=0 时，两侧之差（由 Cauchy 留数定理）= 2πi × 0 × (ρ,σ 积分) = 0，即两侧值相同。

## §4. 需要处理的技术细节（proof.md 的任务清单）

1. **半周期平移的影响**：`𝒢 := −1/Φ₁₀(ρ,σ,v+1/2)` 中的 `v ↦ v+1/2` 使得 Φ₁₀ 的零点从 v=0 **移到** v=−1/2。需要核实：
   - 围道 v₁∈[0,1] 是否包含 v=−1/2（若 v₁=1/2 在围道内部，需要重新定位极点）；
   - 若极点在 v=−1/2，Φ₁₀(ρ,σ,v+1/2) 在 v=0 处**不是**奇点，这会改变整个图像。

2. **Laurent 展开的精确形式**：用 Sen 2008 (C.26) 或 Gritsenko–Nikulin 的展开，逐项写出 `1/Φ₁₀(ρ,σ,v+1/2)` 在 v=−1/2 附近的主部与留数（对 v 的留数，ρ,σ 固定）。验证 v^{−1} 项系数为零。

3. **围道变形的合法性**：证明对 ε 充分小，C_±(ε,Λ) 不穿过 `1/Φ₁₀` 的**其它**极点（除 v=−1/2 外）。这需要用到 gap-102b-route-a §4/§5 的技巧（n2=0 分支已完全排除，n2≠0 分支有未闭合 GAP，但 ℓ=0 情形可能特殊）。

4. **与 Rosselló Cor 1.1 的兼容性**：ℓ=0 时 Δ=4mn>0，满足 Cor 1.1 的判别式条件。若 [GAP-ℓ0] 使 d_*(m,n,0) 无定义，Cor 1.1 本身就有问题——这个张力本身是强证据，支持"ℓ=0 自动良定"而非"需要人为规定主值"。

5. **物理解释**：ℓ = Q·P = 0 的 dyon 落在两心态 (Q,0)+(0,P) 的边缘稳定壁上；壁跨越跳变 `Δd ∝ ⟨Γ₁,Γ₂⟩ ∝ Q·P` 在此退化为零，即**壁两侧指标相同，这堵"墙"是透明的**。核对这是已知物理事实还是新观察。
