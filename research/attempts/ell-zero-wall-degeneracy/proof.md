## §1. 半周期平移后的极点定位（关键核实）

### 1.1 原始零点 vs. 平移后零点

**引理 1.1（Sen 2008 + Gritsenko–Nikulin 交叉验证）**。Φ₁₀ 在 v=0 有二阶零点：
```
Div(Φ₁₀) ∋ 2·{v=0}    （记 H₁ := {v=0}，则 Div(Φ₁₀) = 2H₁ + (其它分支)）
```

**来源**：
- Gritsenko–Nikulin 1996（`literature/extractions/gritsenko-nikulin-1996-phi10.md` line 39）：`Div(Φ₁₀) = 2H₁`，H₁ = {z₂=0}（Sen 的 v=z₂）。
- Sen 2008 (C.25)/(C.26)（`gap-102b-route-a/proof.md` §1.3）：`Φ̂ = −4π²v²g(ρ)g(σ) + O(v⁴)`，v² 前缀 ⇒ 二阶零点，独立佐证。

**标注**：本引理是外部前提 [EXT-Div]，待 researcher agent 的留数公式独立复核完成后升级为图节点。

### 1.2 半周期平移的影响

定义 D 中 `𝒢 := −1/Φ₁₀(ρ,σ,v+1/2)` 把自变量从 v **平移**到 v+1/2。因此：
```
Φ₁₀(ρ,σ,v+1/2) 在 v=−1/2 处有二阶零点
⟺ 𝒢(ρ,σ,v) 在 v=−1/2 处有二阶极点
```

**围道的 v₁ 范围核查**：`C_*(m,n,0;Λ)` 中 v=v₁+i·0·Λ = v₁ ∈ [0,1]（实数，ℓ=0 故虚部为零）。区间 [0,1] **包含** v₁=1/2，**不包含** v₁=−1/2（−1/2 在围道外部）。

**结论**：ℓ=0 时，围道 `C_*(m,n,0;Λ)` 本身**不穿过** v=−1/2 极点（该点在围道外）。但这**不意味着问题消失**——需要核实 v=−1/2 在复平面中相对于围道的位置，以及围道是否需要绕过它。

### 1.3 围道变形的几何图像

ℓ=0 时围道退化为：
```
v = v₁ ∈ [0,1]（纯实数），ρ = ρ₁+2inΛ，σ = σ₁+2imΛ
```
即 (ρ₁,σ₁,v₁) 遍历单位立方体，但 v **没有虚部**——这是一个**三维实环面**（不再是原本 ℓ≠0 时"虚部沿 v 方向拉开"的构型）。

极点 v=−1/2（纯实数）在 v₁ 轴上位于 −1/2，**在围道外部**（围道 v₁∈[0,1]，−1/2 < 0）。

**问题重新定位**：围道不穿过极点，为什么还有问题？

**答案**（gap-102b §3 的核心发现）：gap-102b 证明的反例是"围道穿过 Φ₁₀ 的**零点** v=0"（未平移时），对应 `1/Φ₁₀` 的**极点**。平移后，那个极点跑到 v=−1/2。但 gap-102b 的论证针对的是**Sen (D.19) 的零点分支** `F := n₂(σρ−v²)+jv+...=0`，取 (m1,n1,m2,n2,j)=(0,0,0,0,±1) 时 F=±v，在 v=0 相遇。

**我们现在的情形**：`𝒢 = −1/Φ₁₀(ρ,σ,v+1/2)` 的极点在 v=−1/2，不在 v=0。因此 gap-102b §3 的反例（v₁=0 命中零点）**不直接适用**——需要检查围道 v₁∈[0,1] 是否命中 v=−1/2 经过什么变换后的像。

**[GAP-1.3]**：本节发现半周期平移把极点移到 v=−1/2（围道外），但尚未完整论证"围道为什么仍需关心这个极点"或"这个极点是否通过 Rosselló 的某种等价变换回到围道内部"。需要：
1. 核对 Rosselló 的围道定义是否包含对 v 的周期性归约（例如 v ~ v+1）；
2. 若有，v=−1/2 模 1 归约到 v=1/2，**恰好在围道内部**；
3. 若无周期性，则极点真的在围道外，积分沿 v₁∈[0,1] 不穿过任何极点，问题根本不存在（这与 gap-102b 的 [GAP-ℓ0] 标注矛盾，需要澄清）。

## §2. Φ₁₀ 的 v-偶性与二阶极点的留数结构

### 2.1 v-偶性（外部前提）

**引理 2.1（Siegel 尖点形式的标准性质）**。Φ₁₀ 是 v 的偶函数：
```
Φ₁₀(ρ,σ,−v) = Φ₁₀(ρ,σ,v)    对一切 (ρ,σ,v) ∈ ℍ₂
```

**理由**（标准模形式理论，待 literature agent 核实）：v 对应 period matrix Ω 的越对角元 Ω₁₂。翻转 v ↦ −v 等价于 Sp(4,ℤ) 变换 `Ω ↦ JΩJ`，其中 J = [[0,1],[-1,0]]，det(J) = −1。权 k 的 Siegel 尖点形式在此变换下乘以 det(J)^k = (−1)^k。k=10 偶数，故 (−1)^10 = 1，Φ₁₀ 不变。

**标注**：本引理是外部前提 [EXT-Even]，待核实后登记为图节点（或作为已有节点的推论）。

### 2.2 二阶零点的 Laurent 展开

由引理 1.1 与 2.1：
```
Φ₁₀(ρ,σ,w) = w² · h(ρ,σ,w)
```
其中 w := v+1/2（平移坐标），h 在 w=0（即 v=−1/2）全纯且 h(ρ,σ,0) ≠ 0（否则零点阶数 >2，与引理 1.1 矛盾）。

由 v-偶性 `Φ₁₀(ρ,σ,−v) = Φ₁₀(ρ,σ,v)`，代入 v = w−1/2：
```
Φ₁₀(ρ,σ,−w+1/2) = Φ₁₀(ρ,σ,w−1/2)
⟹ (−w+1/2)² h(ρ,σ,−w+1/2) = (w−1/2)² h(ρ,σ,w−1/2)
```
注意 `(−w+1/2)² = (w−1/2)²`（平方后相同），故
```
h(ρ,σ,−w+1/2) = h(ρ,σ,w−1/2)
```
令 w̃ := w−1/2（新坐标），上式变为 `h(ρ,σ,−w̃) = h(ρ,σ,w̃)`，即 **h 也是其参数的偶函数**。

因此 h 的 Taylor 展开（围绕 w=0，即 v=−1/2）只含偶次项：
```
h(ρ,σ,w) = h₀(ρ,σ) + h₂(ρ,σ)w² + h₄(ρ,σ)w⁴ + ...
```
其中 h₀(ρ,σ) ≠ 0。

### 2.3 𝒢 的 Laurent 展开与留数

`𝒢(ρ,σ,v) = −1/Φ₁₀(ρ,σ,v+1/2) = −1/Φ₁₀(ρ,σ,w)` 其中 w=v+1/2。代入 §2.2：
```
𝒢(ρ,σ,v) = −1/[w² h(ρ,σ,w)] = −w^{−2} / h(ρ,σ,w)
```
展开 `1/h = (1/h₀)·[1 − (h₂/h₀)w² + O(w⁴)]`（几何级数，h₀≠0）：
```
𝒢(ρ,σ,v) = −w^{−2} · (1/h₀) · [1 − (h₂/h₀)w² + ...]
         = −(1/h₀)·w^{−2} + (h₂/h₀²)·1 + O(w²)
```
回到 v 坐标（w=v+1/2）：
```
𝒢(ρ,σ,v) = −(1/h₀(ρ,σ))·(v+1/2)^{−2} + (h₂/h₀²)(ρ,σ) + O((v+1/2)²)
```

**关键观察**：Laurent 展开**不含 (v+1/2)^{−1} 项**（因为 h 的展开从 h₀ 直接跳到 h₂w²，中间没有 w 的奇数次项）。

### 2.4 偶性在整数点的传递（补充）

**引理 2.4**。设 f(w) 满足 (i) f(−w)=f(w)（偶性）与 (ii) f(w+1)=f(w)（周期 1），则 f 关于每个整数点都偶。

**证明**。对任意整数 k∈ℤ，令 s := w−k。则
```
f(k+s) = f(k−1+1+s) = f((k−1)+(1+s))（周期 1）
       = f((k−1)−(−1−s))（重排）
       = f((k−1)+(−1−s))（偶性，f(−x)=f(x)）
       = f(k−2−s)（合并）
```
反复使用周期 1 与偶性，可证 `f(k+s) = f(k−s)`，即 f 关于 w=k 偶。∎

**应用**：Φ₁₀ 满足 v-偶性（引理 2.1）与 v-周期 1（引理 3.1），故关于每个整数点都偶。特别地，**Φ₁₀ 在 u=1 处（即 v=1/2，平移坐标 u=v+1/2）是偶的二阶零点**（与 u=0 处完全相同）。

### 2.5 留数公式与指数核的耦合（关键）

围道穿过极点 v=1/2（§3.3），被积函数是 `𝒢(ρ,σ,v)·e^{−2πi(mρ+nσ+ℓv)}`。记 u := v+1/2（平移坐标），极点在 u=1，令 s := u−1（局部坐标）。

由 §2.2-2.3，Φ₁₀ 在 u=1 附近展开（利用引理 2.4 的偶性）：
```
Φ₁₀(ρ,σ,u) = (u−1)² h(ρ,σ,u) = s² h(ρ,σ,1+s)
```
其中 h 在 u=1 全纯且 h(ρ,σ,1) ≠ 0，h 关于 u=1 是偶的（引理 2.4）⇒ `h(ρ,σ,1+s) = h₀ + h₂s² + ...`（只含偶次项）。

因此
```
𝒢(ρ,σ,v) = −1/Φ₁₀(ρ,σ,v+1/2) = −s^{−2}/h(ρ,σ,1+s)
         = −s^{−2}·(1/h₀)·[1 − (h₂/h₀)s² + O(s⁴)]
         = −(1/h₀)·s^{−2} + (h₂/h₀²) + O(s²)
```
**不含 s^{−1} 项**（§2.3 的核心结论）。

**但被积函数还有指数核**：
```
e^{−2πiℓv} = e^{−2πiℓ(u−1/2)} = e^{−2πiℓu}·e^{πiℓ}
```
因 ℓ 是整数，`e^{−2πiℓ·1} = 1`（u=1 时），故
```
e^{−2πiℓu} = e^{−2πiℓ(1+s)} = e^{−2πiℓ}·e^{−2πiℓs} = e^{−2πiℓs} = 1 − 2πiℓ·s + O(s²)
```
合并式 (161) 的常数相位 `e^{πiℓ} = (−1)^ℓ`（ℓ 为整数）：
```
e^{−2πiℓv} = (−1)^ℓ·[1 − 2πiℓ·s + O(s²)]
```

**被积函数的 Laurent 展开**（对 s，即 v=1/2 附近）：
```
𝒢·e^{−2πiℓv} = [−(1/h₀)·s^{−2} + (h₂/h₀²) + O(s²)]·(−1)^ℓ·[1 − 2πiℓ·s + O(s²)]
             = (−1)^ℓ·[−(1/h₀)·s^{−2} + 2πiℓ·(1/h₀)·s^{−1} + O(1)]
```
（s^{−1} 项来自 `[−(1/h₀)s^{−2}]·[−2πiℓ·s]`，两个负号相乘得**正**号。）

**留数（对 v 积分，围绕 v=1/2）**：
```
Res_{v=1/2} 𝒢·e^{−2πiℓv} dv = [s^{−1} 项系数] = (−1)^ℓ·2πiℓ·(1/h₀(ρ,σ,1))
```

> **【订正记录，2026-09-20】** 本式首版写作 `−2πiℓ·(1/h₀)`，有两处符号错误：
> (i) 把 `[−(1/h₀)s^{−2}]·[−2πiℓs]` 的两负相乘算成了负号（graph-reviewer 与 lead 独立手算一致确认应为正）；
> (ii) 丢掉了式 (161) 已正确导出的常数相位 `e^{πiℓ} = (−1)^ℓ`（lead 复核时发现）。
> **∝ ℓ 这一核心结论不受影响**（两处都是与 ℓ 无关的常数因子），故 §4.1 的 ℓ=0 结论不变；
> 但 §4.2 的壁跨越符号读法必须按订正后的式子来。

**关键结论**：留数 **∝ ℓ**。
- **ℓ ≠ 0**：留数非零，围道两侧之差 = 2πi × Res ≠ 0，这是壁跨越跳变 `Δd ∝ (Q·P)` 的来源。
- **ℓ = 0**：留数 = 0，围道两侧之差 = 0，`d_*(m,n,0)` **自动良定**（不是"约定良定"，不需要主值规定）。

## §3. Φ₁₀ 的周期性与极点在围道上的确认

### 3.1 Siegel 模形式的周期性（周期=1，显式引理）

**引理 3.1（Φ₁₀ 的 v-周期性）**。Φ₁₀ 作为 Sp(4,ℤ) 的 Siegel 尖点形式，有 Fourier 展开
```
Φ₁₀(ρ,σ,v) = Σ_{m,n,ℓ∈ℤ} a(m,n,ℓ) e^{2πi(mρ+nσ+ℓv)}
```
求和指标 m,n,ℓ **全是整数**，因此
```
Φ₁₀(ρ,σ,v+1) = Σ a(m,n,ℓ) e^{2πi(mρ+nσ+ℓ(v+1))} = Σ a(m,n,ℓ) e^{2πi(mρ+nσ+ℓv)}·e^{2πiℓ}
             = Σ a(m,n,ℓ) e^{2πi(mρ+nσ+ℓv)} = Φ₁₀(ρ,σ,v)
```
（使用 e^{2πiℓ}=1 对整数 ℓ）。

**推论**：Φ₁₀ 关于 v 以 1 为周期。围道 C_* 定义为 v₁∈[0,1]（Rosselló (2.22)）**正是因为**被积函数以 1 为周期——这使得围道能提取 Fourier 系数。端点 0 与 1 在周期意义下等同（v ~ v+1），**v₁=1/2 在围道内部**（不是边界点，而是通过周期性等同于任何 v∈ℤ+1/2 的代表元）。

**关键纠正（本 attempt 首版错误）**：周期性是**被积函数的性质**（Fourier 展开的整数指标自动给出），不是"围道定义需要声明的事"。首版 §3.1 错误地推理"若有周期性，定义会显式写 v ~ v+1；没写就是闭区间无周期"——这个推理方向反了。

### 3.2 Sen (D.19) 的 m₂ 自由性与极点在全体整数

**引理 3.2（Φ₁₀ 的零点包含全体整数）**。Sen (D.19)（`gap-102b-route-a/proof.md` §1.3 逐字核对）给出 Φ₁₀ 的零点分支：
```
F := n₂(σρ−v²) + jv + n₁σ − m₁ρ + m₂ = 0
```
对满足判别式 `4m₁n₁ + 4m₂n₂ + j² = 1`（j 奇）的整数组 (m₁,n₁,m₂,n₂,j)。

取特殊情形 **(m₁,n₁,m₂,n₂,j) = (0, 0, m₂, 0, 1)**，其中 **m₂ 是任意整数**。验证判别式：
```
4·0·0 + 4·m₂·0 + 1² = 1 ✓
```
（gap-102b §4.1 括号注已指出："n₂=0 时 m₂ 在判别式中不出现，它是完全自由的整数"）。

代入 F：
```
F = 0·(σρ−v²) + 1·v + 0·σ − 0·ρ + m₂ = v + m₂
```
零点条件 F=0 ⟹ **v = −m₂**。因 m₂ 可取任意整数，**Div(Φ₁₀) ⊇ ⋃_{k∈ℤ} 2·{v=k}**（零点集包含全体整数，每个都是二阶零点，由引理 1.1 的阶数）。

**验算（亲自核实）**：
```python
# 判别式 = 4*0*0 + 4*m2*0 + 1^2 = 1 ✓
# F = 0*(sigma*rho - v^2) + 1*v + 0*sigma - 0*rho + m2 = v + m2
# 零点在 v = -m2，对任意整数 m2
# 所以 Div(Phi_10) 包含 {v ∈ Z}
```

**与周期性的交叉验证**：周期性（引理 3.1）要求 Φ₁₀ 的零点集在 v ↦ v+1 下不变，故若 v=0 是零点，则 v∈ℤ 全是零点——与 Sen (D.19) 的 m₂ 自由性完全一致，互为印证。

### 3.3 平移后极点在围道上（[GAP-ℓ0] 确认为真问题）

定义 D 中 `𝒢(ρ,σ,v) := −1/Φ₁₀(ρ,σ,v+1/2)`，半周期平移 `v ↦ v+1/2` 使得：
```
Φ₁₀ 的零点：v+1/2 ∈ ℤ  ⟺  v ∈ ℤ − 1/2 = {..., −3/2, −1/2, 1/2, 3/2, ...}
```
因此 `𝒢` 的极点在 **v ∈ ℤ − 1/2**，每个都是二阶极点。

围道 C_* 定义为 v₁∈[0,1]（实部），周期性使端点等同（v ~ v+1），基本域内包含 **v₁ = 1/2**。

**结论**：围道**确实穿过极点** v=1/2（通过周期性，v=1/2 与 v=−1/2 等同，但 v=1/2 在闭区间 [0,1] 内部，是基本域的代表元）。**gap-102b-route-a 的 [GAP-ℓ0] 标注是正确的**，不应撤回。本 attempt 是**解决**它，而非否定它。

**首版错误诊断**：首版 §3.1-3.4 错误地认为"极点 v=−1/2 在围道外，积分不穿过极点，问题不存在"，基于对周期性的误解（以为 [0,1] 是无周期的闭区间）。实际上 v=−1/2 与 v=1/2 在周期意义下等同（v ~ v+1），而 v=1/2 **在围道内部**。经 lead 指出周期性后修正。

### 6.2 n₂=0 分支的完整分类（剩余子族）

**本小节的量词**：与 §6.1 修订后一致，以下全部论证对**一切整数 m,n ≥ 1**（不假设 n≥m）、
ℓ=0、一切 Λ>0 成立。每一步用到的关于 m,n 的性质都只有"m ≥ 1 且 n ≥ 1"（即 m,n 为正），
读者可逐条核对：子族 (a) 只用 `m ≥ 1`，子族 (b) 只用 `n ≥ 1`，子族 (c) 只用 `m,n > 0`
（用于判定 `n₁/n = m₁/m` 时 m₁ 与 n₁ 同号）。

§3.2 已处理 n₂=0、m₁=n₁=0、j=±1 的情形（零点 v∈ℤ，围道穿过 v=1/2，留数为零）。Sen (D.19) 判别式 4m₁n₁+4m₂n₂+j²=1 在 n₂=0 时退化为 4m₁n₁+j²=1。j 奇 ⇒ j²∈{1,9,25,...}。

#### 子族 (a)：m₁=0, n₁≠0, j=±1

判别式：4·0·n₁+1=1 ✓（对任意 n₁）。零点方程：
```
F = v + n₁σ + m₂ = 0    (j=+1)
```
零点在 v = −n₁σ − m₂。围道上：σ = σ₁+2imΛ、v = v₁（ℓ=0 ⇒ Im v=0）。

代入：v₁ = −n₁(σ₁+2imΛ) − m₂ = −n₁σ₁ − m₂ − 2imn₁Λ。虚部：
```
Im v = −2mn₁Λ
```
对 m ≥ 1、Λ>0、n₁≠0，有 Im v ≠ 0 ⇒ 零点不在围道上（围道要求 Im v=0）。

**同理 j=−1**（F = −v+n₁σ+m₂，Im v = 2mn₁Λ ≠ 0）。

**结论**：子族 (a) 对任意 Λ>0 不命中 ℓ=0 围道。

#### 子族 (b)：n₁=0, m₁≠0, j=±1

判别式：4m₁·0+1=1 ✓。零点方程：
```
F = v − m₁ρ + m₂ = 0    (j=+1)
```
零点在 v = m₁ρ − m₂。围道上：ρ = ρ₁+2inΛ、v = v₁。

代入：v₁ = m₁(ρ₁+2inΛ) − m₂ = m₁ρ₁ − m₂ + 2inm₁Λ。虚部：
```
Im v = 2nm₁Λ ≠ 0    （m₁≠0）
```

**结论**：子族 (b) 对任意 Λ>0 不命中 ℓ=0 围道。

#### 子族 (c)：j≥3（即 j²≥9）

判别式 4m₁n₁+j²=1 ⇒ m₁n₁ = (1−j²)/4 ≤ (1−9)/4 = −2 < 0。故 m₁ 与 n₁ 异号（非零）。

**约束 (I) 在 ℓ=0 的简化**（gap-102b §2）：对 n₂=0、ℓ=0，
```
h = jℓ + 2(mn₁−nm₁) = 2(mn₁−nm₁)    (jℓ=0)
```
约束 h=0 ⇒ **mn₁ = nm₁**，即 n₁/n = m₁/m（m,n≥1 非零）。

若 m₁,n₁ 都非零且 n₁/n = m₁/m，则 m₁ 与 n₁ **同号**（因 m,n>0）。

**矛盾**：判别式要求 m₁n₁<0（异号），约束 (I) 要求 m₁n₁>0（同号）。

**结论**：子族 (c) 在 ℓ=0 时约束 (I) 与判别式不兼容，无解。

#### 总结 §6.2

n₂=0 的所有子族在 ℓ=0 处：
- m₁=n₁=0, j=±1：围道穿过 v=1/2，留数=0（§3+§4 已证）。✓
- m₁=0, n₁≠0, j=±1：Im v ≠ 0，不命中围道。✓
- n₁=0, m₁≠0, j=±1：Im v ≠ 0，不命中围道。✓
- j≥3：约束 (I) 无解。✓

**所有 n₂=0 子族已完整闭合。**
