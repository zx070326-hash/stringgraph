# sandbox —— 无规则区

这里没有规则。

- 不需要 `claim.md`，不需要 `status.yaml`，不进生命周期。
- 不过 `stringgraph validate`，pre-commit 不拦。
- 不需要查重、不需要 prior-art 检索、不需要 reviewer。
- 可以写错的东西、脏的东西、半截的东西。
- 想删就删，不留记录，不写 post-mortem。
- 随便开目录，随便命名。

**用途**：想到一个可能成立的东西，先来这里算。算通了再考虑要不要开 `research/attempts/<slug>/`
走正式流程；算不通就删掉或者留一行结论。

**唯一一条约定**（不是规则，是防止自己骗自己）：如果这里的东西要往
`research/attempts/` 或 `graph/` 搬，搬的时候才开始适用那边的规则——包括
prior-art 检索、精确量词的 claim、reviewer 审查。**膜在出口，不在入口。**

见根 `CLAUDE.md`「默认自由」节。
