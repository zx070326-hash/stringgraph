- 抽取者：lead (direct, 2026-09-14)
- 日期：2026-09-14
- 覆盖范围：全文；重点 §2–§4 (generating function, dyon index, Φ₁₀)

## 约定

- N=4 弦论：type II on K3×T²（或等价地杂化 on T⁶），四维。
- 1/4-BPS dyon 带电荷 (Q,P)；Q, P ∈ Γ⁶'⁶（二型情形）或 Γ^{(p,q)}（杂化情形）。
- 第六螺旋超迹（helicity supertrace）：−B₆ = (−1)^{J₃} Tr[(2J₃)⁶]（在 1/4-BPS 扇区）；计的是有符号的指标，不是简并度本身。
- α' 归一化未明确引用，所有计数公式在整数电荷格上成立。

## 陈述

### E1 Igusa 尖点形式 Φ₁₀ 的定义
- 位置：§3，式 (3.1)–(3.3)
- 类型：definition
- 原文陈述（忠实转述）：Φ₁₀(ρ,σ,v) 是 Sp(4,ℤ) 的权 10 尖点形式（Siegel 模形式），由 Borcherds 升举公式
  Φ₁₀(Ω) = exp(−2πi(ρ+σ+v)) ∏_{(m,n,l)>0} (1 − exp(2πi(mρ+nσ+lv)))^{c(4mn−l²)}
  给出，其中 c(k) 是 K3 椭圆亏格（权 0 指标 1 弱 Jacobi 形式）的傅里叶系数，记号 (m,n,l)>0 指 m>0，或 m=0 且 n>0，或 m=n=0 且 l<0。
- 文献自称的严格程度：定义式，引用 Borcherds 1995 和 Gritsenko-Nikulin 1995。
- 文献列出的依赖：K3 椭圆亏格 χ(τ,z)；Borcherds 乘积公式。
- 备注：Φ₁₀ 是唯一权 10 的 Sp(4,ℤ) 尖点形式（在一维子空间意义下），这是数学定理（维数公式）。

### E2 1/4-BPS dyon 的傅里叶展开：系数 = 指标 −B₆
- 位置：§3，式 (3.6)–(3.8) 及相关讨论
- 类型：proposition
- 原文陈述（忠实转述）：设 Ω = (ρ v; v σ) 为 Siegel 上半空间变量，则
  1/Φ₁₀(Ω) = ∑_{m,n,l} d(m,n,l) exp(2πi(mρ+nσ+lv))，
  其中 d(m,n,l) = −B₆(Q,P) 为电荷 (Q,P)（满足 Q²/2 = m, P²/2 = n, Q·P = l）的 1/4-BPS dyon 的螺旋超迹（指标）。
- 文献自称的严格程度："we propose" / "our conjecture is"；该识别基于对偶论证（S-对偶 + T-对偶不变性 + 对低荷情形与直接计数的吻合）。
- 文献列出的依赖：N=4 弦弦对偶（IIA ↔ 杂化）；Cardy 公式对低荷的验证；DVV (1996) 的椭圆亏格生成函数（DMVV）。
- 备注：**这是 physical-argument**——识别 d(m,n,l) = −B₆(Q,P) 不是从第一性原理数学证明推出，而是通过对偶论证和低荷验证建立的猜想，文献本身用"conjecture"和"propose"措辞。这是 BH 熵计数链最关键的物理识别步（识别①）。

### E3 傅里叶系数与电荷格的组合数据
- 位置：§3，文中
- 类型：proposition
- 原文陈述（忠实转述）：d(m,n,l) 只依赖整数 m,n,l（即 Q²/2, P²/2, Q·P），且在 d > 0（判别式 d = 4mn−l² > 0）时对应黑洞态（有宏观视界），在 d < 0 时对应无视界态。
- 文献自称的严格程度：由公式直接读出（数学陈述）。
- 文献列出的依赖：E2 的生成函数识别。
- 备注：判别式 d = 4mn−l² 与电荷格的内积 (Q²P²−(Q·P)²) 相关；这部分是数学事实（给定生成函数），独立于物理识别。

### E4 壁穿越与围道依赖
- 位置：§4，文中讨论
- 类型：proposition
- 原文陈述（忠实转述）：Φ₁₀ 在若干超曲面 {n ρ + m σ + l v = 0} 处有二阶极点；傅里叶展开的围道选择对应模空间中的 stability chamber；围道跨越极点给出系数的跳变（壁穿越）。
- 文献自称的严格程度：物理论证，基于对偶与 stability wall 的识别；具体围道-壁对应关系在后续 Sen 等文中进一步分析。
- 文献列出的依赖：E2；Sen/Ashok-Cardoso-Sen 等关于 N=4 谱的后续工作。
- 备注：围道选择 = 壁穿越是**识别②**（physical-argument）；留数本身是严格复分析计算。

### E5（★核心补充，2026-09-20）：dyon 计数的围道积分公式与 Φ 的定义

- 位置：§3，pp.10-11
- 类型：proposition
- 原文陈述（逐字，从 arXiv PDF 页图）：
  
  **式 (3.10)，p.11**：
  ```
  d(qₑ,qₘ) = ∮ dρdσdv e^{iπ(q²ₘρ+q²ₑσ+2qₑ·qₘv)} / Φ(ρ,σ,v)
  ```
  
  **式 (3.8)，p.10**（Φ 的 Borcherds 乘积表示）：
  ```
  Φ(ρ,σ,v) = e^{2πi(ρ+σ+v)} ∏_{(k,l,m)>0} (1 - e^{2πi(kρ+lσ+mv)})^{c(4kl-m²)}
  ```
  其中 c(n) 是 K3 椭圆亏格的傅里叶系数。

- 文献自称的严格程度：围道积分公式是"announced result"；Φ 的构造引用 Gritsenko-Nikulin 1995 [23] 与 Borcherds 1995。
- 文献列出的依赖：E2（生成函数识别）；Φ₁₀ 的模形式性质。
- **关键观察（researcher，2026-09-20）**：
  - (3.10) 给出围道积分，分母是 Φ，**但未给出"1/Φ 在极点的留数因子化"这一中间步骤的显式公式**
  - p.11 原文只说"From the appearance of the factor ρ₂σ₂ - v₂² = det Im Ω it is clear that the zero-modes must be included by a factor exp[iπ(q²ₘρ + q²ₑσ + 2qₑ·qₘv)]"
  - **DVV 1997 未给出留数的显式因子化表达式**，只给出围道积分的设定

### E6（补充，2026-09-20）：v→0 极限与半-BPS 因子化

- 位置：§2，p.5，式 (2.7)
- 类型：proposition  
- 原文陈述（逐字，从 arXiv PDF 页图）：
  ```
  e^{iπq·Ω·q} / Φ(Ω)  →  (1/v²) · (e^{iπρq²ₘ}/η(ρ)²⁴) · (e^{iπσq²ₑ}/η(σ)²⁴)    as v→0
  ```
  其中 q = (qₘ; qₑ) 是电磁荷向量。

- 文献自称的严格程度："Concretely, this factorization corresponds to taking the limit v→0"（物理动机）
- 文献列出的依赖：E2；1/2-BPS 配分函数 1/η²⁴
- **判定（researcher，2026-09-20）**：
  - **v→0 极限出现 1/v² 发散因子**——这是"v=0 处为二阶极点"的直接体现
  - 右端因子化为两个 η 函数（对应电荷与磁荷的半-BPS 配分函数）
  - **但这是 v→0 的渐近行为，不是有限 v 处留数的精确公式**

## 未解决的疑问

1. Φ₁₀ 的 Borcherds 展开是否在 Mathlib 射程内？涉及 Sp(4,ℤ)（没有）、弱 Jacobi 形式的 K3 椭圆亏格（没有）——当前 Lean 不可形式化。
2. 文献未明确写出傅里叶积分围道与物理 chamber 的对应关系，这在 Sen 2007 中才精确化。
3. E2 中 d(m,n,l) 是有符号量（指标）；文献偶尔把它写成"degeneracy"，但实际含义是 B₆ 型超迹，可以为负。节点应写清楚这一区别。
4. **（2026-09-20 新增）DVV 1997 未给出"1/Φ₁₀ 在极点的留数因子化闭式"**——(3.10) 只给围道积分设定，(2.7) 只给 v→0 渐近行为；**留数的中间因子化表达式需从 Sen 2007 或后续文献补充**。
