### 1.3 ⚠ 一处会咬人的记号差异：正规序常数 `A` vs `a`

- Polchinski **§4.1** 用 `A` 写老协变量子化的物理态条件：`(L_0^m + A)|ψ⟩ = 0`，临界值是 **`A = −1`**。
  - 核实：[S] §4.3–§4.7 明确写出「Requiring `(L_0 + A)|0;k⟩ = 0`」、`m² = A/α'`（tachyon）、`m² = (1+A)/α'`（level 1），并按 `A > −1 / A = −1 / A < −1` 分三种情形讨论。**已核实**。
- Polchinski **§1.3** 用 `A` 表示光锥正规序常数，`A = −(D−2)/24`；[H] 在 D24-brane 习题里写 `A = Ã = −15/16`（那是变形后的值），确认 `A` 是这个位置的符号。
- 而大部分文献（含本项目任务书里的说法）写成 `(L_0 − a)|ψ⟩ = 0`，`a = 1`。

**换算：`a = −A`。「Polchinski 的 `A = −1`」= 「通行的 `a = 1`」。**

## 4. 未解决的疑问

**Q1 — `conv.alpha-prime-regge` 的来源定位很可能是错的。**
该 convention 节点写 `§1.2, eq. (1.2.3)`。按 [C]，§1.2 起于 p.9，而 [S] 已核实 (1.2.15) 在 p.12、(1.2.28) 在 p.19 之前。`(1.2.3)` 落在点粒子作用量的段落，不可能是 `T = 1/(2πα')`。而该节点里另一条内容「`α'm² = N − 1`」已被核实对应 **(1.3.36)**，不在 §1.2。建议 curator 把 loc 拆成两条并修正。

**Q2 — `D = 26` 在 §1.3 到底是怎么论证的？**
抽取者的记忆是「第一激发能级的态数计数 + 洛伦兹表示论」，**不是**显式验算光锥洛伦兹代数 `[J^{i−}, J^{j−}] = 0`。任务书假设 §1.3 里有洛伦兹代数的计算。这两者在**认识论状态上不同**：态数计数是「必要条件」论证（若不是 26 则第一激发能级无法组成洛伦兹表示），而代数闭合是「充分性」检验。**需要人工翻 p.23–24 确认 Polchinski 走的是哪条、以及他是否明说另一条留作习题。** 这直接影响 `worldsheet.critical-dimension--via-lightcone` 这条推导该标 `physical-argument` 还是更低。

**Q3 — OPE 的收敛性在书中有没有论证？**
E27、E39、E45 都依赖「OPE 在有限半径内收敛」。Polchinski 用它推 bootstrap（(2.9.3)）和推 Virasoro 代数（(2.6.14) 的围道变形）。抽取者**没有**在任何公开源里看到 Polchinski 证明这一点。若确实不证，那么 **Virasoro 代数 (2.6.19) 本身在本书中的地位就不是 `rigorous`**，这会影响整条无鬼定理链的有效状态。→ 建议 curator 单独建一个 `worldsheet.ope-convergence` 的 axiom 节点。

**Q4 — 「自由标量 `c = 1`」的公式号找不到锚点。**
这是 `D = 26` 三条推导的公共依赖，却是本清单里唯一一条**既无式号也无页码锚点**的核心陈述。必须人工补。

**Q5 — 任务书要求的「§2.9 Verma 模与 Kac 行列式」在本次核实中找不到证据。**
[C] 确认 §2.9 标题是 "More on states and operators"，页码 68–73（共 6 页）。[S] 在这 6 页里只标注了三处：(2.9.3) 三算子 OPE / bootstrap、(2.9.14) 非最高权态的权、(2.9.15) `h_O = 0` 的算子。针对 "Polchinski + Kac determinant + Verma module" 的定向检索没有返回任何把 Kac 行列式定位到 Polchinski Vol.1 §2.9 的来源；返回的 Kac 行列式来源都是别的文献（Di Francesco 型综述、arXiv:2208.05180 等）。
**结论：抽取者认为 §2.9 很可能只讲最高权态/降算符生成的模，不讲 Kac 行列式。** 但这是 **negative evidence**（[S] 是选择性注释，不是完整转录），**不能当作定论**。需要人工翻 p.68–73 确认。若确实没有，Kac 行列式的来源应改挂 `kac-1979` / `feigin-fuchs-1982`（`sources.bib` 里已有这两条）。

**Q6 — §3.4 里 `D = 26` 的公式号。**
已知 §3.4 = p.90–96，(3.4.31)「中心荷是常数」在 p.96–97（即该节末尾）。所以 `c^{tot} = 0 ⇒ D = 26` 的结论要么在 (3.4.31) 之前、要么就是 (3.4.32)/(3.4.33)。**需要人工确认。** 另外要确认 Polchinski 在此处写的是「`c^m = 26`」（允许一般物质 CFT）还是直接写「`D = 26`」——这两者是**不同的陈述**，图里应该拆开，前者是更强/更一般的那条。
