## 陈述

### E1 椭圆亏格的定义

- 位置：§2，eq. (2.1)（PDF p.3 = 印刷 p.2）
- 类型：definition
- 原文陈述（逐字，图像核对）：

  ```
  Z(τ, z) = Tr(−1)^F q^{L₀−c/24} q̄^{L̄₀−c/24} y^{J₀} ,            (2.1)
  ```

  紧接其后（逐字）："where q = e^{2πiτ} with τ defined on the upper half-plane, y = e^{2πiz}
  and F = F_L − F_R with F_L (F_R) being the fermion number of left (right)-movers."

- 文献自称的严格程度："Following Witten [3] we define the elliptic genus"（定义，不是定理）。
- 文献列出的依赖：[3] = E. Witten, "On the Landau-Ginzburg description of N = 2 minimal models,"
  IASSNS-HEP-93/10 (hep-th/9304026)。
- 备注：这是 **CFT 侧（物理）定义**。后面 (5.3) 给出的是显式 θ 函数表达式，其 z=0 求值是纯数学的。

### E2 z = 0 处椭圆亏格给出 Witten 指标

- 位置：§2，eq. (2.3)（PDF p.3 = 印刷 p.2）
- 类型：proposition
- 原文陈述（逐字，图像核对）：

  "Setting z = 0 in (2.1) we have the Witten index

  ```
  Z(τ, 0) = Tr(−1)^F ,                                            (2.3)
  ```

  which may yield the Euler characteristic of the target manifold if the theory admits a
  sigma model interpretation [12]."

- 文献自称的严格程度：**注意措辞是 "may yield"**（"若理论容许 sigma model 解释，这**可能**给出
  靶空间的 Euler 示性数"）。这是**带条件的、谨慎的**物理陈述，不是无条件断言。
- 文献列出的依赖：[12] = E. Witten, Nucl. Phys. **B202** (1982) 253。
- 备注：**逐字要点**：(2.1)→(2.3) 的推理是「把 z=0 代入迹」，因此 `Z(τ,0)` 与 τ 无关这件事，
  在此处是由 `Tr(−1)^F` 右边**不含 τ** 直接读出的（右边没有 q）。这是本文里
  「Z(τ,0) 与 τ 无关」的第一处（隐式）依据，但它建立在迹的形式操作上，不是模形式论证。

### E3 χ := Z(τ, 0)（把 Euler 亏格定义为 z=0 特殊化）

- 位置：§5 开头，eq. (5.1)（PDF p.13 = 印刷 p.12）
- 类型：definition
- 原文陈述（逐字）：

  "we can compute the elliptic extension of the Â (Dirac genus), σ (Hirzebruch signature)
  and χ (Euler characteristic) genera [10] defined by

  ```
  Â = q^{ĉ/8} Z(τ, (τ+1)/2) ,    σ = Z(τ, 1/2) ,    χ = Z(τ, 0) .    (5.1)
  ```
  "

- 文献自称的严格程度：定义性（"defined by"）。
- 文献列出的依赖：[10] = T. Eguchi, H. Ooguri, A. Taormina, S.-K. Yang,
  Nucl. Phys. **B315** (1989) 193（即 EOTY 1989）。
- 备注：注意 Â 与 σ 是 τ 的非平凡函数（见 E5 的 q-展开），而 χ 恰好退化成常数——这一点是
  **(5.4) 的结论**，不是定义的一部分。

### E4 【★ 承重】K3 椭圆亏格的显式 θ 函数表达式

- 位置：§5.2「ĉ = 2 Models」，eq. (5.3)（PDF p.15 = 印刷 p.14）
- 类型：proposition（作者自称 "After some algebra we find"）
- 原文陈述（逐字，200 dpi 渲染图逐符号目视核对）：

  "the elliptic genus for the K3 surface has already been calculated in [10]. What is left to
  us is to recover the z-dependence in their expression. After some algebra we find

  ```
                  ( ϑ₃(τ,z) )²      ϑ₄⁴ − ϑ₂⁴  ( ϑ₁(τ,z) )²
  Z(τ, z) = 24 · (  ───────  )  − 2 ─────────  (  ───────  ) ,       (5.3)
                  (    ϑ₃    )          η⁴      (     η    )
  ```

  where η = η(τ) and ϑ_a = ϑ_a(τ, z = 0) are theta constants for a = 2, 3 and 4. One can
  easily check that (5.3) satisfies (2.7) and (2.11) with h = 1 ."

  【逐字细节，已逐符号核过】：
  - 整体系数是 **24**（不是 12、不是 8），乘在 `(ϑ₃(τ,z)/ϑ₃)²` 上；
  - 第二项系数是 **−2**，分子是 **ϑ₄⁴ − ϑ₂⁴**（**4 次幂**，顺序是 ϑ₄ 在前、ϑ₂ 在后，**带负号**），
    分母是 **η⁴**；
  - 第二项的括号里是 **ϑ₁(τ,z)/η**（分母是 **η 的一次幂**），整体平方。
  - 两个分式括号都取**平方**。

- 文献自称的严格程度："After some algebra we find"；K3 椭圆亏格本身 "has already been
  calculated in [10]"（EOTY 1989），本文的贡献是恢复 z 依赖。
- 文献列出的依赖：[10] = EOTY 1989；(2.7)（SL(2,ℤ) 模变换）与 (2.11)（z 的双重准周期性）作为验算。

### E5 【★★ 目标 1 的逐字来源】χ = 24

- 位置：§5.2，eq. (5.4) 第三行（PDF p.15 = 印刷 p.14）
- 类型：proposition（由 (5.3) 代入 (5.1) 计算所得）
- 原文陈述（逐字，200 dpi 渲染图目视核对）：

  "Substituting (5.3) into (5.1) and making q-expansions we obtain ⁸

  ```
  Â = 2q^{−1/4}(−1 + 20q^{1/2} + 62q + 216q^{3/2} + 641q² + 1636q^{5/2} + ···) ,

  σ = 16(1 + 32q + 256q² + 1408q³ + 6144q⁴ + 22976q⁵ + ···) ,          (5.4)

  χ = 24 .
  ```
  "

  （脚注 8 逐字："In eq.(3.6) of [10] the coefficient 34 should read 32." ——这是 KYY 对 EOTY
  的一处**勘误**，与本条无关，但一并记下，见「原文疑点」。）

- **对目标 1 的裁定：SUPPORT（强，逐字）。**

  理由，分成「原文说了什么」与「我的推断」两部分：

  **原文说了什么（逐字）**：
  1. (5.1) 逐字定义 `χ = Z(τ, 0)`；
  2. (5.3) 逐字给出 K3 的 `Z(τ, z)`；
  3. (5.4) 逐字给出「把 (5.3) 代入 (5.1) 并做 q-展开」的结果，其中 `χ = 24`。
  4. **同一个式子 (5.4) 里，Â 与 σ 各带一条无穷 q-级数，唯独 χ 写成裸常数 `24`，没有 `+ O(q)`、
     没有省略号。** 这是作者把「χ 与 τ 无关」当作计算结果**显式呈现**出来的方式。

  **我的推断（明确标注为推断，非原话）**：KYY 全文**没有**一句话写成
  「χ_{K3}(τ,0) 对一切 τ 恒为 24」这样的自然语言断言，也没有写「因为权 0 模形式必为常数」。
  「对一切 τ」这一量词是从「(5.4) 的 χ 行是一个不带 q 的常数，而同一式的另外两行都带 q 级数」
  这个**排版/上下文对比**读出来的。若要求一条把量词写死的自然语言句子，本文**不提供**。
  但补上 E6 的独立算路后，这一步是**可自洽验证**的（见 E6）。

- 文献自称的严格程度：计算结果（"we obtain"），无定理/证明标记。

### E6 【★ 交叉验证】(5.3) 在 z = 0 处直接求值 = 24（我的推断，但只用逐字事实）

- 位置：由 E4 的 (5.3) + 标准事实 `ϑ₁(τ, 0) = 0`
- 类型：**我的推断**（KYY 未写出这一步）
- 内容：

  把 z = 0 代入 (5.3)：
  - 第一项：`24 · (ϑ₃(τ,0)/ϑ₃)² = 24 · 1² = 24`（因 (5.3) 下方逐字说明 `ϑ₃ := ϑ₃(τ, z=0)`，
    故该括号在 z=0 恒为 1；且 ϑ₃(τ,0) ≠ 0，分母合法）；
  - 第二项：`−2 · (ϑ₄⁴−ϑ₂⁴)/η⁴ · (ϑ₁(τ,0)/η)² = 0`（因 `ϑ₁(τ,0) = 0`，且 `(ϑ₄⁴−ϑ₂⁴)/η⁴`
    对 τ ∈ ℍ 有限）。

  故 `Z(τ, 0) = 24` **对一切 τ ∈ ℍ**，不需要任何模形式论证、不需要取极限。

- 备注：这一步把 E5 的「对一切 τ」量词坐实成一行显式代入。**但它是我做的，不是 KYY 写的。**
  它的两个输入分别是：(a) KYY (5.3) 逐字；(b) `ϑ₁(τ,0)=0`（Jacobi θ₁ 是 z 的奇函数，标准事实；
  在 kawai-1997 eq.(4.16) 中以 `ϑ′₁(τ,0) = 2πη(τ)³` 的形式间接出现——那条式子写的是**导数**，
  它有意义正是因为 ϑ₁ 本身在 z=0 取零）。

### E7 K3 椭圆亏格的 (q, y) 双重展开系数表

- 位置：§5.2，eq. (5.5)（PDF p.15 = 印刷 p.14）
- 类型：显式数值表
- 原文陈述（逐字，图像核对；空白格即原文空白）：

  "Some coefficients of the double expansion of (5.3) with respect to q and y = e^{2πiz} are
  obtained as

  ```
          y⁻³    y⁻²    y⁻¹     y⁰      y¹     y²    y³
  q⁰                     2      20      2
  q¹              20    −128    216    −128    20
  q²       2     216   −1026   1616   −1026   216    2
  ```
                                                            (5.5)"

- **对目标 1 的附加支撑（逐字层面的数值验算）**：按 `Z = Σ c(4n−r²) qⁿ yʳ`（kawai-1997 eq.(4.28)），
  「χ_{K3}(τ,0)=24 对一切 τ」等价于 `Σ_l c(4N−l²) = 24 δ_{N,0}`。用本表逐行求和（我的算术）：
  - q⁰ 行：`2 + 20 + 2 = 24` ✔（= 24 δ_{0,0}）
  - q¹ 行：`20 − 128 + 216 − 128 + 20 = 0` ✔
  - q² 行：`2 + 216 − 1026 + 1616 − 1026 + 216 + 2 = 0` ✔

  即目标 1 所需的系数恒等式在 **N = 0, 1, 2 三阶被本表逐字数值证实**。
  （这三阶是逐字的；全阶常数性靠 E5/E6。）

- 备注：本表与 kawai-1997 eq.(4.31)（`h₀ = 20 + 216q + 1616q² + ···`，
  `q^{1/4}h₁ = 2 − 128q − 1026q² − ···`）逐项一致，构成两篇之间的独立交叉核对。
  也与 kawai-1997 eq.(4.32) 的 `c(0) = 20, c(−1) = 2` 一致（本表 q⁰y⁰ = 20，q⁰y¹ = 2）。

### E8 一般 CY3 情形：z = 0 给出 Euler 示性数（一般定理的最接近表述）

- 位置：§5.3，eq. (5.7)（PDF p.15 = 印刷 p.14）
- 类型：proposition
- 原文陈述（逐字）：

  "If we let z = 0 in (5.6) we get the Euler characteristic of M

  ```
  Z(τ, 0) = Tr(−1)^F = 2(h^{1,1} − h^{2,1}) = χ(M) ,                  (5.7)
  ```

  thanks to the Euler pentagonal identity."

- 备注：⚠ **这一条是 ĉ = 3（Calabi–Yau 三维）情形，不是 K3**。它是「椭圆亏格在 z=0 退化为
  Euler 示性数」这条一般命题在本文中**唯一**被明确写成等式链（含 `= χ(M)` 字样）的实例。
  **本文对 K3（ĉ=2）没有写出对应的 `Z(τ,0) = χ(K3)` 字样的等式**——K3 情形只给了 (5.4) 的
  `χ = 24`，其中 χ 是 (5.1) 定义的符号。若 curator 需要「一般定理 + χ(K3)=24」这条路径，
  本文能提供的一般定理最强形式是 (5.7)（仅 CY3）与 (2.3)（带 "may yield" 条件的一般陈述），
  **不是**一条无条件的一般定理。

## 原文疑点

1. **KYY 对 EOTY 的勘误**：脚注 8 逐字 "In eq.(3.6) of [10] the coefficient 34 should read 32."
   （[10] = EOTY, Nucl. Phys. B315 (1989) 193）。本项目若后续引 EOTY eq.(3.6) 需注意此勘误。
   本抽取**未核 EOTY 原文**（该文 1989 年，不在 arXiv）。
2. **式号漂移风险**：本文有 arXiv v2 与 Nucl. Phys. B414 刊出版两个版本。本抽取式号全部取自
   arXiv v2 PDF。刊出版编号**未核**。
3. **(2.3) 的措辞是 "may yield"**，不是断言。即 KYY 自己对「Witten 指标 = Euler 示性数」
   这一步是**附条件**的（"if the theory admits a sigma model interpretation"）。
   路线若要用「Z(τ,0) = χ(K3) = 24」中的 **"= χ(K3)"** 一节，这条来源**不够硬**；
   但路线实际只需要**数值 24**（E5 直接给），不需要它等于 Euler 示性数。
