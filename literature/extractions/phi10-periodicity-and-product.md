## 陈述

### E1 Borcherds 乘积公式——逐字来源：kawai-1997 eq.(5.13)

- 位置：T. Kawai, "K3 Surfaces, Igusa Cusp Form and String Theory," arXiv:hep-th/9710016
  （1997；Taniguchi 研讨会论文集），eq.(5.13)，参 eq.(5.12), eq.(2.19), eq.(4.28), eq.(4.32)。
- 类型：proposition（援引 Gritsenko-Nikulin 的乘积公式，kawai-1997 作为清晰转述来源）。
- 原文陈述（ar5iv HTML 逐字核实）：

  eq.(5.13)：
  ```
  χ₁₀(Ω) = pqy ∏_{(k,l,r)>0} (1 − p^k q^l y^r)^{c(4kl−r²)}
  ```

  乘积指标集（eq.(5.13) 脚注）：三元组 (k,l,r) 满足 k>0 且 l≥0；或 k≥0 且 l>0；或 k=l=0 且 r<0。

  变量定义 eq.(2.19)：`p = e[σ], q = e[τ], y = e[z]`（e[x] = e^{2πix}）。

  系数 c(N) 来自 K3 椭圆亏格 eq.(4.28)：`Z(τ,z) = Σ c(4n−r²) q^n y^r`。

  系数低阶值 eq.(4.32)（逐字）：`c(0) = 20, c(−1) = 2, c(N) = 0 if N < −1`。

  前因子乘积 eq.(5.12)（Δ₅ = 权 5 形式，χ₁₀ = Δ₅²）：
  ```
  Δ₅(Ω) = p^{1/2} q^{1/2} y^{1/2} ∏_{(k,l,r)>0} (1 − p^k q^l y^r)^{c(4kl−r²)/2}
  ```

- 文献自称的严格程度：援引 Gritsenko-Nikulin（alg-geom/9611028）乘积升举结果，
  kawai-1997 作为物理综述转述，Gritsenko-Nikulin 为原始严格来源。
- 文献依赖：Borcherds 升举定理；Gritsenko-Nikulin 1997（alg-geom/9611028）。

#### 对 GAP-前提1（整周期性）的支撑：**强（逐字）**

乘积 ∏_{(k,l,r)>0}(1−p^k q^l y^r)^{c(4kl−r²)} 中，每个因子含 y 的指数 r 均为**整数**
（乘积指标集 r∈ℤ）；前因子 pqy 的 y 指数亦为整数 1。故 χ₁₀(Ω) 只含 y 的整数次幂。
由 y = e^{2πiz}，变量 z→z+1 时 y→y·e^{2πi} = y，故每个 y^r 不变，乘积整体不变：

    χ₁₀(τ, z+1, σ) = χ₁₀(τ, z, σ).   [整周期性，由 eq.(5.13) 直接推出]

**本推导仅用 eq.(5.13) 的显式乘积结构，无需诉诸 Sp(4,ℤ) 变换律——整数指数结构已充分。**

### E2 奇 ℓ 系数非零（K3 椭圆亏格侧）——逐字来源：kawai-1997 eq.(4.32)

- 位置：同 E1，kawai-1997 eq.(4.32)（逐字）。
- 原文陈述（逐字）：
  ```
  c(0) = 20,  c(−1) = 2,  c(N) = 0  if N < −1
  ```
- **对 GAP-前提2（奇 ℓ 系数非零）的支撑：直接坐实。**

  乘积 eq.(5.13) 中指标 (k,l,r) = (0,1,1) 对应的项（k=0, l=1>0, r=1 奇数）：
  指数 = c(4·0·1 − 1²) = c(−1) = 2 ≠ 0。

  因此乘积中明确包含因子 (1 − q^0 p^1 y^1)^2 = (1 − p·y)^2（取 k=0, l=1, r=1）。
  将此展开到 y 的线性项：(1−py)^2 = 1 − 2py + p²y²，含 y^1 项（奇 ℓ=1，系数 −2≠0）。

  故 χ₁₀ 的 Fourier-Laurent 展开含 y^{奇数} 项，即：
  **1/χ₁₀（或 χ₁₀）的展开含 y^{±1} 项，奇 ℓ 系数非零**。
  这直接坐实 proof.md Lemma B.3(b) 的矛盾论证所需前提。

- 文献自称的严格程度：明确数值表（严格，导自 K3 椭圆亏格的定义）。
- 备注：c(−1)=2 对应 K3 椭圆亏格的最低阶项 Z = 2y⁻¹ + 20 + 2y + O(q)，即 ℓ=±1 系数各为 2。

### E3 φ_{−2,1} 的显式展开与低阶系数——逐字来源：dabholkar-murthy-zagier-2012 §4.3

- 位置：A. Dabholkar, S. Murthy, D. Zagier, "Quantum Black Holes, Wall Crossing, and Mock
  Modular Forms," arXiv:1208.4074（DMZ），§4.3 "Example: Jacobi forms of index 1"。
- 类型：proposition / 显式展开 + Table 1（数值表）。
- 原文陈述（ar5iv HTML 逐字核实）：

  eq.(85)（逐字）：
  ```
  φ_{−2,1}(τ,z) = (y−1)²/y − 2 (y−1)⁴/y² q + (y−1)⁴(y²−8y+1)/y³ q² + ⋯
  ```
  首项 (y−1)²/y = y − 2 + y⁻¹，即 **φ_{−2,1} = (y − 2 + y⁻¹) + O(q)**。

  eq.(88)（逐字）：
  ```
  φ_{−2,1}(τ,z) = θ₁²(τ,z)/η⁶(τ) = φ_{10,1}(τ,z)/Δ(τ)
  ```

  eq.(78)（逐字）：指标 1 的 Jacobi 形式 φ(τ,z) = Σ_{n,r∈ℤ} C(4n−r²) qⁿ yʳ，
  即系数只依赖判别式 Δ = 4n−r²。

  eq.(61)（逐字，系数约化）：c(n,r) = C(4nm−r², r)，C 只依赖 r mod 2m。

  Table 1（逐字）：k = −2 时 C_{−2}(Δ) 在 Δ = −1, 0, 3, 4, 7, 8, 11, 12, 15 处取值
  ```
  1, −2, 8, −12, 39, −56, 152, −208, 513
  ```
  即 **C_{−2}(−1) = 1 ≠ 0**，C_{−2}(0) = −2。

- **对 GAP-前提2（奇 ℓ 系数非零）的支撑：强（逐字）。**
  proof.md 陈述的乘积公式使用 φ_{−2,1} 的 Fourier 系数 c(k)（DMZ 记号 C(k)）。
  取 (m,n,ℓ) = (0,1,1)（ℓ = 1 奇数，4mn − ℓ² = −1）：
  c(−1) = C_{−2}(−1) = 1 ≠ 0。
  故乘积中出现因子 (1 − p·q^? · y^1)^{c(−1)}（按 DMZ 变量约定），含 y^{奇} 项。
  与 E2 结论一致：**奇 ℓ=±1 项系数非零（C_{−2}(−1)=1≠0）**，坐实前提2。
  另外，(y−2+y⁻¹) 的首项本身即显式给出 y^{±1}（奇 ℓ）系数 = 1 ≠ 0。

- 文献自称的严格程度：Table 1 为显式数值表（逐项可验证）；eq.(85)/(88) 为等式陈述。
- 文献依赖：Eichler-Zagier Jacobi 形式理论（φ_{−2,1} = θ₁²/η⁶ 为标准结果）；
  φ_{−2,1} 即 DMZ eq.(93) 中记作 A 的指标 1 弱 Jacobi 形式环生成元。

## 未解决的疑问

1. **kawai-1997 是综述，原始严格来源是 gritsenko-nikulin-1998（alg-geom/9611028）**，
   本项目未获取 GN 正文逐字。kawai-1997 逐字转述了乘积公式且自足；若要升 L1 一手，
   需后续补 GN 原文逐字。
2. **变量约定映射**：kawai-1997 用 Ω=[[τ,z],[z,σ]] 且 p=e[σ], q=e[τ], y=e[z]；
   proof.md 用 Φ₁₀(τ,z,σ) 且 q=e^{2πiτ}, y=e^{2πiz}, p=e^{2πiσ}。两者一致（τ↔τ, z↔z, σ↔σ），
   但 proof.md 的占位公式写作 e^{2πi(ρ+σ+v)}，其变量名（ρ,σ,v）对应 DGM/Rosselló 记号，
   需注意 ρ↔τ, v↔z, σ↔σ 的换名（见 proof.md 推论 B1）。
3. **φ_{−2,1} 的 c(k) vs K3 椭圆亏格的 c(k)**：两者相差因子（DMZ C_{−2}(−1)=1，
   kawai c(−1)=2），但**非零性一致**，前提2 不依赖具体归一化。
4. kawai-1997 乘积指数用的是 K3 椭圆亏格 c(N)（eq.4.28），而 proof.md 用 φ_{−2,1} 的系数；
   若严格按 proof.md 文字（"c(k) 是弱 Jacobi 形式 φ_{−2,1} 的 Fourier 系数"），
   最贴切逐字来源是 DMZ §4.3（E3），kawai-1997（E2）为等价非零性佐证。
