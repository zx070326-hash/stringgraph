## 4. §5 三处符号链（审查者独立重算，lead 已复核）

全部基于 Li–Wang (3.2) 与 p.11 的 Δ̄ 定义（`literature/extractions/math-sources.md` §36.6 (a)(b) 的 L1 逐字块）。

- **链 1**：`E^-(γ,x) = exp(Σ_{n≥1}(γ(−n)/(−n))x^n)`，代 `γ := −α` 得 `γ(−n) = −α(−n)`，分子分母两负相消 ⟹ `E^-(−α,x) = exp(Σ_{n≥1}(α(−n)/n)x^n)`。
- **链 2**：`E^+(γ,x) = exp(Σ_{n≥1}(γ(n)/n)x^{−n})`，代 `γ := −α` ⟹ `E^+(−α,x) = exp(−Σ_{n≥1}(α(n)/n)x^{−n})`。只经过一次取负，**不相消**，净负号。
- **链 3**（最关键）：`Δ̄(α,y) = (−y)^{α(0)}E^+(−α,−y)`，代 `y = −x`：零模因子 `(−(−x))^{α(0)} = x^{α(0)}`，指数因子 `E^+(−α,x)` ⟹ **`Δ̄(α,−x) = x^{α(0)}E^+(−α,x)`**。

### 4.1 `(−1)^{α(0)}` 去哪了（lead 专门追问的一步）

审查者给了独立交叉验证：把 `(−y)^{α(0)}` 显式拆成 `(−1)^{α(0)}y^{α(0)}` 再走一遍，两条路径汇合。

拆分的合法性依据 Li–Wang p.11 的逐字前提「`α(0)` 半单且**只有整数本征值**」：在 `m`-本征子空间上 `y^{α(0)}` 按定义作用为**整数幂单项式** `y^m`，**不是形式幂级数展开**，因而不涉及二项式定理这类只对非负整数指数或形式级数成立的展开规则。于是对每个整数 `m`（正、负、零一视同仁）`(−y)^m = (−1)^m y^m`，由半单性逐本征空间成立后线性延拓为算子恒等式 `(−y)^{α(0)} = (−1)^{α(0)}y^{α(0)}` … (†)

- **负本征值**：`m` 为负整数时 `(−1)^m` 仍只取 `±1`，不引出分数幂或多值性，无需特殊处理。
- **混合本征空间**：由半单性按本征空间分块作用，每块套整数幂公式后线性叠加，无跨本征空间交叉项。

用 (†) 两次：`(−1)^{α(0)}(−x)^{α(0)} = (−1)^{2α(0)}x^{α(0)}`，而任意整数本征值 `m` 使 `2m` 恒为偶数（不论正负），故 `(−1)^{2α(0)} = id`。

⇒ **"两个负号相消"的精确含义**：`(−1)^{α(0)}` 确实出现了两次（不是从未出现），在指数层面因 `2α(0)` 恒为偶数而抵消。lead 已独立复核这条链，结论一致。
