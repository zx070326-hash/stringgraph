# 我把答案写进了任务书：Borcherds 路线的「两位 reviewer 独立同意」是假的

**记录人**：lead（主会话），2026-09-20 晚
**性质**：多 agent 方法论失效记录。**过错方是 lead**，不是任何一个 agent。
**同类前案**：`research/attempts/so-usp-adjoint-trace-lean-route.md`（2026-09-19，
so-usp 假佐证回路）。本条是第二例，**机制不同，值得单独记**。

## 发生了什么

1. `dvvrev`（审 `dvv-wall-crossing-from-residue`）在 F6 里**主动提出**一条升级路线：
   不走 Sen 的 Φ̂ 与归一化常数 c，改用图内 rigorous 的
   `igusa-cusp-form-phi10-v2` 的 Borcherds 乘积直接算，得

       Φ₁₀ = −4π²v²·η(ρ)²⁴·η(σ)²⁴ + O(v⁴)

   它自述**未核** `χ_{K3}(τ,0)=24`，也未核 `v=0` 邻域的乘积重排合法性。

2. lead 随后派 `ell0s6rev` 去审 `ell-zero-wall-degeneracy` §6，并在任务书里
   **把 dvvrev 的这条目标公式逐字写了进去**，请它一并判断这条路线。

3. `ell0s6rev` 独立做了逐因子计算，得到**同一个公式**，并给出了完整推导
   （`(0,0,−1)` 因子给 `−4sin²(πv) = −4π²v²+O(v⁴)`；`m>0,n=0` 与 `m=0,n>0` 两族
   经指数 `c(0)+2c(−1)=24` 给 `η(ρ)²⁴η(σ)²⁴`；`m,n≥1` 整块因 `Σ_l c(4mn−l²)=0 (mn≥1)`
   等于 1）。

4. **lead 一度把这当成「两个独立 agent 各自算出同一结果」**，即把它读成了对该路线的
   独立佐证。

5. **`ell0s6rev` 自己拆穿了这一点**（它对 lead 提问的回答 B）：它的推导**不独立于
   dvvrev**，因为 lead 的任务书已经把目标公式告诉了它。它知道要算到哪里。

## 为什么这一条比听起来严重

Borcherds 路线**不是可有可无的备选**。它是目前唯一能把 `h₀ ≠ 0`（进而把整条
ℓ=0 留数链的结构卡）从 `physical-argument` 抬到 `rigorous` 的路，因为它绕开了
Sen 的 Φ̂ / 常数 c / [EXT-g-eta] 那一整段取信作者的前提。如果「两位 reviewer 都算出
同一个式子」被当作它已经可靠，那么：

- 该路线唯一真正承重的无源步骤 **`χ_{K3}(τ,0) = 24` 对一切 τ** 就会被跳过。
- **两位 reviewer 都把它当标准知识用了，都没取源**（dvvrev 明确声明未核；
  ell0s6rev 用的是「弱 Jacobi 形式在 z=0 退化为权 0 模形式故为常数 = Euler 示性数」
  这条标准论证，同样无来源）。
- 图内**没有任何 K3 椭圆亏格节点**（`uv run stringgraph search "elliptic genus"` 无命中）。
  抽取记录 `phi10-periodicity-and-product.md:84` 只有 `Z = 2y⁻¹+20+2y+O(q)`，
  那是 **q⁰ 项**，支持不了「对一切 τ 恒为常数」，而路线用的恰恰是全阶常数性。

即：**两次同意 = 同一条未取源的假设，被用了两次。** 已派 researcher 取逐字。

**lead 从「两份一致」里读出的那个信息量**——那个信息量是零。

## 纪律（补进派工习惯）

1. **派第二个 agent 去核第一个 agent 的结论时，不要在任务书里写出那个结论。**
   只写问题。想让它算 Φ₁₀ 在 `v=0` 的领头行为，就写「请用 Borcherds 乘积算 Φ₁₀ 在
   `v=0` 附近的领头行为」，**不要**写「dvvrev 说答案是 −4π²v²η²⁴η²⁴，请核」。
2. **若因为要圈定工作范围而不得不给出目标**，必须逐字标注：
   「这是另一个 agent 的**未核断言**，不得当作既定事实；并请告诉我：**如果没有这句话，
   你会不会走到同一个结论**。」
3. **一致不等于佐证。** 收到两份一致的结果时，先问「它们的输入有没有交集？交集是谁给的？」
   ——交集若来自 lead，一致性就是自己的回声。
4. 承接前案的两条（仍然有效）：派工方必须标注「推断 vs 已核事实」；接收方对无法核实的
   输入必须逐字声明「我无法验证这条，我是在接受你的前提」。
