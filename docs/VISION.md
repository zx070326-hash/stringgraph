# 愿景：把弦论说清楚

## 出发点

弦论没有实验。剩下的进展路径只有两条：

1. **自我消解**：证明理论内部矛盾，或证明它必然与已知事实冲突（例如不允许正宇宙学常数）。
2. **唯一性论证**：证明任何满足少数已被实验确认的前提（量子力学、洛伦兹不变性、引力存在、幺正性）的理论必然包含弦，从而让弦论继承那些前提的实验支持。

两条路都要求理论被**精确陈述**。而弦论目前的状态是：世界面理论（二维 CFT、顶点算子代数）已公理化，拓扑扇区有严格定义（Costello–Li、扭曲全息），微扰弦论接近（弦场论、超模空间），非微扰整体没有定义。五十年文献散落在期刊、讲义和口头传统里，约定不统一，大量"标准结果"没有任何一处完整写出的推导，更没有人能回答"如果某条对偶是错的，会连带倒掉哪些结论"。

## 我们做什么

不是"证明弦论"，而是三件更便宜、更确定的事：

**第零层：依赖图**。把结果整理成陈述节点和推导边，每个节点标注它自身论证的严格程度，工具计算沿图传播的有效状态。产出是一张能回答"某条结论建立在哪些猜想之上"的图。这不需要 Lean，成本最低，信息量最大。

**第一层：审计核心**。少数里程碑陈述由物理学家（船长）逐条确认自然语言表述与规范约定，并通过回译审计。这是人类审计面，其余节点不需要人审。

**第二层：形式化岛**。挑已有 Lean 基础、又是弦论旗舰结果的目标做形式化。第一个目标是 Goddard–Thorn 无鬼定理（临界维数 26 的代数推导），因为 Virasoro 代数已经在 Lean 里，且它是纯代数定理。第二个候选是 Green–Schwarz 反常消除。

## 为什么现在

过去这件事没人做，是因为激励结构不奖励整理、数学基础设施缺失、以及"现有表述只是暂时的"心态。前两个正在被 AI 形式化工具和 Mathlib/Physlib 的增长改变，2026 年的 FLT 形式化和 Prove2Me 平台证明了多 agent 大规模形式化的可行性。第三个心态我们认为方向反了：正因为没有实验，把理论说清楚是剩下的少数几件有意义的事。

## 不做什么

- 不宣称任何未被 Lean 验证的东西被"证明"。
- 不在图里编造依赖。找不到来源的边显式标 `inferred`。
- 不试图给非微扰弦论下定义。那是物理问题，不是整理问题。
- 不用一个私有的、不可归属的流程。所有贡献可追溯，引用计入贡献。
